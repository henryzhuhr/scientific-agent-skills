# ISO 13485:2016 差距分析清单

此综合清单有助于确定您当前的质量管理体系与 ISO 13485:2016 要求之间的差距。

## 如何使用此清单

* *状态指标：**
- ✅ **合规：** 要求完全实施并记录
- ⚠️ **部分：** 要求部分实现，需要改进
- ❌ **不合规：** 要求未实现或记录
- N/A **不适用：** 要求不适用（必须证明合理）

* *对于每个项目：**
1. 评估当前状态
2. 识别现有文档
3. 注意差距或缺陷
4. 确定所需行动的优先顺序
5. 分配责任和目标日期
