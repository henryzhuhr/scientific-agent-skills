# 无细胞蛋白表达验证

* *URL：** https://cloud.ginkgo.bio/protocols/cell-free- Protein-express-validation
* *状态：** Ginkgo 认证
* *价格：** $39/样本（默认：$936 8 个蛋白 x 3 个重复 = 24样品）
* *周转时间：** 5-10 天

## 概述

从蛋白质序列到定量表达的通过/不通过读数的最快路径。使用专有的重组大肠杆菌转录翻译（无细胞蛋白质合成，CFPS）系统。反应在 4-16 小时内完成。专为早期筛选、新颖构建体评估以及在将资源投入下游优化或纯化之前快速筛选候选序列而设计。

## 输入

- **`.fasta` 格式的 DNA 序列**
- 支持高达 1800 bp 的序列

## 输出

- **表达确认：** 验证目标蛋白预期分子量
- **基线滴度：** 初始定量产量测量（mg/L）
- **初始纯度：** 目标蛋白与杂质的百分比，通过虚拟凝胶图像提供

## 自动化工作流程

### 第 1 阶段 - CFPS 反应设置和孵育

1. 检索板
2. 标记 DNA 模板
3. 密封板
4. 在 30 度下振荡孵育 C

### 第 2 阶段 - 定量制备 

1. 分配 PBS 稀释剂
2. 密封板
3. 储存于 4 度 C

### 第 3 阶段 - LabChip 定量

1. 启封板
2. LabChip定量
3. 密封板
4. 储存于 4 度 C

## 实验方案参数

- 有效负载和试剂
- Bravo Stamp
- HiG 离心机
- 孵育和储存
