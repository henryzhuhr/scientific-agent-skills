# 荧光像素艺术一代

* *URL：** https://cloud.ginkgo.bio/protocols/florescent-pixel-art- Generation
* *状态：** Beta
* *价格：** 25 美元/盘
* *周转：** 5-7 天

##

概述将数字图像转化为打印在琼脂多功能托盘上的活体荧光细菌艺术品。客户提交像素艺术设计，颜色被映射到不同的荧光大肠杆菌菌株。用冷冻甘油储备液制备过夜培养物，稀释后通过 Echo 声学液体处理以每点 50 nL 的量分配到选择性 LB-氯霉素琼脂平板上。将板在 30 ℃ 下孵育 16 小时，然后在 4 ℃ 下孵育 12 小时以稳定集落形态和荧光。在紫外线照明下拍摄高分辨率照片并以数字方式传送。

## 输入

- **图像文件：** `.png` 或 `.svg` 格式
- **分辨率：** 48x48 至 96x96 像素
- **颜色映射：** 将图像颜色与荧光应变相匹配调色板
- **方向：** 确认板方向和多板设计（相同与不同）

## 输出

- **数字交付：** TIFF/JPEG 格式的高分辨率 UV 图像
- **可选附加组件：** 带框档案打印

## 自动化工作流程

### 第 1 阶段 - 源板准备

1. 摇源板
2. 离心源板
3. 剥离源板密封

### 第 2 阶段 - 声学点胶（每个目标板）

1. 剥离目标密封件
2. Echo hit-pick 分配（每个点 50 nL）
3. 密封目标板
4. 摇动目标板
5. 离心机目的地
6. 将目的地存储在 30 摄氏度（孵育 16 小时）

### 第 3 阶段 - 源存储

1. 密封源板
2. 店源板

### 后处理

1. 转移至4℃ 12小时（荧光稳定）
2. 紫外照明摄影
3. 图像处理和交付
