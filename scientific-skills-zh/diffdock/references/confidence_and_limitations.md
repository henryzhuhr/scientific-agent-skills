# DiffDock 置信度得分和限制

本文档提供有关解释 DiffDock 置信度得分和了解工具限制的详细指导。

## 置信度得分解释

DiffDock 为每个预测的结合姿势生成置信度得分。该分数表明模型对预测的确定性。

### 分数范围

|分数范围|置信度 |解读 |
|------------------------|--------------------------------|----------------|
| **> 0** |高信心|强有力的预测，可能准确的结合姿势 |
| **-1.5 至 0** |中等信心|合理的预测，可能需要验证|
| **< -1.5** |低信心|不确定的预测，需要仔细验证|

### 关于置信度分数的重要说明

1. **不结合亲和力**：置信度分数反映预测确定性，而不是结合亲和力强度
  - 高置信度 = 模型对结构有信心
  - 不指示强/弱结合亲和力

2. **上下文相关**：应根据系统复杂性调整置信度分数：
  - **较低的期望**：
  - 大配体（> 500 Da）
  - 具有许多链的蛋白质复合物
  - 未结合的蛋白质构象（可能需要构象变化）
  - 未在训练数据

  - **更高的期望**：
  - 药物样小分子（150-500 Da）
  - 单链蛋白质或明确的结合位点
  - 与训练数据中的蛋白质相似（PDBBind，BindingMOAD）

3. **多个预测**：DiffDock 为每个复合体生成多个样本（默认值：10）
  - 查看排名靠前的预测（按置信度）
  - 考虑对相似的姿势进行聚类
  - 多个样本之间的高置信度共识增强了预测

## DiffDock 预测什么

### ✅ DiffDock 预测
- **结合姿势**：蛋白质结合位点中配体的 3D 空间方向
- **置信度分数**：模型对预测的确定性
- **多种构象**：各种可能的结合模式

### ❌ DiffDock 不能预测
- **结合亲和力**：蛋白质-配体相互作用的强度（ΔG、Kd、Ki）
- **结合动力学**：开/关速率、停留时间
- **ADMET 特性**：吸收、分布、代谢、排泄、毒性
- **选择性**：与不同目标的相对结合

## 范围和限制

### 专为
- **小分子对接**：有机化合物通常为100-1000 Da
- **蛋白质目标**：单链或多链蛋白质
- **小肽**：短肽配体（< ~20 个残基）
- **小核酸**：短寡核苷酸

### 不适用于
- **大生物分子**：完整的蛋白质-蛋白质相互作用
  - 使用 DiffDock-PP、AlphaFold-Multimer 或 RoseTTAFold2NA相反
- **大肽/蛋白质**：>20 个残基作为配体
- **共价对接**：不可逆共价键形成
- **金属蛋白特性**：可能无法准确处理金属配位
- **膜蛋白**：未针对膜嵌入进行专门训练蛋白质

### 训练数据注意事项

DiffDock 接受过训练：
- **PDBBind**：多种蛋白质-配体复合物
- **BindingMOAD**：多域蛋白质结构

* *含义**：
- 与训练类似的蛋白质/配体的最佳性能数据
- 可能在以下方面表现不佳：
  - 新型蛋白质家族
  - 不寻常的配体化学类型
  - 训练数据中没有很好地代表变构位点

## 验证和补充工具

### 推荐工作流程

1. **使用 DiffDock 生成姿势**
  - 使用置信度分数进行初始排名
  - 考虑多个高置信度预测

2. **目视检查**
  - 在分子查看器中检查蛋白质-配体相互作用
  - 检查合理性：
  - 氢键
  - 疏水相互作用
  - 立体互补
  - 静电相互作用

3. **评分和细化**（选择一项或多项）：
  - **GNINA**：基于深度学习的评分功能
  - **分子力学**：能量最小化和细化
  - **MM/GBSA 或 MM/PBSA**：结合自由能估计
  - **自由能计算**：FEP 或 TI 以实现准确的亲和力预测

4. **实验验证**
  - 生化测定（IC50、Kd 测量）
  - 结构验证（X 射线晶体学、冷冻电镜）

### 结合亲和力评估工具

DiffDock 应与以下亲和力预测工具结合使用：

- **GNINA**：快速、准确的评分功能
  - Github：github.com/gnina/gnina

  - **AutoDock Vina**：经典对接和评分
  - 网站：vina.scripps.edu

  - **自由能量计算**：
  - OpenMM + OpenFE
  - GROMACS + ABFE/RBFE 协议

- **MM/GBSA 工具**：
  - MMPBSA.py (AmberTools)
  - gmx_MMPBSA

## 性能优化

### 获得最佳结果

1. **蛋白质制备**：
  - 去除远离结合位点的水分子
  - 如果可能，解决缺失的残基
  - 考虑生理pH

2下的质子化状态。 **配体输入**：
 - 使用结构文件时提供合理的3D构象
  - 使用规范SMILES以获得一致的结果
  - 如果需要，使用RDKit进行预处理

3. **计算资源**：
  - GPU 强烈推荐（10-100 倍加速）
  - 首次运行预计算查找表（需要几分钟）
  - 批处理比单个预测更高效

4. **参数调整**：
  - 针对困难情况增加 `samples_per_complex` (20-40)
  - 调整温度参数以实现多样性/准确性权衡
  - 使用预先计算的 ESM 嵌入进行重复预测

## 常见问题和故障排除

### 低置信度分数
- **大/灵活的配体**：考虑分成片段或使用替代方法
- **多个结合位点**：可以以分布式置信度预测多个位置
- **蛋白质灵活性**：考虑使用蛋白质构象的集合

### 不切实际的预测
- **冲突**：可能表明需要蛋白质制备或精炼
- **表面结合**：检查真正的结合位点是否被阻止或不清楚
- **不寻常的姿势**：考虑增加样本以探索更多构象

### 性能缓慢
- **使用GPU**：合理运行时间所必需的
- **预计算嵌入**：重用相同蛋白质的 ESM 嵌入
- **批量处理**：比顺序单独预测更有效
- **减少样本**：降低 `samples_per_complex` 以进行快速筛选
