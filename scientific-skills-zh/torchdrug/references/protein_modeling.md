# 蛋白质建模

## 概述

TorchDrug 为蛋白质相关任务提供广泛支持，包括序列分析、结构预测、性质预测和蛋白质-蛋白质相互作用。蛋白质表示为图表，其中节点是氨基酸残基，边代表空间或顺序关系。

## 可用数据集

### 蛋白质功能预测

* *酶功能：**
- **酶委员会**（17,562个蛋白质）：EC编号分类（7级）
- **β内酰胺酶** （5,864 个序列）：酶活性预测

* *蛋白质特性：**
- **荧光**（54,025 个序列）：GFP 荧光强度
- **稳定性**（53,614 个序列）：热稳定性预测
- **溶解度**（62,478 个序列）：蛋白质溶解度分类
- **二元定位**（22,168 个蛋白质）：亚细胞定位（膜与可溶）
- **亚细胞定位**（8,943 个蛋白质）：10 类定位预测

* *基因本体：**
- **基因本体**（46,796 个蛋白质）：跨生物过程、分子功能和细胞成分的 GO 术语预测

### 蛋白质结构预测

- **折叠**（16,712 个蛋白质）：结构折叠分类（1,195 个类别）
- **二级结构**（8,678 个蛋白质）：3 态或 8 态二级结构预测
- **ContactPrediction** 通过 ProteinNet：残基-残基接触图

### 蛋白质相互作用

* *蛋白质-蛋白质相互作用：**
- **HumanPPI**（1,412 个蛋白质，6,584 个相互作用）：人类蛋白质相互作用网络
- **YeastPPI**（2,018 个蛋白质， 6,451 个相互作用）：酵母蛋白相互作用网络
- **PPIA 亲和力**（2,156 个蛋白质对）：结合亲和力测量

* *蛋白质-配体结合：**
- **BindingDB**（约 150 万条）：综合结合亲和力数据库
- **PDBBind**（20,000 多个复合物）：基于 3D 结构的结合数据
  - 精炼集：高质量晶体结构
  - 核心集：多样化基准set

### 大规模蛋白质数据库

- **AlphaFoldDB**：访问 200M+ 预测的蛋白质结构
- **ProteinNet**：用于结构预测的标准化数据集

## 任务类型

### NodePropertyPrediction

在残基（节点）级别预测属性，例如二级结构

* *用例：**
- 二级结构预测（螺旋、片、卷）
- 残基水平无序预测
- 翻译后修饰位点
- 结合位点预测

### PropertyPrediction

预测蛋白质水平特性

* *用例：**
- 酶功能分类
- 亚细胞定位
- 蛋白质稳定性预测
- 基因本体术语预测

### 交互预测

预测蛋白质对或蛋白质-配体之间的相互作用

* *主要功能：**
- 处理序列和结构输入
- 支持对称（PPI）和不对称（蛋白质-配体）相互作用
- 多种负采样策略

### ContactPrediction

用于预测折叠中残基之间的空间邻近性的专门任务

* *应用：**
- 序列结构预测
- 蛋白质折叠途径分析
- 预测结构的验证

## 蛋白质表示模型

### 基于序列的模型

* *ESM （进化规模建模）：**
- 在 250M 序列上预训练的 Transformer 模型
- 最先进的仅序列任务
- 提供多种尺寸（ESM-1b、ESM-2）
- 捕获进化和结构信息

* *ProteinBERT：**
- BERT 式掩码语言模型
- 在 UniProt 序列上预训练
- 适合迁移学习

* *ProteinLSTM：**
- 用于序列编码的双向 LSTM
- 轻量级且快速
- 良好的序列基线任务

* *ProteinCNN / ProteinResNet：**
- 卷积架构
- 捕获局部序列模式
- 比变压器模型更快

### 基于结构的模型

* *GearNet（几何感知关系图）网络）：**
- 包含 3D 几何信息
- 基于顺序、半径和 K 最近邻的边缘类型
- 基于结构的任务的最先进
- 支持主干和全原子表示

* *蛋白质上的 GCN/GAT/GIN图：**
- 适用于蛋白质的标准 GNN 架构
- 灵活的边缘定义（序列、空间、接触）

* *SchNet：**
- 连续滤波器卷积
- 直接处理 3D 坐标
- 适合结构预测和蛋白质配体结合

### 基于特征的模型

* *统计特征：**
- 氨基酸组成
- 序列长度统计
- 基序计数

* * 理化特征：**
- 疏水性尺度
- 电荷性质
- 二级结构倾向
- 分子量，pI

## 蛋白质图构建

### 边缘类型

* * 连续边缘：**
- 按顺序连接相邻残基
- 捕获一级结构

* *空间边缘：**
- 3D 空间中的 K-最近邻
- 半径截止（例如 10Å 内的 Cα 原子）
- 捕获三级结构

* *接触边缘：**
- 基于重原子距离
- 通常< 8Å阈值

### 节点特征

* *残基身份：**
- 20个氨基酸的单热编码
- 学习嵌入

* *位置信息：**
- 3D坐标（Cα， N, C, O)
- 主干角度（phi、psi、omega）
- 相对空间位置编码

* *理化性质：**
- 疏水性
- 电荷
- 大小
- 二级结构

## 训练工作流程

### 预训练策略

* *自监督预训练：**
- 掩蔽残留预测（如BERT）
- 残基之间的距离预测
- 角度预测（phi、psi、omega）
- 二面角预测
- 接触图预测

* *预训练模型用法：**
```python
from torchdrug import models

# Load pre-trained ESM
model = models.ESM(path="esm1b_t33_650M_UR50S.pt")

# Fine-tune on downstream task
task = tasks.PropertyPrediction(
    model, task=["stability"],
    criterion="mse", metric=["mae", "rmse"]
)
```

### 多任务学习

同时训练多个相关任务：
- 功能、定位和稳定性的联合预测
- 提高泛化和数据效率
- 跨任务共享表示

### 最佳实践

* *仅用于序列任务：**
1. 从预训练的 ESM 或 ProteinBERT
2 开始。以较小的学习率进行微调（1e-5 至 1e-4）
3. 对小数据集使用冻结嵌入 
4. 应用 dropout 进行正则化

* *对于基于结构的任务：**
1. 使用具有多种边缘类型的 GearNet
2. 包括几何特征（角度、二面角）
3. 在大型结构数据库
4上进行预训练。使用数据增强（旋转、裁剪）

* *对于小型数据集：**
1. 从预训练模型 
2 进行迁移学习。具有相关任务的多任务学习
3. 数据增强（序列突变、结构扰动）
4. 强正则化（丢失、权重衰减）

### 酶工程

- 筛选所需的催化特性

### 抗体设计
- 预测结合亲和力
- 优化抗体序列
- 预测免疫原性

### 药物靶点识别
- 预测蛋白质功能
- 识别可成药位点
- 分析蛋白质-配体相互作用

### 蛋白质结构预测
- 根据序列预测二级结构
- 生成三级结构的接触图
- 细化AlphaFold 预测

```python
from torchdrug import data

# Load AlphaFold structure
protein = data.Protein.from_pdb("alphafold_structure.pdb")

# Use in TorchDrug workflows
```

使用ESMFold进行结构预测，然后用TorchDrug模型进行分析。

用Rosetta生成结构，导入到TorchDrug中进行结构分析分析.
