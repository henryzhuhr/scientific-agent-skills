# 逆合成

## 概述

逆合成是规划从目标分子回到市售起始材料的合成路线的过程。 TorchDrug 提供基于学习的逆合成预测工具，将复杂的任务分解为可管理的子任务。

## 可用数据集

### USPTO-50K

来自美国专利文献的逆合成标准基准数据集。

* *统计：**
- 50,017 反应示例
- 单步反应
- 过滤质量和规范化
- 包含用于反应中心识别的原子映射

* *反应类型：**
- 多种有机反应
- 类药物转化
- 常见反应之间的良好平衡类

* *数据分割：**
- 训练：~40k 反应
- 验证：~5k 反应
- 测试：~5k 反应

* *格式：**
- 产品 → 反应物
- SMILES 表示
- 用于训练的原子映射反应

## 任务类型

Torch药物将逆合成分解为多步骤管道：

### 1.中心识别

识别反应中心-在正向反应中形成/断裂哪些键。

* *输入：**产品分子
* *输出：**每个键成为反应中心一部分的概率

* *目的：**
- 定位化学发生的位置
- 指导后续合成子生成
- 大幅减少搜索空间

* *模型架构：**
- 产品上的图形神经网络分子
- 边缘级分类
- 突出反应区域的注意机制

* *评估指标：**
- **Top-K准确度**：前K个预测中的正确反应中心
- **键级F1**：键预测的精度和召回率

### 2. SynthonCompletion

给定产物和识别的反应中心，预测反应物结构（合成）。

* *输入：**
- 产物分子
- 识别的反应中心（断裂/形成的键）

* *输出：**
- 预测的反应物分子（合成子）

* *过程：**
1. 在反应中心
2处断裂键。修改原子环境（化合价、电荷）
3. 确定离去基团和保护基团
4. 生成完整的反应物结构

* *挑战：**
- 多个有效的反应物组
- 立体特异性
- 原子环境变化（杂交、电荷）
- 离去基团选择

* *评估：**
- **精确匹配**：生成的反应物与真实情况完全匹配
- **Top-K 准确度**：正确预测前 K 个反应物
- **化学有效性**：生成的分子有效

### 3. 逆合成（端到端）

将中心识别和合成子完成合并为统一的pipeline.

* *输入：**目标产物分子
* *输出：**反应物组排序列表（合成途径）

* *工作流程：**
1. 识别top-K反应中心
2. 对于每个中心，生成候选反应物
3. 按模型置信度对组合进行排名
4. 商业可用性和可行性过滤器

* *优点：**
- 训练和部署单一模型
- 子任务的联合优化
- 中心识别的错误传播

## 训练工作流程

### 基本Pipeline

```python
from torchdrug import datasets, models, tasks

# Load dataset
dataset = datasets.USPTO50k("~/retro-datasets/")

# For center identification
model_center = models.RGCN(
    input_dim=dataset.node_feature_dim,
    num_relation=dataset.num_bond_type,
    hidden_dims=[256, 256, 256]
)

task_center = tasks.CenterIdentification(
    model_center,
    top_k=3  # Consider top 3 reaction centers
)

# For synthon completion
model_synthon = models.GIN(
    input_dim=dataset.node_feature_dim,
    hidden_dims=[256, 256, 256]
)

task_synthon = tasks.SynthonCompletion(
    model_synthon,
    center_topk=3,  # Use top 3 from center identification
    num_synthon_beam=5  # Beam search for synthon generation
)

# End-to-end
task_retro = tasks.Retrosynthesis(
    model=model_center,
    synthon_model=model_synthon,
    center_topk=5,
    num_synthon_beam=10
)
```

## 模型架构

### 图神经网络

* *RGCN（关系图卷积网络）：**
- 处理多种键类型（单一、双、三、芳香）
- 边缘类型特定转换
- 适合反应中心识别

* *GIN（图同构网络）：**
- 强大的消息传递
- 捕获结构模式
- 非常适合合成子完成

* *GAT（图注意）网络）：**
- 注意力权重突出重要的原子/键
- 可解释的反应中心预测
- 灵活适用于各种反应类型

### 基于序列的模型

* * 变压器模型：**
- SMILES-to-SMILES翻译
- 可以捕获远程依赖关系
- 需要大型数据集

* *LSTM/GRU:**
- 反应物的序列生成
- 自回归解码
- 适合小分子

### 混合方法

组合图形和序列表示：
- 产品的图形编码器
- 反应物的序列解码器
- 两种表示的最佳

## 反应化学注意事项

### 反应类

* *常见转化：**
- C-C 键形成（偶联、加成）
- 官能团相互转化（氧化、还原）
- 杂环合成（环化）
- 保护/脱保护
- 芳香族取代

* *罕见反应：**
- 新颖的偶联方法
- 复杂的重排
- 多组分反应

### 选择性问题

* *区域选择性：**
- 哪个位置对分子起反应
- 需要了解电子学和立体

* *立体选择性：**
- 立体化学控制
- 非对映选择性和对映选择性
- 对于药物合成至关重要

* *化学选择性：**
- 哪个官能团发生反应
- 需要保护基策略

### 反应条件

虽然 TorchDrug 侧重于反应连通性，但请考虑：
- 温度和压力
- 催化剂和试剂
- 溶剂
- 反应时间
- 后处理和纯化

## 多步合成规划

### 单步逆合成

预测目标分子的直接前体。

* *用例：**
- 后期转化
- 简单分子（距离商业化1-2步）
- 初始路线探索

### 多步规划

对每个预测的反应物递归应用逆合成，直到达到商业构建块。

* *树搜索策略：**

* *广度优先搜索：**
- 探索相同深度的所有路线
- 查找最短路线
- 内存密集

* *深度优先搜索：**
- 遵循每条路线完成
- 内存高效
- 可能会错过最佳路线

* *蒙特卡罗树搜索（MCTS）：**
- 平衡探索和利用
- 由模型引导置信度
- 最先进的多步规划

* *A\* 搜索：**
- 启发式搜索
- 针对成本、复杂性或可行性进行优化
- 有效寻找最佳路线

### 路线评分

Rank 合成路线：
1. **步骤数**：越少越好（效率）
2. **收敛与线性**：收敛路线首选
3. **商业可用性**：可购买化合物
4需要多少步骤。 **反应可行性**：每一步起作用的可能性
5. **总体良率**：估计的端到端良率
6. **成本**：试剂、人工、设备
7. **绿色化学**：环境影响、安全

### 停止标准

达到以下条件时停止逆合成：
- **商业化合物**：可从供应商处获得（例如，Sigma-Aldrich、Enamine）
- **构建模块**：标准合成中间体
- **最大深度**：例如 6-10 个步骤
- **低置信度**：模型不确定性太高

## 验证和过滤

### 化学有效性

检查每个预测的反应：
- 反应物是有效分子
- 反应在化学上是合理的
- 原子映射是一致的
- 化学计量平衡

### 合成可行性

* *过滤器：**
- 反应先例（文献示例）
- 官能团兼容性
- 典型反应条件
- 预期产量范围

* *专家系统：**
- 基于规则的验证（例如，ARChem Route Designer）
- 检查不兼容的官能团
- 识别保护/去保护需求

### 商业可用性

* *数据库：**
- eMolecules：10M+商业化合物
- ZINC：附有供应商信息注释
- Reaxys：商业可用建筑块

* *注意事项：**
- 每克成本
- 纯度和质量
- 交货时间
- 最小订购量

## 挑战和未来方向

### 当前限制

- 仅限于单步预测（大多数模型）
- 不考虑反应条件明确
- 立体化学处理具有挑战性
- 罕见反应类型未得到充分体现

### 活跃研究领域

- 端到端多步骤规划
- 反应条件的纳入
- 立体选择性逆合成
- 与集成用于闭环优化的机器人
- 半模板方法（平衡模板和无模板）
- 预测的不确定性量化

### 新兴技术

- 化学大型语言模型（ChemGPT、MolT5）
- 用于路线优化的强化学习
- 用于远程交互的图transformers
- 反应数据库的自监督预训练
