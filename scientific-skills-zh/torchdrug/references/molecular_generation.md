# 分子生成

## 概述

分子生成涉及创建具有所需特性的新颖分子结构。 TorchDrug 支持无条件生成（探索化学空间）和条件生成（优化特定属性）。

## 任务类型

### 自回归生成

通过顺序添加原子和键来逐步生成分子。这种方法可以在生成过程中进行细粒度控制和属性优化。

* *主要特点：**
- 顺序原子键结构
- 支持生成过程中的属性优化
- 可以合并化学有效性约束
- 实现多目标优化

* *生成策略：**
1. **波束搜索**：在每一步保留前 k 个候选者 
2. **采样**：多样性的概率选择
3. **贪婪**：始终选择最高概率的行动

* *属性优化：**
- 基于所需属性的奖励塑造
- 实时约束满足
- 多目标平衡（例如，效力+药物相似性）

### GCPNGeneration（图卷积策略）网络）

使用强化学习生成针对特定属性优化的分子。

* *组件：**
1. **策略网络**：决定采取哪个操作（添加原子，添加键）
2. **奖励功能**：评估生成的分子质量
3. **训练**：带有策略梯度的强化学习

* *优点：**
- 不可微目标的直接优化
- 可以融入复杂的领域知识
- 平衡探索和利用

* *应用：**
- 具有特定目标的药物设计
- 具有属性约束的材料发现
- 多目标分子优化

## 生成模型

### GraphAutoregressiveFlow

通过精确似然计算对分子生成的流模型进行归一化。

* *架构：**
- 耦合层将简单分布转换为复杂分子分布
- 可逆变换实现密度估计
- 支持条件生成

* * 主要功能：**
- 精确似然计算（与 VAE 的近似）似然）
- 稳定训练（与 GAN 的对抗训练相比）
- 通过可逆变换进行高效采样
- 可以生成具有指定属性的分子

* *训练：**
- 分子数据集上的最大似然
- 条件的可选属性预测头Generation
- 通常在 ZINC 或 QM9

 上进行训练**用例：**
- 生成多种类药物分子
- 已知分子之间的插值
- 分子空间的密度估计

## 生成工作流程

### 无条件生成

生成没有特定属性目标的多种分子。

* *工作流程：**
1. 在分子数据集（例如 ZINC250k）
2 上训练生成模型。来自学习分布 
3 的样本。有效性和唯一性的后处理
4. 评估多样性指标

* *评估指标：**
- **有效性**：化学有效分子的百分比
- **唯一性**：有效
- **新颖性**：不在训练集中的百分比
- **多样性**：使用指纹的内部多样性相似性

### 条件生成

生成针对特定性质优化的分子。

* *性质目标：**
- **药物相似性**：LogP、QED、Lipinski五法则
- **可合成性**：SA评分、逆合成可行性
- **生物活性**：预测IC50、结合亲和力
- **ADMET**：吸收、分布、代谢、排泄、毒性
- **多目标**：同时平衡多种特性

* *工作流程：**
1. 结合财产目标定义奖励函数
2. 在属性 
3 上训练 GCPN 或条件流模型。生成具有所需属性范围 
4 的分子。验证生成的分子（在计算机中 → 湿实验室）

### 基于支架的生成

围绕固定支架或核心结构生成分子。

* *应用：**
- 保持核心药效基团的先导优化
- 用于 SAR 研究的 R 基团枚举
- 片段连接和生长

* *方法：**
- 训练期间的掩模支架
- 支架上的条件生成
- 生成后嫁接

### 基于片段的生成

从经过验证的分子构建分子

* *优点：**
- 确保类似药物的子结构
- 减少搜索空间
- 纳入药物化学知识

* *方法：**
- 片段库作为构建块
- 基于词汇Generation
- 与学习链接器进行片段链接

## 属性优化策略

### 单目标优化

最大化或最小化单个属性（例如，结合亲和力）。

* *方法：**
- 定义标量奖励函数
- 使用GCPN与RL训练
- 生成候选者并对其进行排名

* *挑战：**
- 可能牺牲其他重要属性
- 对抗性示例的风险（有效但非类药物）
- 需要约束药物相似性

### 多目标优化

平衡多个竞争目标（例如效力、选择性、可合成性）。

* *加权方法：**
- **线性组合**：w1×prop1 + w2×prop2 + ...
- **帕累托优化**：查找非支配解决方案
- **约束满足**：次要目标的阈值

* *示例目标：**
- 高结合亲和力（目标）
- 低结合亲和力（脱靶）
- 高可合成性（SA 评分）
- 类药物特性(QED)
- 低分子量

* *工作流程：**
```python
from torchdrug import tasks

# Define multi-objective reward
def reward_function(mol):
    affinity_score = predict_binding(mol)
    druglikeness = calculate_qed(mol)
    synthesizability = sa_score(mol)

    # Weighted combination
    reward = 0.5 * affinity_score + 0.3 * druglikeness + 0.2 * (1 - synthesizability)
    return reward

# GCPN task with custom reward
task = tasks.GCPNGeneration(
    model,
    reward_function=reward_function,
    criterion="ppo"  # Proximal policy optimization
)
```

### 基于约束的生成

生成满足硬约束的分子。

* *常见约束：**
- 分子量范围
- LogP 范围
- 可旋转数量bond
- 环计数限制
- 子结构包含/排除
- 合成可及性阈值

* *实现：**
- 生成过程中的有效性检查
- 早期停止无效分子
- 奖励函数中的惩罚项

## 训练注意事项

### 数据集选择

* *ZINC（类药化合物）：**
- ZINC250k：250,000 种化合物
- ZINC2M：200 万种化合物
- 预过滤药物相似性
- 有利于药物发现应用

* *QM9（有机小分子）：**
- 133,885 个分子
- 包括量子特性
- 适用于特性预测模型

* *ChEMBL（生物活性分子）：**
- 数百万种生物活性化合物
- 活性可用数据
- 特定目标生成

* *自定义数据集：**
- 专注于特定化学空间
- 包括专家知识
- 特定领域约束

### 数据增强

* *SMILES增强：**
- 生成同一分子的多个 SMILES
- 帮助模型学习规范表示
- 提高鲁棒性

* *图增强：**
- 随机节点/边缘掩蔽
- 子图采样
- 基序替换

### 模型架构选择

* *对于小分子（<30个原子）：**
- 更简单的架构就足够了
- 更快的训练和生成
- GCN或GIN主干

* *对于类药物分子：**
- 更深的架构（4-6）层）
- 注意机制有帮助
- 考虑分子指纹

* *对于大环/聚合物：**
- 处理更大的图
- 环闭合机制重要
- 远程依赖性

## 验证和过滤

### 计算机验证

* *化学有效性：**
- 化合价规则
- 芳香性规则
- 电荷中性
- 稳定子结构

* * 药物相似过滤器：**
- Lipinski 的五规则
- Veber 的规则规则
- PAINS 过滤器（泛测定干扰化合物）
- BRENK 过滤器（有毒/反应性子结构）

* *可合成性：**
- SA 评分（合成可及性）
- 逆合成预测
- 商业可用性前体

* *性质预测：**
- ADMET 性质
- 毒性预测
- 脱靶结合
- 代谢稳定性

### 排名和选择

* *标准：**
1. 预测的目标亲和力
2. 药物相似度评分
3. 可合成性
4. 新颖性（与已知活性物质不同）
5. 多样性（生成集中）
6. 预测的 ADMET 属性

* *选择策略：**
- 帕累托前沿选择
- 加权评分
- 聚类和代表性选择
- 湿实验室验证的主动学习

## 最佳实践

1. **从简单开始**：从无条件生成开始，然后添加约束
2. **验证化学**：始终检查有效分子和药物相似性
3. **多样化的训练数据**：使用大型、多样化的数据集以实现更好的泛化
4. **多目标**：从
5开始考虑多个属性。 **迭代细化**：生成→验证→使用反馈重新训练
6. **领域专家评审**：在合成
7之前咨询药物化学家。 **基准**：与已知活性物质和随机样品
8进行比较。 **可合成性**：优先考虑实际可以制造的分子
9. **可解释性**：了解模型为何生成某些结构
10. **湿实验室验证**：最终通过实验验证有前途的候选人

## 常见应用

### 药物发现
- 新靶标的先导化合物生成
- 活性支架周围的先导化合物优化
- 生物等排体替代
- 片段精加工

### 材料科学
- 具有目标特性的聚合物设计
- 催化剂发现
- 能量存储材料
- 光伏材料

### 化学生物学
- 探针分子设计
- 降解器（PROTAC）设计
- 分子胶发现

## 与其他工具集成

* *对接：**
- 生成分子→对接目标→使用对接分数重新训练

* *逆合成：**
- 通过合成可访问性过滤生成的分子
- 为最佳候选者规划合成路线

* *属性预测：**
- 使用经过训练的属性预测模型作为奖励函数
- 通过生成和生成进行多任务学习预测

* *主动学习：**
- 生成候选→预测属性→综合最佳→重新训练
