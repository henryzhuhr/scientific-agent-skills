# 数据集参考

## 概述

TorchDrug 提供了跨多个领域的 40 多个精选数据集：分子特性预测、蛋白质建模、知识图推理和逆合成。所有数据集均支持延迟加载、自动下载和可定制的特征提取。

## 数据集用法模式

### 加载数据集

```python
from torchdrug import datasets

# Basic loading
dataset = datasets.BBBP("~/molecule-datasets/")

# With transforms
from torchdrug import transforms
transform = transforms.VirtualNode()
dataset = datasets.BBBP("~/molecule-datasets/", transform=transform)

# Protein dataset
dataset = datasets.EnzymeCommission("~/protein-datasets/")

# Knowledge graph
dataset = datasets.FB15k237("~/kg-datasets/")
```

### 数据分割

```python
# Random split
train, valid, test = dataset.split([0.8, 0.1, 0.1])

# Scaffold split (for molecules)
from torchdrug import utils
train, valid, test = dataset.split(
    utils.scaffold_split(dataset, [0.8, 0.1, 0.1])
)

# Predefined splits (some datasets)
train, valid, test = dataset.split()
```

### 特征提取

* *节点特征（分子）：**
- 原子类型（单热或嵌入）
- 形式电荷
- 杂化
- 芳香性
- 氢原子数
- 手性

* * 边缘特征（分子）：**
- 键类型（单键、双键、三元，芳香族）
- 立体化学
- 缀合
- 环成员

* *节点特征（蛋白质）：**
- 氨基酸类型（一热）
- 理化性质
- 位置序列
- 二级结构
- 溶剂可及性

* *边缘特征（蛋白质）：**
- 边缘类型（顺序、空间、接触）
- 距离
- 角度和二面角

## 选择数据集

### 按任务

* *分子特性预测：**
- 从BBBP或HIV开始（中等大小，明确的任务）
- 使用QM9进行量子特性
- ESOL/FreeSolv进行回归

* *蛋白质功能：**
- EnzymeCommission（明确定义的类）
- GeneOntology（综合注释）

* *药物安全性：**
- Tox21（标准基准）
- ClinTox（临床相关性）

* *基于结构：**
- PDBBind（蛋白质配体）
- ProteinNet（结构预测）

* *知识图：**
- FB15k-237（标准基准）
- Hetionet（生物医学应用）

* *生成：**
- ZINC250k（训练）
- QM9（带属性）

* *逆合成：**
- USPTO-50k（唯一选择）

### 按大小和资源

* *小（<5k，用于测试）：**
- BACE、FreeSolv、ClinTox
- 核心集PDBBind

* *中 (5k-100k)：**
- BBBP、HIV、ESOL、Tox21
- EnzymeCommission、Fold
- FB15k-237、WN18RR

* *大(>100k):**
- QM9、MUV、PCQM4M
- GeneOntology、AlphaFoldDB
- ZINC2M、BindingDB

### 按域

* *药物发现：** BBBP、HIV、Tox21、ESOL、 ZINC
* *量子化学：** QM7、QM8、QM9、PCQM4M
* *蛋白质工程：**荧光、稳定性、溶解度
* *结构生物学：** Fold、PDBBind、ProteinNet、AlphaFoldDB
* *生物医学：** Hetionet、GeneOntology、酶委员会
* *逆合成：** USPTO-50k

## 最佳实践

1. **从小规模开始**：在缩放 
2 之前在小数据集上进行测试。 **支架拆分**：用于实际药物发现评估
3. **平衡指标**：对不平衡数据使用 AUROC + AUPRC
4. **多次运行**：报告多个随机种子
5 的平均值±标准差。 **数据泄露**：小心预训练模型
6. **领域知识**：了解您的预测
7. **验证**：始终使用保留测试装置
8. **预处理**：标准化特征，处理缺失值
