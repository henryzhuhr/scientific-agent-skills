# 可供出版的图形指南

## 核心原则

科学图形必须清晰、准确且易于理解。可供出版的数字遵循以下基本原则：

1. **清晰度**：信息应立即可理解
2. **准确性**：数据表示必须真实且未经操纵
3. **可访问性**：所有读者都应该能够理解图表，包括那些有视力障碍的读者
4. **专业**：干净、抛光的外观，适合同行评审期刊

## 分辨率和文件格式

### 分辨率要求
- **光栅图像（照片、显微镜）**：最终打印尺寸为 300-600 DPI
- **线条艺术和图表**：600-1200 DPI（或矢量）格式）
- **组合数字**：300-600 DPI

### 文件格式
- **矢量格式（图表/绘图的首选）**：PDF、EPS、SVG
  - 无限可扩展，不会造成质量损失
  - 线条文件尺寸较小art
  - 最适合：绘图、图表、示意图

  - **光栅格式**：TIFF、PNG（科学数据绝不使用 JPEG）
  - 用于：照片、显微镜、连续色调图像
  - TIFF：无损，广泛接受
  - PNG：无损，适合网络和补充材料
  - **切勿使用 JPEG**：有损压缩会引入伪影

### 尺寸规格
- **单列**：85-90 毫米（3.35-3.54 英寸）宽度
- **1.5 列**：114-120 毫米（4.49-4.72 英寸）宽度
- **双栏**：174-180 毫米（6.85-7.08 英寸）宽度
- **最大高度**：通常为230-240 毫米（9-9.5 英寸）

## 版式

### 字体指南
- **字体系列**：适用于大多数期刊的无衬线字体（Arial、Helvetica、Calibri）
  - 一些期刊更喜欢特定字体（检查指南）
  - 手稿中所有数字的一致性

- **最终打印尺寸的字体大小**：
  - 轴标签：最小 7-9 pt
  - 刻度标签：最小 6-8 pt
  - 图例：6-8 pt
  - 面板标签（A、B、C）：8-12 pt、粗体
  - 标题：通常在多面板中避免figures

- **字体粗细**：大多数文本的常规粗细；仅用于面板标签的粗体

### 文本最佳实践
- 对轴标签使用句子大小写（“时间（小时）”而不是“时间（小时）”）
- 在括号中包含单位
- 避免使用缩写，除非空间受限（在标题中定义）
- 最终文本不得小于 5-6 磅尺码

## 颜色使用

#### 颜色选择原则
1. **色盲友好**：~8％的男性有色觉缺陷
  - 避免红色/绿色组合
  - 使用蓝色/橙色、蓝色/黄色，或添加纹理/图案
  - 使用色盲模拟器

2进行测试。 **有目的的颜色**：颜色应该传达意义，而不仅仅是美观
 - 使用颜色来区分类别或突出关键数据
  - 保持图形之间的一致性（相同处理=相同颜色）

3. **打印注意事项**：
  - 打印时与屏幕上的颜色可能会有所不同
  - 打印时使用 CMYK 色彩空间，数字时使用 RGB
  - 确保足够的对比度（尤其是灰度转换）

### 推荐调色板
- **定性（类别）**：ColorBrewer、Okabe-Ito调色板
- **顺序（从低到高）**：Viridis、Cividis、Blues、Orange
- **发散（负到正）**：RdBu、PuOr、BrBG（确保色盲安全）

### 灰度兼容性
- 所有数字都应可在灰度
- 使用不同的线条样式（实线、虚线、点线）和标记
- 向条形和区域添加图案/阴影

## 布局和构图

### 多面板图
- **面板标签**：在左上角使用粗体大写字母（A、B、C）
- **间距**：面板之间有足够的空白
- **对齐**：尽可能沿边缘或轴对齐面板
- **尺寸**：相关面板应具有一致的尺寸
- **排列**：逻辑流程（从左到右，从上到下）

### 绘图元素

#### 轴
- **轴线**：0.5-1 pt 厚度
- **刻度线**：一致向内或向外指向
- **刻度频率**：足以读取值，不杂乱（通常为 4-7 个主要刻度）
- **轴标签**：所有图都需要；状态单位
- **轴范围**：条形图从零开始（除非科学上不合适）

#### 线条和标记
- **线宽**：数据线为1-2 pt；参考线 0.5-1 pt
- **标记尺寸**：3-6 pt，大于线宽
- **标记类型**：区分多个系列（圆形、正方形、三角形）
- **误差线**：0.5-1 pt 宽度；如果合适，请包括大写字母

#### 图例
- **位置**：如果空间允许，则在绘图区域内，否则在外部
- **框架**：可选；；如果使用，细线（0.5 pt）
- **顺序**：数据出现的匹配顺序（从上到下或从左到右）
- **内容**：简洁描述；标题中的完整详细信息

### 空白和边距
- 删除图周围不必要的空白
- 保持一致的边距
- matplotlib中的`tight_layout()`或`constrained_layout=True`

## 数据表示最佳实践

### 统计Rigor
- **误差线**：始终显示不确定性（SD、SEM、CI）并在标题中注明 
- **样本大小**：在图或标题中注明 n 
- **显着性**：清楚地标记统计显着性（*、**、***）
- **重复**：尽可能显示单个数据点，而不仅仅是摘要统计

### 适当的图表类型
- **条形图**：比较离散类别；始终从零开始 y 轴
- **线图**：时间序列或连续关系
- **散点图**：变量之间的相关性；如果合适的话添加回归线
- **箱线图**：分布比较；显示离群值
- **热图**：矩阵数据、相关性、表达模式
- **小提琴图**：分布形状比较（优于双峰数据的箱线图）

### 避免扭曲
- **无 3D 效果**：扭曲值的感知
- **没有不必要的装饰**：否渐变、阴影或图表垃圾
- **一致的比例**：对可比较的面板使用相同的比例
- **无截断轴**：除非明确指示并经过科学论证
- **线性与对数比例**：选择适当的比例；始终标记清楚

## 可访问性

### 色盲注意事项
- 使用在线模拟器进行测试（例如Coblis、Color Oracle）
- 除了颜色之外还使用图案/纹理
- 如果需要，在补充材料中提供替代表示

### 视觉损伤
- 元素之间的高对比度
- 足够粗的线条（最小0.5 pt）
- 清晰、整洁的布局

### 数据可用性
- 在补充材料中包含数据表
- 提供源数据文件graphs
- 考虑在线补充材料的交互式图形

## 要避免的常见错误

1. **字体太小**：最终打印尺寸 
2 时无法读取文本。 **低分辨率**：像素化或模糊的图像
3. **图表垃圾**：不必要的网格线、3D 效果、装饰
4. **颜色选择不佳**：红/绿组合，低对比度
5. **缺少元素**：没有轴标签，没有单位，没有误差线
6. **样式不一致**：图形内或图形之间的字体/大小不同
7. **数据失真**：截断的轴、不适当的比例、3D 效果
8. **JPEG 压缩**：文本和线条周围的伪影
9. **信息太多**：将太多数据系列塞进一张图中
10. **无法访问的图例**：导出后图例超出图形边界

## 图形检查表

提交前，请验证：

- [ ]分辨率符合期刊要求（光栅为300+ DPI）
- [ ]文件格式可接受（绘图为矢量，图像为TIFF/PNG）
- [ ]图形尺寸匹配期刊规格
- [ ]所有文本均以最终尺寸可读（最小 6-7 pt）
- [ ]字体一致并嵌入（适用于 PDF/EPS）
- [ ]颜色适合色盲人士 
- [ ]图形可以灰度解释 
- [ ]所有轴标有单位
- [ ]存在误差线或不确定性指标
- [ ]标记统计显着性（如果适用）
- [ ]面板标签存在且一致（A、B、C）
- [ ]图例清晰完整
- [ ]没有图表垃圾或不必要的图表elements
- [ ]文件命名遵循期刊约定
- [ ]图标题很全面
- [ ]源数据可用

## 期刊特定注意事项

请始终查阅特定期刊的作者指南。常见的变体包括：

- **自然期刊**：RGB，最低 300 DPI，特定尺寸要求
- **科学**：EPS 或高分辨率 TIFF，特定字体要求
- **Cell Press**：PDF 或 EPS 首选，Arial 或 Helvetica 字体
- **PLOS**：TIFF 或 EPS，特定色彩空间要求
- **ACS 期刊**：应用程序文件（AI、EPS）或高分辨率 TIFF

 有关主要出版商的详细规格，请参阅 `journal_requirements.md`。
