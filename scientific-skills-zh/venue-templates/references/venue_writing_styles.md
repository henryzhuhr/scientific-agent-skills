# 场所写作风格：大师指南

本指南概述了不同出版场所的写作风格如何变化。了解这些差异对于在每个地点撰写读起来像真实出版物的论文至关重要。

* *最后更新**：2024

- --

## 风格谱

科学写作风格存在于从**广泛访问**到**深入的范围内技术**：

```
Accessible ◄─────────────────────────────────────────────► Technical

Nature/Science    PNAS    Cell    IEEE Trans    NeurIPS    Specialized
   │                │       │         │            │         Journals
   │                │       │         │            │            │
   ▼                ▼       ▼         ▼            ▼            ▼
General           Mixed   Deep     Field      Dense ML      Expert
audience         depth  biology   experts    researchers    only
```

## 快速样式参考

|场地类型 |观众|语气|语音 |抽象风格|
|------------|---------|-----|--------|----------------|
| **自然/科学** |受过教育的非专业人士 |平易近人、引人入胜|主动，第一人称OK |段落流畅，没有行话|
| **细胞压榨** |生物学家|机械、精准 |混合|摘要 + eTOC 简介 + 亮点 |
| **医学（新英格兰医学杂志/柳叶刀）** |临床医生|注重证据 |正式|结构化（背景/方法/结果/结论）|
| **PLOS/BMC** |研究人员|标准学术|中性| IMRaD 结构化或流动 |
| **IEEE/ACM** |工程师/CS |技术|被动常见 |简洁、技术性|
| **机器学习会议** |机器学习研究人员 |技术密集 |混合|前期数字、关键结果 |
| **NLP 会议** | NLP 研究人员 |技术|多种多样 |以任务为中心的基准 |

## 高影响力期刊（自然、科学、细胞）

### 核心理念

高影响力多学科期刊优先考虑**广泛意义**而不是技术深度。问题不是“这在技术上合理吗？”但是“为什么这个领域之外的科学家应该关心？”

### 关键写作原则

1. **从大局开始**：首先解释为什么这对科学/社会很重要
2. **尽量减少行话**：定义专业术语；更喜欢常用词
3. **讲一个故事**：结果应该以叙述的方式流动，而不是数据转储
4. **强调影响**：这对我们的理解有何改变？
5. **可访问的图形**：原始数据图的示意图和模型

### 结构差异

* *自然/科学**与**专业期刊**：

|元素|自然/科学 |专业期刊|
|---------|-------------|------------------------|
|简介 | 3-4 段，宽泛→具体 |广泛的文献综述|
|方法 |通常是补充或简短|正文中有完整详细信息 |
|结果 |按发现/故事组织 |通过实验整理|
|讨论 |首先是影响，然后是注意事项 |文献详细对比|
|数字|有价值的概念原理图|强调原始数据 |

### 示例：相同的发现，不同的风格

* *自然风格**：
> “我们发现蛋白质 X 作为一个分子开关，控制发育过程中的细胞命运决定，解决了有关干细胞如何选择其命运的长期存在的问题。”

* *专业期刊风格**：
> “使用在小鼠胚胎干细胞 (mESC)中进行 CRISPR-Cas9 敲除，我们证明蛋白 X（由基因 ABC1 编码）通过直接启动子结合调节多能性因子 Oct4、Sox2 和 Nanog 的表达，ChIP-seq 分析证实了这一点（n=3 个生物重复，FDR < 0.05）。“

## 医学期刊 (NEJM, Lancet、JAMA、BMJ)

### 核心理念

医学期刊优先考虑**临床相关性**和**患者结果**。每一个发现都必须联系实践。

### 关键写作原则

1. **以患者为中心的语言**：“接受治疗 X 的患者”而不是“治疗 X 受试者”
2. **证据强度**：基于研究设计
3的谨慎对冲。 **临床可操作性**：“那又怎样？”对于执业医师
4. **绝对数字**：报告绝对风险降低，而不仅仅是相对
5. **结构化摘要**：需要带有标记部分

### 结构化摘要格式（医学）

```
Background: [1-2 sentences on problem and rationale]

Methods: [Study design, setting, participants, intervention, outcomes, analysis]

Results: [Primary outcome with confidence intervals, secondary outcomes, adverse events]

Conclusions: [Clinical implications, limitations acknowledged]
```

### 证据语言约定

|研究设计|合适的语言|
|----------|------------------------|
|随机对照试验| “治疗 X 通过...降低死亡率”|
|观察| “治疗 X 与降低死亡率相关……”|
|案例系列| “这些发现表明治疗 X 可能......”|
|病例报告| “这个案例说明治疗 X 可以......”|

## ML/AI 会议（NeurIPS、ICML、ICLR、CVPR）

### 核心理念

ML 会议重视**新颖性**、**严谨的实验**和**可重复性**。重点是用经验证据推进最先进的技术。

### 关键写作原则

1. **贡献项目符号**：简介中的编号列表准确说明了新增内容
2. **基线至关重要**：与强大的近期基线 
3 进行比较。 **预期的消融**：显示方法的哪些部分很重要
4. **再现性**：种子、超参数、计算要求
5. **限制部分**：诚实的致谢（越来越需要）

### 介绍结构（ML会议）

```
[Paragraph 1: Problem motivation - why this matters]

[Paragraph 2: Limitations of existing approaches]

[Paragraph 3: Our approach at high level]

Our contributions are as follows:
• We propose [method name], a novel approach to [problem] that [key innovation].
• We provide theoretical analysis showing [guarantees/properties].
• We demonstrate state-of-the-art results on [benchmarks], improving over [baseline] by [X%].
• We release code and models at [anonymous URL for review].
```

### 抽象风格（ML会议）

ML摘要是**密集且以数字为中心**：

> “我们提出了 TransformerX，一种用于远程序列建模的新颖架构，可在保持表达能力的同时实现 O(n log n)复杂度。在 Long Range Arena 基准测试中，TransformerX 实现了 86.2% 的平均准确率，优于 Transformer (65.4%)和 Performer (78.1%)。在语言建模方面，TransformerX 使用少了 40% 的参数来匹配 GPT-2 困惑度 (18.4)。我们提供的理论分析表明， TransformerX 可以近似任何连续的序列到序列函数。”

### 实验部分期望

1. **数据集**：标准基准测试，数据集统计
2. **基线**：最近的强大方法，公平比较
3. **主要结果表**：清晰、全面
4. **消融研究**：系统地删除/修改组件
5. **分析**：错误分析、定性示例、失败案例
6. **计算成本**：训练时间、推理速度、内存

## CS 会议（ACL、EMNLP、CHI、SIGKDD）

### ACL/EMNLP (NLP)

- **以任务为中心**：明确的问题定义
- **基准重**：标准数据集（GLUE、SQuAD 等）
- **错误分析有价值**：它在哪里失败？
- **人类评估**：通常与自动指标一起预期
- **道德考虑**：偏见、公平性、环境成本

### CHI（人机交互）

- **以用户为中心**：关注人类，而不仅仅是技术
- **研究设计细节**：参与者招募，IRB 批准
- **定性接受**：访谈研究，民族志有效
- **设计含义**：从业者的具体要点
- **可访问性**：考虑不同的用户人口

### SIGKDD（数据挖掘）

- **强调可扩展性**：处理大数据
- **实际应用**：有价值的行业数据集
- **效率指标**：时间和空间复杂度
- **方法或应用程序的新颖性**：两条路径都有效

## 在场地类型之间适应

### 期刊→机器学习会议

将期刊论文转换为会议格式时：

1. **精简介绍**：去除大量背景
2. **添加贡献列表**：显式枚举贡献
3. **重组结果**：组织为实验，添加 ablations
4. **删除单独的讨论**：简要整合解释
5. **添加再现性部分**：种子、超参数、代码

### ML Conference → Journal

当将会议论文扩展到期刊时：

1. **拓展相关工作**：综合文献综述
2. **详细方法**：完整算法描述
3. **更多实验**：附加数据集，分析
4. **扩展讨论**：影响、限制、未来工作
5. **附录→正文**：将重要细节向上移动

### 专业→高影响力期刊

当从专门场所定位自然/科学/细胞时：

1. **具有重要意义的领导**：为什么这很重要？
2. **减少 80% 的行话**：替换技术术语
3. **添加概念图**：原理图、模型，而不仅仅是数据
4. **故事驱动的结果**：叙事流程，而不是逐个实验
5. **扩大讨论**：子领域之外的含义

## 语音和语气指南

### 主动语音与被动语音

|地点 |偏好 |示例 |
|-------|------------|---------|
|自然/科学 |积极鼓励| “我们发现……”|
|细胞|混合| “我们的结果表明......” |
|医疗|被动常见| “患者被随机分配到……”|
| IEEE |被动传统| “该算法已实现...”|
|机器学习会议 |活跃首选 | “我们提出了一种方法......” |

### 第一人称用法

|地点 |第一人称|示例 |
|-------|-------------|---------|
|自然/科学 |是的（我们）| “我们表明......”|
|细胞|是的（我们）| “我们发现……”|
|医疗|有时| “我们进行了试验……”|
| IEEE |不太常见 |更喜欢“本文呈现......”|
|机器学习会议 |是的（我们）| “我们介绍...” |

### 对冲和确定性

|声明强度|语言 |
|---------------|---------|
|强| “X导致Y”（仅具有因果证据）|
|中等| “X 与 Y 相关”/“X 导致 Y”|
|暂定| “X 可能对 Y 做出贡献”/“X 表明...”|
|投机| “有可能 X...”/“一种解释是...” |

## 场地常见风格错误

### 自然/科学提交

❌ 技术性太强：“我们使用带有靶向外显子 3 的 sgRNA 的 CRISPR-Cas9...”
✅ 可访问：“使用基因编辑技术，我们禁用了该基因...”

❌干巴巴的开头：“蛋白质X参与细胞信号传导...”
✅引人入胜的开头：“细胞如何决定它们的命运？我们发现...”

### ML会议提交的内容

❌模糊的贡献：“我们提出了一种新方法X"
✅ 具体贡献：“我们提出方法 Y，在基准 W 的基础上实现 Z% 的改进”

❌ 缺失消融：仅显示完整方法结果
✅ 完整：显示每个组件贡献的表格

### 医学期刊提交

❌ 缺失绝对数字：“风险降低 50%”
✅ 完整：“相对降低 50%（ARR 2.5%，NNT 40）”

❌ 观察数据的因果语言：“治疗导致改善”
✅ 适当：“治疗与改进"

## 提交前的快速检查清单

### 所有场地
- [ ]抽象匹配场地风格（流畅与结构化）
- [ ]适合观众的声音/语气
- [ ]行话级别适当
- [ ]数字匹配场地期望
- [ ]引文风格正确

### 高影响力期刊（自然/科学/细胞）
- [ ]第一段中明确的广泛意义
- [ ]非专业人士可以理解摘要
- [ ]故事驱动的结果叙述
- [ ]概念性包括数字
- [ ]强调的含义

### ML 会议
- [ ]介绍中的贡献列表
- [ ]包括强基线
- [ ]呈现消融研究
- [ ]再现性信息完整
- [ ]承认的局限性

### 医学期刊
- [ ]结构化摘要（如果需要）
- [ ]以患者为中心的语言
- [ ]适当的证据强度
- [ ]报告的绝对数字
- [ ] CONSORT/STROBE合规性
