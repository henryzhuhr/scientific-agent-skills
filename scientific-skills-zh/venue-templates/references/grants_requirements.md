# 拨款提案要求

主要联邦和私人基金会拨款计划的综合要求和格式指南。

* *最后更新**：2024

- --

## NSF（国家科学基金会）

### 概述

* *机构**：国家科学基金会
* *典型奖项**：每年 10 万-50 万美元，3-5 年 
* *成功率**：20-25%（因项目而异） 
* *评审标准**：智力优点 + 更广泛的影响（同等权重）

- --

### NSF 标准拨款提案

* *页面限制（NSF PAPPG - 提案和奖励政策和程序指南）**：

|组件|页数限制 |字体|间距|
|---------|------------|-----|---------|
| **项目概要** | 1 页 |任何可读的，10pt+ |任意|
| **项目描述** | 15 页 | Times Roman 11pt 或类似 |单|
| **引用的参考文献** |无限制|泰晤士罗马 11pt |单|
| **传记概要** |每人 3 页 |泰晤士罗马 11pt |单|
| **预算理由** | 3-5 页 |任何可读的 |任意|
| **当前和待定的支持** |无限制|泰晤士罗马 11pt |单|
| **设施、设备** | 2 页 |任何可读的 |任意|
| **数据管理计划** | 2 页 |任何可读的 |任何 |

* *边距**：所有边均为 1 英寸（2.54 厘米）（严格执行）

- --

### NSF 项目摘要（1 页）

* *必填部分**（明确标记）：

1. **概述**（1-2 段）
  - 研究活动的简明描述
  - 目标和方法

2. **智力优点**（1 段）
  - 项目如何推进知识
  - 创新和变革潜力
  - 研究团队的资格

3. **更广泛的影响**（1 段）
  - 对社会的益处
  - 扩大参与
  - 传播和推广

* *格式**：可以是整页文本或分段 
  * *受众**：非专家（广泛的科学界）

* *模板**：`assets/grants/nsf_project_summary.tex`

- --

### NSF项目描述（15页）

* *典型结构**：

1. **介绍/背景**（2-3页）
  - 知识现状
  - 研究差距
  - 初步工作/可行性
  - 团队资格

2. **研究计划**（8-10页）
  - 目标和假设
  - 方法和途径
  - 时间表和里程碑
  - 预期结果

3. **更广泛的影响**（1-2 页）
  - 教育活动
  - 扩大参与（代表性不足的群体）
  - 传播（出版物、会议、公众宣传）
  - 社会效益

4. **先前 NSF 支持的结果**（1 页，如果适用）
  - 如果 PI 在过去 5 年内获得过 NSF 支持，则需要 
  - 先前工作的智力优点和更广泛的影响 
  - 先前 NSF 资助的出版物

  * *关键要求**：
  - 综合智力优点和更广泛的影响全文
- 允许使用图表（计入页数限制）
- 引用参考文献（使用参考文献引用部分）

* *模板**：`assets/grants/nsf_proposal_template.tex`

- --

### NSF 传记草图（3 页）

* *必填章节**：
1. **专业准备**：机构、学位、领域
2. **约会**：当前和以前的职位
3. **产品**：最多 5 个最相关的产品，最多 5 个其他重要产品
  - 可以包括出版物、数据集、软件、专利
4. **协同活动**：最多 5 个超出研究影响的示例

* *格式**：
- 必须使用 NSF 模板（SciENcv 或 NSF 批准的格式）
- 不再使用“出版物”，而是“产品”

- --

### NSF Broader影响

* *NSF 认可类别**（证明 ≥1）：
1. **在促进教学/学习的同时推进发现**
2. **扩大代表性不足群体的参与**
3. **广泛传播**以增强科学/技术理解
4. **对社会的效益**（经济、健康、环境、国家安全）
5. **发展科学劳动力**和基础设施

* *最佳实践**：
- 具体说明可衡量的结果
- 解释如何评估活动
- 与研究相结合（不要视为“附加”）
- 产生更广泛影响的预算活动

* *示例**：
- K-12 外展计划
- 课程开发
- 培训代表性不足的学生
- 公共科学传播
- 开源软件开发

- --

### NSF预算

* *典型类别**：
- **高级人员**：PI、共同PI（工作量百分比、工资）
- **其他人员**：博士后、研究生、本科生
- **附带福利**：机构费率
- **设备**：项目>$5,000
- **旅行**：国内和国外
- **参与者支持**：研讨会、会议（单独类别）
- **其他直接成本**：材料、出版物、子奖项
- **间接成本**：机构 F&A 费率

* *预算理由**：解释每项的需要

- --

### NSF数据管理计划（2页）

* *所需内容**：
- 产生的数据类型
- 数据格式和元数据标准
- 访问和共享政策
- 重用和重新分发
- 归档和保存计划

* *可接受的方法**：
- 存放在特定领域的存储库中
- 机构存储库
- 根据请求提供数据（带有限制理由）

- --

### NSF 审查流程

* *审核标准**（同等权重）：

1. **智力优点**：
  - 推进知识的潜力是什么？
  - 构思和组织如何？
  - PI和团队的资格？
  - 资源的可用性？

2. **更广泛的影响**：
  - 对社会有哪些潜在好处？
  - 实现更广泛影响的适合程度如何？

  * *小组审查**：由专家小组审查的提案 
  * *时间表**：从截止日期到授予决定通常需要 6 个月

- --

- **项目摘要**：`assets/grants/nsf_project_summary.tex`
- **传记草图**：使用NSF SciENcv或模板

* *资源**：
- NSF PAPPG： https://www.nsf.gov/publications/pub_summ.jsp?ods_key=pappg

## NIH（美国国立卫生研究院）

### 概述

* *机构**：美国国立卫生研究院
* *资助机制**：
- **R01**：研究项目补助金（最常见）
- **R21**：探索性/发展性研究补助金
- **K 奖**：职业发展奖
* *成功率**：10-20%（因机构和机构而异）机制）

- --

### NIH R01研究资助

* *页数限制**（研究策略）：

|组件|页数限制 |字体|间距 |
|---------|------------|------|---------|
| **具体目标** | 1 页 | Arial 至少 11 磅 |任意|
| **研究策略** | 12 页 | Arial 至少 11 磅 |最小边距 0.5 英寸 |
| - 意义| 12 的一部分 | | |
| - 创新| 12 的一部分 | | |
| - 方法| 12 的一部分 | | |
| **参考书目** |无限制|宋体 11pt | |
| **传记概要** |每人 5 页 |宋体 11pt | |

* *边距**：最小 0.5 英寸（所有边） 
* *纸张尺寸**：Letter（8.5 × 11 英寸）

- --

### NIH 特定目标页面（1 页）

* *最关键组件**

* *结构**（推荐）：

1. **开头段落**（2-3句话）
  - 钩子：问题的意义
  - 间隙：什么是未知的

2. **长期目标**（1 句话）
  - 总体研究愿景

3. **目标**（1-2 句话）
  - 该提案将实现什么
  - 中心假设

4. **基本原理**（2-3 句话）
  - 为什么您期望成功
  - 支持假设的初步数据

5. **具体目标**（典型的 3 个目标）
  - **目标 1**：[标题]。 [1-2句话描述。工作假设。预期结果。]
  - **目标 2**：[标题]。 [1-2句话描述。工作假设。预期结果。]
  - **目标 3**：[标题]。 [1-2句话描述。工作假设。预期结果。]

6. **回报段落**（2-3句话）
  - 影响和意义
  - 创新
  - 未来方向

  * *最佳实践**：
  - 清晰、引人注目的叙述
  - 明确陈述假设
  - 解释预期结果
  - 展示创新和影响

* *模板**：`assets/grants/nih_specific_aims.tex`

- --

### NIH 研究策略（12 页）

* *必填部分**：

#### 1. 意义（通常为 2-3 页）
- **重要性**：进展
- **知识差距**：未知的内容
- **影响**：项目如何推进该领域
- **严谨性**：科学前提/先前工作
- **参考文献**：引用关键文献

#### 2. 创新（通常为1-2）页）
- **新颖**：新概念、方法、方法
- **挑战范式**：转变思维
- **精炼/新方法**：技术创新
- **新颖应用**：以新方式使用现有工具

#### 3. 方法（通常 7-9 页）
* *对于每个目标**：
- **基本原理**：为什么这个目标
- **实验设计**：详细方法
- **预期结果**：结果意味着什么
- **潜在问题和替代方案**：缓解措施策略
- **严谨性和再现性**：控制、复制、统计
- **时间线**：每个目标完成时

* *其他方法内容**：
- 初步数据（对R01至关重要）
- 样本量的功效分析
- 统计分析计划
- 引用的先前研究的严谨性

- --

### NIH传记草图（5页）

* *章节**（NIH格式）：
1. **个人陈述**（4句话解释为什么你适合）
2. **职位、荣誉和科学任命**
3. **对科学的贡献**（最多 5 个贡献，每个最多 4 个 pub）
4. **研究支持**（当前和已完成的拨款，重叠检查）

* *格式**：必须使用 NIH 模板（可填写 PDF 或格式页面）

- --

### NIH 审查标准

* *评分标准**（1-9 等级， 1=最佳）：
1. **重要性**：重要性、影响
2. **研究者**：资格、跟踪记录
3. **创新**：新颖的概念、方法
4. **方法**：可行性、严谨性、设计
5. **环境**：机构支持、资源

* *其他考虑因素**（未评分但已注明）：
- 脊椎动物
- 生物危害
- 人类受试者保护
- 纳入妇女、少数民族、儿童
- 预算适当性

* *总体影响分数**：1-9（综合所有标准）

- --

### NIH R21（探索性资助）

* *与 R01** 的主要区别**：
- **研究策略**：6 页（相对于 12 页） R01)
- **持续时间**：最长 2 年
- **预算**：2 年总成本 275,000 美元
- **初步数据**：不需要（探索性）
- **目的**：高风险、高回报项目；新方向

* *何时选择 R21 与 R01**：
- R21：早期，初步数据有限，高风险
- R01：已建立的研究线，强有力的初步数据

- --

### NIH K 奖（职业发展）

* *机制**：
- **K01**：指导研究科学家发展奖
- **K08**：指导临床科学家研究职业发展奖
- **K23**：指导以患者为导向的研究职业发展奖
- **K99/R00**：独立之路奖（博士后到教师）

* *关键组成部分**：
- **职业发展计划**：培训目标、时间表
- **研究计划**：6-12页（取决于机制）
- **导师**：支持信、指导计划
- **机构承诺**：环境、资源
- **受保护时间**：典型的 75% 研究工作

- --

### NIH 预算

* *模块化与详细**：
- **模块化**：每年 ≤ 25 万美元直接成本（25 万增量）
- **详细**：每年> 25 万美元直接成本年

* *模块化预算**：仅需要人员、财团、设备的预算理由>$25K

* *预算期限**：逐年（R01通常为5年）

- --

- **具体目标**：`assets/grants/nih_specific_aims.tex`

## DOE（能源部）能源）

### 概述

* *机构**：美国能源部 
* *办公室**：
- **科学办公室**：基础研究（BES、BER、ASCR、NP、HEP、FES）
- **ARPA-E**：高风险、高回报能源技术
- **EERE**：能源效率和可再生能源

* *典型奖励**：每年 20 万-100 万美元，3 年 
* *成功率**：10-30%（因项目而异）

- --

### DOE 科学提案办公室 

* *页数限制**（典型，因 FOA 而异）：

|组件|页数限制 |格式 |
|-----------|------------|--------|
| **项目叙述** | 10-20 页 | 11 磅，1 英寸边距 |
| **参考文献** | 无限制 | |
| **预算理由** | 3-5 页 | |
| **传记草图** | 每页 2-3 页 | |
| **当前和待定** | 无限制 | |
| **设施和资源** | |
| **数据管理计划** | |

- --

### DOE 项目叙述结构

* *：

1. **背景和意义**（2-3 页）
相关性
 - 知识现状
  - 研究需求

2. **初步工作**（1-2页）
  - 团队资格
  - 相关先前结果

3. **研究计划**（10-15页）
  - **目标**：明确的目标
  - **技术方法**：详细方法
  - **里程碑和可交付成果**：具体的、可衡量的
  - **时间表**：常见的甘特图
  - **团队和管理**：角色、协作

4. **更广泛的影响**（1-2）页）
  - 劳动力发展
  - 技术转让潜力
  - 出版物和传播

- --

### DOE特定要求

* *能源相关性**：必须明确与DOE使命相关
- 基础科学：对能源的基本了解应用
- 应用：能源效率、可再生能源、电网、存储

* *技术就绪水平 (TRL)**：通常需要指定
- **TRL 1-3**：基础研究、概念验证
- **TRL 4-6**：组件/子系统验证
- **TRL 7-9**：系统演示、部署

* *国家实验室合作**：鼓励
- 包括实验室科学家作为联合PI或合作者
- 实验室合作信

* *成本分摊**：有时需要（检查FOA）
- 可以是实物（设备、时间）
- 必须是记录

- --

### DOE预算考虑因素

* *允许成本**：
- 人员（工资、福利）
- 设备
- 旅行（特别是到DOE国家实验室）
- 材料和用品
- 分包合同
- 间接成本（协商的F&A费率）

* *不允许**：
- 施工
- 娱乐
- 一些间接成本（取决于机构类型）

## DARPA（国防高级研究计划局）

### 概述

* *机构**：国防高级研究计划局 (DoD) 
* *使命**：高风险、高回报的研究国家安全 
* *典型奖励**：每年 50 万-500 万美元，2-4 年 
* *成功率**：5-15%（竞争激烈）

- --

### DARPA BAA（广泛机构公告）响应

* *页面限制**（典型，因情况而异） BAA):

|组件|页数限制 |格式|
|---------|------------|--------|
| **技术和管理建议** | 20-25 页 | 12 点，1 英寸边距 |
| **成本提案** | 单独卷 | |

- --

### DARPA 技术提案结构

* *关键部分**：

1. **执行摘要**（1 页）
  - 愿景和影响
  - 技术方法概述
  - 团队资格

2. **Heilmeier 教义问答**（1-2 页）
 DARPA 要求回答以下问题：
 - **你想做什么？** 不用行话阐明目标
  - **今天是如何完成的？局限性？** 目前的做法和缺点
  - **您的方法有什么新内容？** 创新
  - **谁在乎？** 成功后的影响
  - **如果成功，会产生什么变化？** 转型
  - **有什么风险？** 技术风险和缓解
  - **需要多少钱？** 预算概述
  - **需要多长时间？** 时间表
  - **期中考试和期末考试是什么？** 成功的里程碑

3. **技术方法**（10-15页）
  - 详细技术计划
  - 任务分解
  - 风险缓解
  - 创新理由

4. **管理计划**（2-3页）
  - 团队组织
  - 关键人员角色
  - 协作方法
  - 里程碑时间表（甘特图）

5. **能力和经验**（2-3页）
  - 团队资格
  - 相关设施和设备
  - 过去的类似项目

6. **过渡计划**（1-2 页）
  - DoD 过渡的路径
  - 确定的最终用户
  - 技术转让方法

- --

### DARPA 特定注意事项

* *与项目经理 (PM)的接触**：
- **强烈鼓励**在提交前联系PM
- 讨论想法与计划目标的一致性
- PM可以提供有关方法的反馈

* *变革性影响**：
- 必须展示“改变游戏规则”影响的潜力
- 不是渐进式改进

* *技术风险**：
- 高风险方法可接受（甚至鼓励）
- 必须显示缓解策略

* *国家安全相关性**：
- 与国防应用的明确连接
- 两用（民用+军用）通常很有价值

* *成功指标**：
- 可量化的里程碑
- “进行/不进行”决策点

- --

### DARPA 预算

* *全部成本核算**：需要详细说明
- **劳动力**：每小时费率，每项任务的小时数
- **材料**：逐项
- **设备**：购买理由
- **旅行**：有目的的具体旅行
- **分包合同**：详细的分包合同预算
- **间接成本**：协商费率

  * *成本现实**：预算必须符合建议的实际情况工作

## 一般最佳实践

### 撰写有效的提案

1. **尽早开始**：最少 2-3 个月
2. **仔细阅读电话**：严格遵循
3要求。 **了解你的审稿人**：为专家受众撰写
4. **讲故事**：逻辑清晰、引人入胜的叙述
5. **具体**：具体目标、方法、结果
6. **显示可行性**：初步数据，专业知识
7. **解决弱点**：承认并减轻风险

### 要避免的常见错误

1. **目标模糊**：“理解X”→“确定X是否导致Y”
2. **缺乏创新**：增量与变革
3. **更广泛的影响较差** (NSF)：通用、未集成的
4. **具体目标薄弱**（NIH）：最关键的页面！
5. **缺少初步数据**：显示可行性
6. **不切实际的时间表**：诚实地说明可实现的目标
7. **格式违规**：可能自动拒绝
8. **打字和错误**：表明缺乏关注

### 提案制定时间表

* *截止日期前3个月**：
- 识别机会
- 组建团队
- 概述目的/目标

* * 2个月前**：
- 草案目的/目标
- 初步预算
- 联系项目官员（如果允许）

* *1 个月前**：
- 完整初稿
- 内部审查
- 根据反馈进行修改

* *2 周前**：
- 最终修订
- 仔细校对
- 组装所有文件

* *1周前**：
- 机构审查/批准
- 预算最终确定
- 提交系统上传

* *2天前**：
- 最终结果check
- 提交（不要等到截止日期！）

## 摘要

* *关键要点**：

1. **了解机构**：不同使命，不同侧重点
2. **遵循规则**：页面限制、字体、边距严格执行
3. **讲述一个引人入胜的故事**：明确的问题，创新的解决方案，可行的计划
4. **展示影响**：智力价值 (NSF/NIH)或任务相关性 (DOE/DARPA)
5. **展示可行性**：初步数据、团队专业知识、资源
6. **实际预算**：证明所有成本合理
7. **仔细校对**：打字错误破坏了可信度
8. **尽早提交**：会发生技术故障

* *记住**：资助写作是一项随着时间的推移而发展的技能。寻求反馈、修改、坚持！
