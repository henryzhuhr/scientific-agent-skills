# What-If Oracle — 场景模板

特定领域场景分析配置的参考指南。

## 启动/业务决策

* *要测试的变量：**

- 市场进入时机
- 定价策略
- 合作条款
- 招聘决策
- 融资轮次

* *分支重点：**可能案例+逆向+二阶
* *关键张力：**速度与彻底性——初创公司无法永远分析

* *模板提示：**

> “如果我们在[时间范围]内[具体行动]会怎样？我们当前的状态：[收入、团队规模、关键约束：[限制因素]。“

## 技术架构

* *要测试的变量：**

- 技术堆栈选择
- 构建与购买
- 扩展方法
- 安全模型
- 迁移路径

* *分支重点：**最坏情况+通配符+二阶
* *关键张力：**工程优雅与出货速度

* *模板提示：**

> “如果我们为[系统]选择[技术/方法]会怎样？当前架构：[简要描述]。团队能力：[相关技能]。时间线： [截止日期]."

## 投资/金融

* *要测试的变量：**

- 市场状况
- 估值情景
- 退出时机
- 资本配置
- 收入模式变化

* *分行重点：**全部6个分支——资金决策值得全面分析
* *关键张力：**风险承受能力与机会成本

* *模板提示：**

> “如果[市场状况/金融事件]发生怎么办？我们的敞口：[金额/百分比]。当前位置：[财务状况]。时间范围：[投资期限]。”

## 职业/个人

* *要测试的变量：**

- 工作变动
- 技能发展路径
- 搬迁
- 关系决策
- 健康变化

* *分支重点：**可能情况+最佳情况+逆向
* *关键紧张：**安全与增长——舒适区与扩张

* *模板提示：**

> “如果我[个人决定]怎么办？我目前的情况：[简要]。我最看重什么：[1-3 个值]。我害怕什么：[诚实的答案]。”

## 地缘政治/宏观

* *要测试的变量：**

- 政策变化
- 监管转变
- 市场颠覆
- 技术突破
- 社会运动

* *分支强调：**通配符+二阶+逆向
* *关键张力：**局部影响与系统性影响

* *模板提示：**

> “如果[地缘政治事件]发生怎么办？我的暴露：[它如何影响我/我的组织]。时间范围：[相关时期]。“

## 危机应对

* *要测试的变量：**

- 严重程度升级
- 沟通策略
- 资源分配
- 恢复时间表
- 声誉影响

* *分支重点：**最坏情况（详细）+可能情况+二阶
* *关键张力：**立即分类与根本原因解决

* *模板提示：**

> “我们面临[危机/事件]。当前影响：[损坏的东西]。受影响的利益相关者：[谁]。资源可用：[我们可以部署什么]。如果[特定的升级场景]？“

## 递归模板

用于复杂的多层分析：

```
ROUND 1: "What if X?"
  → Identify the most likely branch (α)

ROUND 2: "Given α is happening, what if Y?"
  → Identify the most likely sub-branch

ROUND 3: "Given α+Y, what if Z?"
  → Map the deepest consequences

Each round narrows the possibility space while deepening understanding.
Maximum recommended depth: 3 rounds.
```

## 概率校准指南

将概率分配给分支时：

|置信度 |概率范围 |需要证据|
| ---------------- | ----------------- | ---------------------------------------------------------------------- |
| **非常高** | >80% |强有力的历史先例+当前数据对齐|
| **高** | 60-80% |多个汇聚信号，一些历史支撑|
| **中** | 30-60% |混合信号，可以任意选择 |
| **低** | 10-30% |看似合理，但需要几件事才能走上特定的道路 |
| **非常低** | <10% |黑天鹅领域 — 可能但不太可能 |

* *规则：** 单个分析中的所有分支概率之和应约为 100%。如果没有，则缺少一个分支。
