# 科学图表最佳实践

## 概述

本指南提供出版标准、可访问性指南以及创建满足期刊要求并与所有读者有效沟通的高质量科学图表的最佳实践。

## 出版标准

### 1. 文件格式要求

* *矢量格式（首选）**
- **PDF**：普遍接受，保持质量，与 LaTeX
 配合使用 - 用于：线条图、流程图、框图、电路图
 - 优点：可扩展、文件大小小、嵌入字体
  - LaTeX 工作流程的标准

- **EPS（封装 PostScript）**：传统格式，仍然已接受
  - 用于：较旧的出版系统
  - 与大多数期刊兼容
  - 可以从PDF转换

  - **SVG（可缩放矢量图形）**：网络友好，越来越被接受
  - 用于：在线出版物、交互式图形
  - 可以矢量图形编辑软件
  - 并非所有期刊都接受 SVG

* * 光栅格式（必要时）**
- **TIFF**：光栅图形的专业标准
  - 用于：显微镜图像、与图表组合的照片
  - 最终打印尺寸最低 300 DPI
  - 无损压缩(LZW)

- **PNG**：网络友好、无损压缩
  - 用于：在线补充材料、演示
  - 打印最低 300 DPI
  - 支持透明度

* *切勿使用**
- **JPEG**：有损压缩会在图
- **GIF**：颜色有限，不适合科学图形
- **BMP**：未压缩、不必要的大文件

### 2. 分辨率要求

* *矢量图形**
- 无限分辨率（可扩展）
- **推荐**：在以下情况下始终使用矢量可能

* *光栅图形（当矢量不可能时）**
- **出版质量**：300-600 DPI
- **线条艺术**：600-1200 DPI
- **网页/屏幕**：可接受 150 DPI
- **从不**：低于 300 DPI print

* *计算 DPI**
```
DPI = pixels / (inches at final size)

Example:
Image size: 2400 × 1800 pixels
Final print size: 8 × 6 inches
DPI = 2400 / 8 = 300 ✓ (acceptable)
```

### 3. 尺寸和尺寸

* *期刊特定栏宽**
- **自然**：单栏 89 毫米（3.5 英寸），双栏 183 毫米（7.2 英寸） in)
- **科学**：单柱 55 毫米（2.17 英寸），双柱 120 毫米（4.72 英寸）
- **细胞**：单柱 85 毫米（3.35 英寸），双柱 178 毫米（7 英寸）
- **PLOS**：单柱 83 毫米（3.27 英寸），双柱 173 毫米（6.83 英寸）
- **IEEE**：单列 3.5 英寸，双列 7.16 英寸

* *最佳实践**
- 按最终打印尺寸进行设计（避免缩放）
- 在可用时使用日志模板
- 允许裁剪边距
- 在最终尺寸下测试外观提交

### 4.排版标准

* *字体选择**
- **推荐**：Arial、Helvetica、Calibri（无衬线）
- **可接受**：数学重的Times New Roman（衬线）
- **避免**：装饰性可能无法嵌入的字体、脚本字体、系统字体

* *字体大小（最终打印尺寸）**
- **最小**：6-7 pt（取决于期刊）
- **轴标签**：8-9 pt
- **图形标签**：10-12 pt
- **面板标签（A、B、C）**：10-14 pt，粗体
- **正文**：应匹配稿件正文

* *文本清晰度**
- 使用句子大小写：“时间（秒）”而不是“时间（秒）”
- 包括括号中的单位： “温度 (°C)”
- 拼写出图形标题中的缩写
- 尽可能避免旋转文本（例外：y 轴标签）
- **图中没有数字** - 不包括“图 1：”、“图 1”等（这些由 LaTeX/文档添加）

### 5.线宽和笔画

* *推荐线宽**
- **图表轮廓**：0.5-1.0 pt
- **连接线/箭头**：1.0-2.0 pt
- **强调元素**：2.0-3.0 pt
- **最小可见**：最终0.25 pt尺寸

* *一致性**
- 对相似元素使用相同的线宽
- 改变线宽以显示层次结构
- 避免细线规则（太细而无法可靠打印）

## 辅助功能和色盲

### 1. 色盲安全调色板

* *Okabe-Ito 调色板（推荐）**
最能区分所有类型的色盲：

```latex
% RGB values
Orange:     #E69F00 (230, 159,   0)
Sky Blue:   #56B4E9 ( 86, 180, 233)
Green:      #009E73 (  0, 158, 115)
Yellow:     #F0E442 (240, 228,  66)
Blue:       #0072B2 (  0, 114, 178)
Vermillion: #D55E00 (213,  94,   0)
Purple:     #CC79A7 (204, 121, 167)
Black:      #000000 (  0,   0,   0)
```

* *替代：ColorBrewer 调色板**
- **定性**：Set2，配对，深色2
- **顺序**：蓝色、绿色、橙色（避免红色/绿色在一起）
- **发散**：RdBu（红-蓝色）、PuOr（紫-橙色）

* *要避免一起的颜色**
- 红-绿组合（8％的男性不能区分）
- 蓝紫色组合
- 黄-浅绿色组合

### 2.冗余编码

不要单独依赖颜色。使用多个视觉通道：

* *形状+颜色**
```
Circle + Blue   = Condition A
Square + Orange = Condition B
Triangle + Green = Condition C
```

* *线条样式+颜色**
```
Solid + Blue = Treatment 1
Dashed + Orange = Treatment 2
Dotted + Green = Control
```

* *图案填充+颜色**
```
Solid fill + Blue = Group A
Diagonal stripes + Orange = Group B
Cross-hatch + Green = Group C
```

### 3. 灰度兼容性

* *测试要求**：所有图表必须可以灰度解释

* *策略**
- 使用不同的阴影（浅色、中度、深色）
- 向填充区域添加图案或纹理
- 改变线条样式（实线、虚线、点）
- 直接在元素上使用标签
- 包括文本注释

* *灰度测试**
```bash
# Convert to grayscale to test
convert diagram.pdf -colorspace gray diagram_gray.pdf
```

### 4. 对比度要求

* *最小对比度（WCAG 指南）**
- **普通文本**：4.5:1
- **大文本**（≥18pt）：3:1
- **图形元素**：3:1

* *高对比度实践**
- 浅色背景上的深色文本（反之亦然）
- 避免低对比度颜色对（白色上黄色，白色上浅灰色）
- 关键文本使用黑色或深灰色
- 深色背景上的白色文本需要更大的字体大小

### 5. 替代文本和描述

* *图形标题必须包括**
- 图表类型的描述
- 拼写出的所有缩写
- 符号和颜色的解释
- 相关的样本大小(n)
- 解释的统计注释
- 详细方法的参考，如果适用

* *示例标题**
“遵循 CONSORT 指南的参与者流程图。矩形代表研究阶段，显示参与者数量 (n)。排除标准列在每个筛选阶段旁边。最终分析包括两组中的 n=350 名参与者。”

## 设计原则

### 1. 简单性和清晰度

* *图表的奥卡姆剃刀**
- 删除所有不添加信息的元素
- 简化复杂的关系
- 将复杂的图表分解为多个面板
- 在相关图形中使用一致的布局

* *视觉层次结构**
- 最重要的元素：最大、最暗、中心
- 支持元素：更小、更轻、外围
- 注释：最小、仅限清晰标签

### 2. 一致性

* *图中**
- 相同的形状/颜色表示相同概念
- 相同关系的一致箭头样式
- 统一间距和对齐
- 匹配相似元素的字体大小

* *论文中的图形**
- 重复使用配色方案
- 保持一致的节点样式
- 使用相同的符号系统
- 应用相同的布局原则

### 3.专业外观

* *对齐**
- 使用网格进行节点放置
- 水平或垂直对齐节点
- 均匀间隔元素
- 形状内的居中标签

* *空白**
- 不要过度拥挤图表
- 在元素周围留出呼吸空间
- 使用空白对相关项目进行分组
- 整个图表周围的边距

* *波兰**
- 没有锯齿状线条或未对齐的元素
- 平滑的曲线和精确的角度
- 干净的连接点
- 无重叠文本

## 常见陷阱和解决方案

### 陷阱1：过于复杂的图表

* *问题**：一张图表中的信息太多
* *解决方案**：
- 分成多个面板（A、B、 C)
- 创建概述 + 详细图表
- 将详细信息移动到补充图表
- 使用分层演示文稿

### 陷阱 2：样式不一致

* *问题**：不同图表中相同元素的不同样式
* *解决方案**：
- 创建和使用样式模板
- 始终使用相同的调色板
- 记录您的样式选择

### 陷阱 3：标签放置不当

* *问题**：标签重叠元素或难以阅读
* *解决方案**：
- 尽可能将标签放置在形状外部
- 对远处的标签使用引导线
- 仅在必要时旋转文本
- 确保与背景有足够的对比度

### 陷阱 4：小文本

* *问题**：文本太小，无法在最终打印尺寸下阅读
* *解决方案**：
- 根据最终尺寸进行设计start
- 以最终尺寸测试打印
- 最小 7-8 pt 字体
- 如果空间有限则简化标签

### 陷阱 5：不明确的箭头

* *问题**：不清楚箭头代表什么或它们在哪里点
* *解决方案**：
- 使用不同的箭头样式表示不同的含义
- 为箭头添加标签
- 包括箭头类型的图例
- 使用锚点进行精确连接

### 陷阱6：颜色过度使用

* *问题**：颜色太多，令人困惑或无法访问
* *解决方案**：
- 最多限制为3-5种颜色
- 有目的地使用颜色（类别、强调）
- 坚持色盲安全调色板
- 提供冗余编码

## 期刊特定指南

### Nature

* *图形要求**
- **尺寸**：89毫米（单列）或183毫米（双列）
- **格式**：PDF、EPS或高分辨率TIFF
- **字体**：首选无衬线
- **文件大小**：每个文件 <10 MB
- **分辨率**：光栅最低 300 DPI

* *样式注释**
- 面板标签：小写粗体（a、b、c）
- 简单、干净的设计
- 最少颜色
- 清晰标题

### Science

* *图形要求**
- **尺寸**：55毫米（单列）或120毫米（双列）
- **格式**：PDF、EPS、TIFF或JPEG（高质量）
- **分辨率**：300照片 DPI，线条艺术 600 DPI
- **文件大小**：<10 MB
- **字体**：最小 6-7 磅

* *样式注释**
- 面板标签：大写粗体（A、B、C）
- 高对比度
- 小码可读尺寸

### 电池

* *图形要求**
- **尺寸**：85 毫米（单列）或 178 毫米（双列）
- **格式**：首选 PDF，TIFF、EPS 可接受
- **分辨率**：最小 300 DPI
- **字体**：8-10 pt标签
- **线宽**：最小 0.5 磅

* *样式注释**
- 干净、专业
- 彩色或灰度
- 面板标签大写（A、B、C）

### IEEE

* *图形要求**
- **尺寸**： 3.5 英寸（单列）或 7.16 英寸（双列）
- **格式**：PDF、EPS（首选矢量）
- **分辨率**：线条艺术 600 DPI，半色调 300 DPI
- **字体**：8-10 pt最小值
- **颜色**：打印灰度，数字颜色

* *样式注释**
- 遵循 IEEE 图形手册
- 电路标准符号
- 技术精度
- 清除轴标签

## 软件特定的导出设置

### AI 生成的图像

AI 生成的图表导出为 PNG 图像，并可以使用以下命令包含在 LaTeX 文档中：

```latex
\includegraphics[width=\textwidth]{diagram.png}
```

### Python (Matplotlib) Export

```python
import matplotlib.pyplot as plt

# Set publication quality
plt.rcParams['font.family'] = 'sans-serif'
plt.rcParams['font.sans-serif'] = ['Arial']
plt.rcParams['font.size'] = 8
plt.rcParams['pdf.fonttype'] = 42  # TrueType fonts in PDF

# Save with proper DPI and cropping
fig.savefig('diagram.pdf', dpi=300, bbox_inches='tight', 
            pad_inches=0.1, transparent=False)
fig.savefig('diagram.png', dpi=300, bbox_inches='tight')
```

### Schemdraw导出

```python
import schemdraw

d = schemdraw.Drawing()
# ... build circuit ...

# Export
d.save('circuit.svg')  # Vector
d.save('circuit.pdf')  # Vector
d.save('circuit.png', dpi=300)  # Raster
```

### Inkscape 命令行

```bash
# PDF to high-res PNG
inkscape diagram.pdf --export-png=diagram.png --export-dpi=300

# SVG to PDF
inkscape diagram.svg --export-pdf=diagram.pdf
```
