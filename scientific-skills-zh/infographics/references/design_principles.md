# 信息图表设计原则

此参考涵盖了创建有效、专业的信息图表的基本设计原则。

- --

## 视觉层次结构

视觉层次结构引导观看者的眼睛按有意的顺序浏览信息图表，确保首先看到关键信息。

### 层次金字塔

1. **主要元素**（首先看到）
  - 标题和标题
  - 大数字或关键统计数据
  - 英雄图像或主要插图
  - 号召性用语元素

2. **次要元素**（第二次看到）
  - 副标题和章节标题
  - 图表和图形
  - 图标和视觉标记
  - 关键支持文本

3. **第三级元素**（最后看到）
  - 正文和描述
  - 图例和标签
  - 来源引用
  - 小字体和脚注

### 创建层次结构

 * *大小**：较大的元素首先吸引注意
  - 标题：比正文大 200-300%
- 主要统计数据：使数字比标签大 2-4 倍
- 重要图标：比支持图标大 1.5-2 倍

* *颜色**：明亮和对比色吸引眼球
- 谨慎使用强调色来强调
- 保留最亮的颜色最重要的元素
- 使用柔和的颜色来支持信息

* *位置**：首先看到左上角和中心
- 将最重要的内容放在顶部或中心
- 向底部或边缘支撑细节
- 阅读流程：从上到下，从左到右（西文）文化）

* *对比度**：高对比度元素脱颖而出
- 关键文本的深色亮色或浅色深色
- 中性背景下的彩色元素
- 提升关键元素的边框和阴影

* *白色空间**：隔离引起注意
- 用space
- 不要拥挤关键信息
- 使用间距对相关项目进行分组

## 布局模式

### F 图案布局

最适合：文字较多的信息图表、列表、文章

```
┌─────────────────────────────────────┐
│ ████████████████████████████████████│  ← Top horizontal scan
├─────────────────────────────────────┤
│ █████████████████                   │  ← Second horizontal scan
├─────────────────────────────────────┤
│ █████                               │
│ █████                               │  ← Vertical scan down left
│ █████                               │
│ █████                               │
└─────────────────────────────────────┘
```

* *应用：**
- 将标题放在顶部的全角
- 第二行的重要副标题
- 与左侧对齐的关键内容
- 较少右侧关键内容

### Z 模式布局

最适合：最小内容、登陆页面、单消息信息图表

```
┌─────────────────────────────────────┐
│ ●────────────────────────────────→ ●│  ← Start top-left, scan right
├─────────────────────────────────────┤
│      ╲                              │
│        ╲                            │  ← Diagonal scan
│          ╲                          │
├─────────────────────────────────────┤
│ ●────────────────────────────────→ ●│  ← Bottom left to right
└─────────────────────────────────────┘
```

* *应用：**
- 徽标/标题左上角
- 关键视觉效果右上
- 通过中心的对角线眼球运动
- 号召性用语右下

### 单列布局

最适合：移动设备友好、滚动内容、流程信息图表

```
┌───────────────┐
│    HEADER     │
├───────────────┤
│   Section 1   │
├───────────────┤
│   Section 2   │
├───────────────┤
│   Section 3   │
├───────────────┤
│   Section 4   │
├───────────────┤
│    FOOTER     │
└───────────────┘
```

* *应用：**
- 垂直滚动内容
- 分步流程
- 时间轴信息图表
- 移动优先设计

### 多列布局

最适合：比较、功能列表、复杂数据

```
┌─────────────────────────────────────┐
│           HEADER/TITLE              │
├──────────────┬──────────────────────┤
│   Column 1   │      Column 2        │
│   --------   │      --------        │
│   Content    │      Content         │
│   Content    │      Content         │
│   Content    │      Content         │
├──────────────┴──────────────────────┤
│            FOOTER                   │
└─────────────────────────────────────┘
```

* *应用：**
- 并排比较
- 优缺点列表
- 特征矩阵
- 两类信息

### 网格布局

最适合：多个等权重项目、统计、图标网格

```
┌─────────────────────────────────────┐
│           HEADER/TITLE              │
├───────────┬───────────┬─────────────┤
│   Item 1  │   Item 2  │   Item 3    │
├───────────┼───────────┼─────────────┤
│   Item 4  │   Item 5  │   Item 6    │
├───────────┼───────────┼─────────────┤
│   Item 7  │   Item 8  │   Item 9    │
├───────────┴───────────┴─────────────┤
│            FOOTER                   │
└─────────────────────────────────────┘
```

* *应用：**
- 多个统计（2x2、3x3、2x3网格）
- 图标集合
- 功能亮点
- 团队成员展示

### 模块化/卡片布局

最适合：多种内容类型、灵活的信息、现代设计

```
┌─────────────────────────────────────┐
│           HEADER/TITLE              │
├───────────────────┬─────────────────┤
│                   │      Card 2     │
│     Card 1        ├─────────────────┤
│     (large)       │      Card 3     │
├───────────────────┼─────────────────┤
│      Card 4       │      Card 5     │
└───────────────────┴─────────────────┘
```

* *应用：**
- 混合内容类型
- 不同的重要性级别
- 现代仪表板风格
- 杂志风格布局

## 60-40规则

最佳信息图表平衡视觉和文本内容：

- **60%视觉元素**：图标、图表、插图、图像、形状
- **40% 文本内容**：标题、标签、描述、数据

### 为什么这很重要

- 太多文本：感觉像文档，而不是信息图
- 太多视觉效果：缺乏实质内容和清晰度
- 正确平衡：参与和信息性

### 应用规则

* *视觉元素 (60%)**
- 图表和图形
- 图标和符号
- 插图
- 照片
- 装饰形状
- 色块
- 线条和连接器

* *文本元素(40%)**
- 标题和标题
- 副标题
- 数据标签
- 简要说明
- 来源引用
- 号召性用语

## 空格（负数） Space)

空白是元素之间和元素周围的空白区域。它不是浪费空间——它是一个设计工具。

### 空白空间

1的功能。 **提高可读性**：在内容 
2 之间让眼睛休息。 **创造焦点**：孤立的元素吸引注意力
3. **群组内容**：相关项目显示为连接
4. **增添优雅**：设计
5 具有高级感。 **减少混乱**：防止观众不知所措

### 空白指南

* *边距**：整个信息图周围的空间
- 宽度/高度的至少5-10%
- 更多边距=更优质的感觉
- 所有侧面一致

* *填充**：内部空间元素（框、卡片）
- 最小等于文本行高度
- 重要元素有更多填充
- 相似元素内一致

* *间隙**：元素之间的空间
- 相关项目：小间隙（8-16 像素）
- 不相关项目：大间隙(24-48 像素)
- 部分：最大间隙 (48-72 像素)

* *行间距**：文本行之间的间距
- 正文：1.4-1.6 倍字体大小
- 标题：1.1-1.3 倍字体大小
- 列表： 1.5-2 倍字体大小

## 版式

### 字体选择

* *无衬线字体**（推荐用于信息图表）
- 干净、现代的外观
- 更好的屏幕可读性
- 专业Feel
- 示例：Arial、Helvetica、Open Sans、Roboto、Montserrat

* *衬线字体**（谨慎使用）
- 传统、权威 Feel
- 适合正式上下文中的标题
- 示例：Georgia、Times New Roman、Playfair显示

* *显示字体**（仅限标题）
- 对标题影响较大
- 不适用于正文
- 示例：Impact、Bebas Neue、Oswald

### 字体配对规则

1. **每个信息图表
2 最多 2-3 种字体**。 **对比是关键**：搭配不同的风格（衬线 + 无衬线）
3. **建立角色**：一种用于标题，一种用于正文，一种用于重音
4. **保持一致性**：始终使用相同的字体

* *安全配对：**
- Montserrat（标题）+ Open Sans（正文）
- Playfair Display（标题）+ Roboto（正文）
- Bebas Neue（标题）+ Lato（正文）
- Oswald （标题）+ Source Sans Pro（正文）

### 字体大小

|元素|尺寸范围 |重量 |
|---------|------------|--------|
|主标题 | 36-72 点 |粗体|
|节标题 | 24-36 点 |粗体/半粗体|
|副标题| 18-24点|半粗体|
|正文 | 12-16 分 |常规|
|标题/标签 | 10-14 分 |常规/浅色|
|精美印刷| 8-10分|光 |

### 版式最佳实践

1. **左对齐正文**（比居中更容易阅读）
2. **居中对齐标题**（影响力）
3. **限制行长度**为 45-75 个字符
4. **谨慎使用粗体**用于强调
5. **避免正文全部大写**（难以阅读）
6. **对于短标题/标签，可接受全部大写**
7. **保持文本和背景之间的对比度**（最低 4.5:1）

## 故事结构

每个有效的信息图都讲述一个由三个部分组成的故事：

### 1. 简介（挂钩）

* *目的**：吸引注意力，建立主题

* *元素：**
- 引人注目的标题
- 引人注目的英雄视觉
- 关键统计数据或问题
- 主题介绍

* *最佳实践：**
- 让人无法忽视
- 承诺价值（“学习如何...”）
- 产生好奇心
- 总空间的10-15%

### 2. 正文（内容）

* *目的**：传递主要信息

* *元素：**
- 数据和统计
- 分步内容
- 比较和分析
- 支持视觉效果

* *最佳实践：**
- 逻辑流程（时间顺序、重要性或分类）
- 清除分节符
- 平衡视觉效果和文本
- 总空间的 70-80%

### 3. 结论（要点）

* *目的**：总结、号召性用语

* *元素：**
- 关键要点或摘要
- 号召性用语
- 来源引文
- 品牌/归因

* *最佳实践：**
- 强化主要信息
- 为观众明确下一步
- 不要引入新信息
- 占总数的10-15% space

## 对齐和网格

### 网格系统

使用不可见网格一致地对齐元素：

* *列网格**（最常见）
- 2、3、4 或 6 列
- 元素跨越一列或多列列
- 列之间的排水沟（间隙）
- 创建有序、专业的外观

* *模块化网格**
- 列+行=模块
- 为不同的内容提供更大的灵活性
- 适合复杂的布局
- 仪表板式设计

### 对齐类型

* *左对齐**
- 最常见的文本
- 创建强大的左边缘
- 易于扫描
- 专业外观

* * 中心对齐**
- 适合headers
- 创建对称
- 谨慎使用文本
- 适用于单个元素

* *右对齐**
- 很少用于主要内容
- 适合表格中的数字
- 在西方语言中感觉不寻常设计
- 有意使用

### 对齐最佳实践

1. **选择一个主要对齐方式**并坚持使用它
2. **将相关元素**对齐到相同的边缘或中心
3. **使用隐形网格线**以保持一致性
4. **避免随机放置**——一切都应该与 
5 对齐。 **通过对齐创建视觉联系**

## 颜色使用

### 信息图表中的颜色功能

1. **建立层次结构**：重要项目用鲜艳的颜色
2. **组相关项目**：相同颜色 = 相同类别
3. **创建对比**：区分元素
4. **唤起情感**：颜色具有心理意义
5. **强化品牌**：与品牌标识一致

### 颜色分布

* *60-30-10 规则：**
- **60%** 主色（背景、大面积）
- **30%** 次要颜色（支撑元素）
- **10%** 强调色（高亮、大面积） CTA)

### 色彩心理学

|颜色 |协会 |最适合 |
|--------|--------------|----------|
|蓝色|信任、专业、冷静 |企业、科技、医疗保健 |
|绿色|成长、自然、金钱 |环境、金融、健康|
|红色|紧迫感、活力、激情 |警报、销售、食品 |
|橙色|友善、自信、有创造力 | CTA，青年品牌|
|黄色|乐观、谨慎、关注 |亮点、警告|
|紫色|奢华、创意、智慧|优质品牌，教育|
|黑色|精致、力量、优雅 |奢华、正式|
|白色|干净、简约、空间|背景、呼吸空间 |

### 对比度要求

无障碍功能 (WCAG 2.1 AA)：
- **普通文本**：最小对比度 4.5:1
- **大文本** (18pt+)：最小对比度 3:1
- **图形和 UI**： 3:1 对比度最小值

检查对比度的工具：
- WebAIM 对比度检查器
- Coolors 对比度检查器
- Adobe 颜色辅助工具

## 图标用法

### 图标样式

* *线条图标**（轮廓）
- 干净、现代的外观
- 在小尺寸下效果很好
- 最适合简约设计
- 一致的线宽重要

* *填充图标**（实心）
- 更大胆的视觉效果冲击
- 适合快速识别
- 适合作为焦点
- 小尺寸更容易接近

* *插图图标**
- 更具个性和独特性
- 更高的视觉重量
- 最适合有趣的设计
- 可能无法很好地缩放

### 图标最佳实践

1. **在整个信息图中一致使用一种风格**
2. **确保可识别性**——图标应立即被理解
3. **同一层次结构级别的图标保持一致的大小**
4. **当图标含义不是 100% 清晰时添加标签**
5. **将图标的视觉重量**与周围元素相匹配
6. **仔细考虑颜色**——单色通常更干净
7. **避免图标过载**——并非所有东西都需要图标

### 图标大小指南

|背景 |推荐尺寸|
|----------|------------------|
|英雄/功能图标| 64-128 像素 |
|部分图标| 32-48 像素 |
|列表项图标| 24-32 像素 |
|内嵌图标 | 16-24px |

## 数据可视化最佳实践

### 选择图表类型

|数据类型 |最佳图表|
|---------|------------|
|比较（几项）|条形图|
|比较（多项）|单杠|
|整体的部分|饼图/圆环图 |
|随时间变化的趋势|折线图|
|分销|直方图|
|关系 |散点图|
|地理|地图/等值线 |
|层次结构|树状图 |
|流程/过程 |桑基图 |

### 图表最佳实践

1. **标记所有内容**：轴、数据点、图例
2. **条形图的 Y 轴从零开始**（避免误导）
3. **将饼图切片**限制为最多 5-7 个
4. **对图表中的相同类别使用一致的颜色**
5. **删除图表垃圾**：无 3D 效果，最小网格线
6. **突出关键数据**：用颜色强调重要点

### 数字表示

- **大数字**：使用缩写（1.2M，而不是 1,200,000）
- **百分比**：包括 % 符号，最多一位小数
- **比较**：使用一致的单位和精度
- **上下文**：始终提供参考点（“2x 行业”）平均")

## 辅助功能注意事项

### 视觉辅助功能

1. **仅颜色不应传达含义**
  - 添加图案、标签或形状
  - 适用于色盲用户

2. **足够的对比度**
  - 4.5:1（适用于普通文本）
  - 3:1（适用于大文本和图形）

3. **文本大小**
  - 打印的最小 10 磅 
  - 数字 

4 的最小 12 像素。 **不要依赖颜色图例**
 - 尽可能直接标记数据

### 色盲安全设计

 - 使用色盲安全调色板（参见color_palettes.md）
  - 使用色盲模拟器进行测试
  - 添加图案或纹理区分
- 使用标签和直接注释

### 阅读无障碍

- 清晰的层次结构和流程
- 简洁的文字
- 简单的语言
- 足够的间距
- 逻辑阅读order
