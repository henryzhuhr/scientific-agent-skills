## 对比检查

### WCAG 2.1 要求

|对比度|要求 |
|----------------|------------------------|
| 4.5:1 |普通文本（18pt以下）|
| 3:1 |大文本（18pt+ 或 14pt 粗体）|
| 3:1 |图形和 UI 组件 |

### 常见安全组合

* *白色背景 (#FFFFFF)：**
|文字颜色 |十六进制 |对比度|
|------------|-----|----------------|
|黑色| `#000000` | 21:1 ✓ |
|深灰色| `#333333` | 12.6:1 ✓ |
|海军| `#1E3A5F` | 11.2:1 ✓ |
|深绿色| `#1B4332` | 10.9:1 ✓ |
|深蓝色| `#0072B2` | 5.7:1 ✓ |
|中灰色| `#666666` | 5.7:1 ✓ |
|红色| `#CC0000` | 5.5:1 ✓ |

* *在深色背景上 (#1A1A2E):**
|文字颜色 |十六进制 |对比度|
|------------|-----|----------------|
|白色| `#FFFFFF` | 17.1:1 ✓ |
|浅灰色| `#E5E5E5` | 13.8:1 ✓ |
|浅青色| `#90E0EF` | 10.2:1 ✓ |
|黄色| `#F0E442` | 12.5:1 ✓ |
|浅蓝色 | `#56B4E9` | 7.8:1 ✓ |

### 避免同时使用的颜色

这些组合的对比度较差或对色盲用户来说是有问题的：

- 红色和绿色（最常见的色盲）
- 蓝色和紫色（难以区分）
- 浅绿色和黄色（低对比度）
- 红色和橙色（相似色调）
- 蓝色和灰色（可能混淆）
- 粉色和紫色灰色（相似值）
