# 状态报告/执行简报模板

> **返回 [Markdown 样式指南](../markdown_style_guide.md)** — 首先阅读样式指南以了解格式、引用和表情符号规则。

* *将此模板用于：** 每周/每月状态更新、执行简报、项目健康报告、季度审查、冲刺回顾或任何向利益相关者通报进展、风险和所需决策的文件。专为具有决策权的人在 5 分钟内阅读而设计。

* *主要特点：** TL;DR 位于顶部，适合不会进一步阅读的高管、红绿灯健康指标、显示阻碍因素的明确“需要决策”部分、包含趋势的指标表以及包含缓解措施的风险登记册。

* *理念：** 状态报告的第一大失败模式是将重要的内容埋在成就之墙中。以需要注意的内容为主导。如果读者只有 30 秒的时间，TL;DR 和健康摘要可以满足他们的需要。如果他们有 5 分钟的时间，完整的报告会回答他们提出的每个后续问题。永远不要让领导层挖掘他们需要采取行动的事情。

- --

## 如何使用

1. 为每个报告期 
2 复制此文件。按日期命名：`status-2026-02-14.md` 或 `status-week-07.md`
3. **先填写TL;DR**——如果你不能概括它，你还没有理解它
4. 诚实地对待健康状况——绿色意味着绿色，而不是“因为我乐观而绿色”
5. 添加 [美人鱼图](../mermaid_style_guide.md)用于进度时间表、架构变更或风险影响流
