# 治疗建议指南

## 概述

循证治疗建议为临床医生的治疗决策提供系统指导。本指南涵盖了制药和医疗保健环境中临床建议的制定、分级和呈现。

## 证据分级系统

### GRADE（建议评估、制定和评估分级）

* *证据质量级别**

* *高质量 (⊕⊕⊕⊕)**
- 进一步研究不太可能改变估计的置信度
- 标准：精心设计的随机对照试验，结果一致，没有严重的局限性
- 示例：多个大型随机对照试验显示相似的治疗效果

* *中等质量（⊕⊕⊕○）**
- 进一步的研究可能对置信度产生重要影响
- 标准：有局限性或非常严重的随机对照试验来自观察性研究的有力证据
- 示例：单个 RCT 或多个有一些不一致的 RCT

* * 低质量（⊕⊕○○）**
- 进一步的研究很可能对信心产生重要影响
- 标准：观察性研究或具有严重局限性的 RCT
- 示例：病例对照研究、混杂的队列研究

* *非常低质量（⊕○○○）**
- 效果估计非常不确定
- 标准：病例系列、专家意见或非常严重的局限性
- 示例：机械推理、非系统的临床观察

* *建议**

* *强烈建议（1 级）**
- 收益明显超过风险和负担（反之亦然）
- 措辞：“我们建议...”
- 含义：大多数患者应接受推荐的疗程
- 符号：↑↑（强用于）或 ↓↓（强）反对）

* *有条件/弱推荐（2 级）**
- 存在权衡；获益与风险紧密平衡
- 措辞：“我们建议……”
- 含义：不同患者有不同选择；共同决策
- 符号：↑（弱支持）或↓（弱反对）

* *GRADE 表示法示例**
- **1A**：强推荐，高质量证据
- **1B**：强推荐，中等质量证据
- **2A**：弱推荐，高质量证据
- **2B**：弱推荐，中等质量证据
- **2C**：弱推荐，低质量或极低质量证据

### 牛津循证医学中心 (CEBM)级别

* *1 级：系统评价/荟萃分析**
- 1a：SR RCT
- 1b：具有窄置信区间的个体 RCT
- 1c：全或无研究（所有患者在治疗前死亡，一些患者在治疗后存活）

* *2 级：队列研究**
- 2a：队列研究的 SR
- 2b：个体队列研究（包括低质量） RCT)
- 2c：结果研究、生态研究

* *第3级：病例对照研究**
- 3a：病例对照研究的SR
- 3b：个体病例对照研究

* *第4级：病例系列**
- 病例系列，低质量队列，或病例对照研究

* *5级：专家意见**
- 基于机制的推理，无需严格评估的专家意见

* *推荐等级**
- **A级**：一致的1级研究
- **B级**：一致的2级或3级研究，或从该水平推断1
- **C 级**：4 级研究或从 2 级或 3 级推断
- **D 级**：5 级证据或不一致/不确定的研究

## 治疗顺序和治疗路线

### 一线治疗

* *选择标准**
- **护理标准**：基于第3阶段试验的指南推荐
- **患者因素**：表现状态、合并症、器官功能
- **疾病因素**：分期、分子特征、侵袭性
- **目标**：治愈（辅助/新辅助），延长缓解，症状控制

* *一线选项文档**
```
First-Line Treatment Options:

Option 1: Regimen A (NCCN Category 1, ESMO I-A)
- Evidence: Phase 3 RCT (n=1000), median PFS 12 months vs 8 months (HR 0.6, p<0.001)
- Population: PD-L1 ≥50%, EGFR/ALK negative
- Toxicity Profile: Immune-related AEs (15% grade 3-4)
- Recommendation Strength: 1A (strong, high-quality evidence)

Option 2: Regimen B (NCCN Category 1, ESMO I-A)
- Evidence: Phase 3 RCT (n=800), median PFS 10 months vs 8 months (HR 0.7, p=0.003)
- Population: All patients, no biomarker selection
- Toxicity Profile: Hematologic toxicity (25% grade 3-4)
- Recommendation Strength: 1A (strong, high-quality evidence)
```

### 二线及以上

* *二线选择**
- **先前反应**：对一线的反应持续时间
- **进展模式**：寡进展与广泛进展进展
- **残留毒性**：从一线毒性中恢复
- **生物标志物进化**：获得性耐药机制
- **临床试验可用性**：正在开发的新药

  * *治疗历史文件**
```
Prior Therapies:
1. First-Line: Pembrolizumab (12 cycles)
   - Best Response: Partial response (-45% tumor burden)
   - PFS: 14 months
   - Discontinuation Reason: Progressive disease
   - Residual Toxicity: Grade 1 hypothyroidism (on levothyroxine)

2. Second-Line: Docetaxel + ramucirumab (6 cycles)
   - Best Response: Stable disease
   - PFS: 5 months  
   - Discontinuation Reason: Progressive disease
   - Residual Toxicity: Grade 2 peripheral neuropathy

Current Consideration: Third-Line Options
- Clinical trial vs platinum-based chemotherapy
```

### 维持治疗

* *适应症**
- 诱导治疗有反应后的巩固
- 无需连续细胞毒治疗即可预防进展
- 过渡到确定性治疗（例如，移植）

* *证据要求**
- 随机试验中证明的 PFS 益处
- 可耐受的长期毒性特征 
- 保留或改善的生活质量

## 生物标志物引导的治疗选择

### 伴侣诊断

* *FDA 批准的生物标志物-药物对**

* *所需测试（治疗特异性）**
- **ALK 重排 → Alectinib、Brigatinib、Lorlatinib** (NSCLC)
- **EGFR 外显子 19 del/L858R → Osimertinib** (NSCLC)
- **BRAF V600E → 达拉非尼 + 曲美替尼** (黑色素瘤、NSCLC、CRC)
- **HER2 扩增/3+ → 曲妥珠单抗、帕妥珠单抗** (乳腺癌、胃病)
- **PD-L1 ≥50% → 帕博利珠单抗单药治疗** (NSCLC)一线）

* *补充诊断（提供信息，但不是必需的）**
- **PD-L1 1-49%**：首选联合免疫疗法
- **TMB 高**：可预测免疫治疗获益（研究）
- **MSI-H/dMMR**：派姆单抗在多种肿瘤类型中获得批准

### 生物标志物测试算法

* *NSCLC 生物标志物组合**
```
Reflex Testing at Diagnosis:
✓ EGFR mutations (exons 18, 19, 20, 21)
✓ ALK rearrangement (IHC or FISH)
✓ ROS1 rearrangement (FISH or NGS)
✓ BRAF V600E mutation
✓ PD-L1 IHC (22C3 or SP263)
✓ Consider: Comprehensive NGS panel

If EGFR+ on Osimertinib progression:
✓ Liquid biopsy for T790M (if first/second-gen TKI)
✓ Tissue biopsy for resistance mechanisms
✓ MET amplification, HER2 amplification, SCLC transformation
```

* *乳腺癌生物标志物算法**
```
Initial Diagnosis:
✓ ER/PR IHC
✓ HER2 IHC and FISH (if 2+)
✓ Ki-67 proliferation index

If Metastatic ER+/HER2-:
✓ ESR1 mutations (liquid biopsy after progression on AI)
✓ PIK3CA mutations (for alpelisib eligibility)
✓ BRCA1/2 germline testing (for PARP inhibitor eligibility)
✓ PD-L1 testing (if considering immunotherapy combinations)
```

### 可操作的改变

* *I 级：FDA 批准的靶向治疗**
- 来自前瞻性试验的强有力证据
- 指南推荐
- 示例：EGFR外显子19缺失、HER2扩增、ALK融合

* *II级：临床试验或标签外使用**
- 新证据，临床试验首选
- 示例：NTRK 融合（larotrectinib）、RET 融合（selpercatinib）

* *III 级：生物学合理性**
- 仅临床前证据
- 强烈建议参加临床试验
- 示例：新型激酶融合、罕见耐药突变

## 联合治疗方案

### 组合的基本原理

* *机制**
- **非重叠毒性**：最大化每种药物的剂量强度
- **协同活性**：超越相加效应的增强功效
- **补充机制**：针对多种途径同时
- **预防耐药性**：降低耐药克隆的选择压力

* *组合设计原则**
- **顺序**：诱导然后巩固（不同方案）
- **同时**：一起给药以获得协同作用
- **交替**：轮换方案以最大限度地减少耐药性耐药性
- **间歇**：脉冲给药与连续暴露

### 药物相互作用评估

* *药代动力学相互作用**
- **CYP450 诱导/抑制**：检查药物-药物相互作用
- **转运蛋白相互作用**：P-gp、BCRP、OATP 底物/抑制剂
- **蛋白质结合**：高度蛋白质结合的药物（华法林谨慎）
- **肾/肝清除**：避免多种肾清除药物

* *药效学相互作用**
- **附加毒性**：避免重叠的不良事件（例如QTc延长）
- **拮抗**：确保机制是互补的，而不是相反
- **剂量修改**：预先定义的剂量减少时间表组合

### 组合文档

```
Combination Regimen: Drug A + Drug B

Rationale:
- Phase 3 RCT demonstrated PFS benefit (16 vs 11 months, HR 0.62, p<0.001)
- Complementary mechanisms: Drug A (VEGF inhibitor) + Drug B (immune checkpoint inhibitor)
- Non-overlapping toxicity profiles

Dosing:
- Drug A: 10 mg/kg IV every 3 weeks
- Drug B: 1200 mg IV every 3 weeks
- Continue until progression or unacceptable toxicity

Key Toxicities:
- Hypertension (Drug A): 30% grade 3-4, manage with antihypertensives
- Immune-related AEs (Drug B): 15% grade 3-4, corticosteroid management
- No significant pharmacokinetic interactions observed

Monitoring:
- Blood pressure: Daily for first month, then weekly
- Thyroid function: Every 6 weeks  
- Liver enzymes: Before each cycle
- Imaging: Every 6 weeks (RECIST v1.1)
```

## 特殊人群

### 老年患者（≥65-70岁）年)

* *注意事项**
- **器官功能下降**：肾/肝损伤调整
- **复方用药**：药物间相互作用风险
- **虚弱**：老年评估（G8、VES-13、CARG 评分）
- **护理目标**：质量生命与生存、功能独立性

* *修改**
- 剂量减少：体弱患者减少 20-25%
- 更长的间隔：每 4 周一次，而不是每 3 周一次 
- 不太激进的治疗方案：单药治疗与联合治疗
- 支持治疗：增加监测、G-CSF预防

### 肾损伤

* *根据 eGFR 调整剂量**
```
eGFR (mL/min/1.73m²)    Category  Action
≥90                     Normal    Standard dosing
60-89                   Mild      Standard dosing (most agents)
30-59                   Moderate  Dose reduce renally cleared drugs 25-50%
15-29                   Severe    Dose reduce 50-75%, avoid nephrotoxic agents
<15 (dialysis)          ESRD      Avoid most agents, case-by-case decisions
```

* *需要调整的肾脏清除药物**
- 卡铂（Calvert 公式：AUC × [GFR + 25]）
- 甲氨蝶呤（如果 CrCl 则减少剂量 50-75%） <60)
- 卡培他滨（如果 CrCl 30-50，则减少剂量 25-50%）

### 肝损伤

* *通过 Bili 和 AST/ALT 调整剂量**
```
Category          Bilirubin         AST/ALT        Action
Normal           ≤ULN              ≤ULN           Standard dosing
Mild (Child A)    1-1.5× ULN        Any            Reduce dose 25% for hepatically metabolized
Moderate (Child B) 1.5-3× ULN       Any            Reduce dose 50%, consider alternative
Severe (Child C)  >3× ULN           Any            Avoid most agents, case-by-case
```

* *需要肝代谢药物调整**
- 多西他赛（如果胆红素升高则减少25-50%）
- 伊立替康（如果胆红素1.5-3×ULN则减少50%）
- 酪氨酸激酶抑制剂（大部分由CYP3A4代谢，减少50%）

### 怀孕和生育

* *避孕要求**
- 治疗期间和治疗后6-12个月需要有效避孕
- 高度致畸药物推荐的两种方法
- 男性患者：育龄伴侣避孕

* *生育力保留**
- 卵母细胞/胚胎冷冻保存（女性，性腺毒性治疗前）
- 精子库（男性，烷化剂、铂前）
- GnRH 激动剂（卵巢抑制，疗效有争议）
- 治疗前转诊至生殖内分泌科

* *妊娠管理**
- 避免妊娠早期化疗（器官发生）
- 妊娠中期/晚期安全的选择性药物（具体情况而定）
- 多学科团队：肿瘤学、母胎医学、新生儿学

## 临床试验注意事项

### 何时推荐临床试验

* *理想场景**
- 没有可用的标准治疗（罕见疾病、难治性情况）
- 多种等效标准选项（患者偏好新药）
- 标准治疗失败（二线及以上）
- 高风险疾病（改善结果的辅助试验）

* *试验选择标准**
- **阶段**：第1阶段（剂量探索、安全性）、第2阶段（功效信号）、第3阶段（比较有效性）
- **资格**：将患者与纳入/排除标准相匹配
- **机制**：新颖与已建立的机制、生物学原理
- **申办者**：学术与行业、试验设计质量
- **后勤**：距试验地点的距离、就诊频率、自付费用

### 共同决策

* *告知患者**
- 无需治疗的自然史
- 带证据、益处、风险的标准治疗选择
- 临床试验选项（如果可用）
- 护理目标调整
- 患者价值观和偏好

* *决策辅助**
- 效益的视觉表示（图标阵列）
- 治疗计算所需的数量
- 生活质量权衡
- 决策冲突尺度

## 质量指标

### 治疗建议质量指标

- 为所有建议提供证据分级
- 同等证据时提出多个选项存在
- 明确描述毒性概况
- 指定监测计划
- 包括剂量修改指南
- 针对特殊人群（老年人、肾/肝损伤）
- 适当时提及的临床试验选项
- 记录共享决策
- 与以下一致的护理目标治疗强度
