# 临床报告质量保证清单

## 一般质量标准

### 完整性
- [ ]提供所有必填部分
- [ ]无空白字段或缺失信息
- [ ]包括所有相关临床信息
- [ ]事件时间表清晰完整
- [ ]全部记录诊断测试和结果
- [ ]记录所有治疗和干预
- [ ]指定随访计划

### 准确性
- [ ]患者人口统计数据正确
- [ ]日期和时间准确
- [ ]具有正确单位和参考的实验室值范围
- [ ]药物名称、剂量和频率正确
- [ ]诊断编码正确 (ICD-10)
- [ ]程序编码正确（CPT 如果适用）
- [ ]无矛盾信息

### 清晰度
- [ ]清晰、专业的语言
- [ ]正确使用医学术语
- [ ]仅定义或标准的缩写
- [ ]逻辑组织和流程
- [ ]清晰（如果手写）
- [ ]无歧义陈述
- [ ]临床推理清晰解释

### 及时性
- [ ]实时记录或在遇到后不久记录
- [ ] 24-48 小时内完成出院总结
- [ ]立即传达关键结果
- [ ]监管报告截止日期met

## 病例报告质量检查表

### CARE 指南合规性
- [ ]标题包括“病例报告”
- [ ]提供关键词（2-5 个 MeSH 术语）
- [ ]包含所有元素的结构化摘要
- [ ]简介解释新颖性
- [ ]患者信息呈现和去识别化
- [ ]临床发现记录
- [ ]提供时间线（表格或图）
- [ ]详细诊断评估
- [ ]描述治疗干预措施
- [ ]报告随访和结果
- [ ]与文献综述进行讨论
- [ ]包括患者观点（如果可能）
- [ ]提供知情同意声明

### 隐私和道德
- [ ]已获得并记录知情同意
- [ ]删除所有 18 个 HIPAA 标识符
- [ ]删除或近似日期
- [ ]正确报告的年龄（>89 总计）
- [ ]仅限于州的地理信息
- [ ]图像已去识别化或已同意
- [ ] IRB 批准（如果适用）

### 科学质量
- [ ]明确确立新颖性
- [ ]文献检索综合
- [ ]考虑鉴别诊断
- [ ]解决因果关系
- [ ]承认局限性
- [ ]学习要点可操作
- [ ]当前和相关参考文献

- --

## 临床试验报告质量检查清单

### SAE 报告检查清单
- [ ]所有管理信息完整
- [ ]受试者去识别化（仅ID 号）
- [ ]详细事件描述
- [ ]应用MedDRA 编码
- [ ]严重性标准记录
- [ ]评估严重程度
- [ ]指定结果
- [ ]完成因果关系评估并说明理由
- [ ]确定预期
- [ ]使用研究药物采取的行动记录
- [ ]事件治疗描述
- [ ]叙述全面且按时间顺序
- [ ]传达关键发现（如果适用）
- [ ]满足监管时间表（7 天、15 天）

### 临床研究报告 (CSR)检查清单
- [ ]遵循 ICH-E3 结构
- [ ]概要完整且准确
- [ ]所有章节编号正确
- [ ]缩写定义
- [ ]记录伦理批准
- [ ]研究者名单完整
- [ ]明确描述研究设计
- [ ]合理样本量
- [ ]指定统计方法
- [ ]包含CONSORT图
- [ ]基线人口统计表
- [ ]主要终点结果
- [ ]所有次要终点报告终点
- [ ]不良事件总结
- [ ]包括个别SAE叙述
- [ ]提出讨论和结论
- [ ]附录完整（方案、CRF等）

## 诊断报告质量检查清单

### 放射学报告
- [ ]患者人口统计资料完整
- [ ]记录临床适应症
- [ ]记录比较研究
- [ ]描述技术
- [ ]系统和全面的结果
- [ ]提供的测量结果异常
- [ ]印象总结主要发现
- [ ]回答临床问题
- [ ]指定建议
- [ ]传达关键结果
- [ ]如果适用，使用结构化报告（BI-RADS、Lung-RADS 等）
- [ ]报告签名并注明日期

### 病理报告
- [ ]标本标记正确
- [ ]提供临床病史
- [ ]详细大体描述
- [ ]显微镜描述全面
- [ ]诊断明确且具体
- [ ]完成癌症分期（如果适用）
- [ ]记录切缘 
- [ ]量化淋巴结 
- [ ]用于癌症的概要报告（CAP 方案）
- [ ]包括免疫组织化学结果 
- [ ]包括分子结果，如果适用
- [ ]病理学家签署的报告

### 实验室报告
- [ ]记录样本类型
- [ ]记录收集时间
- [ ]结果单位
- [ ]提供参考范围
- [ ]标记的临界值
- [ ]传达的临界值
- [ ]样本质量注明
- [ ]指定的方法（如果相关）
- [ ]提供的解释（如果适用）
- [ ]分配的LOINC代码（用于互操作性）
- [ ]签署并注明日期的报告

- [ ]安排后续
- [ ]文档支持计费级别
- [ ]签名、注明日期和计时

### 病史和体检(H&P)

- [ ]详细 HPI

- [ ]既往手术史 
- [ ]药物调和 
- [ ]过敏记录 
- [ ]家族史

- [ ]每个问题的评估和计划

- [ ]医院病程叙述
- [ ]执行的程序
- [ ]出院药物协调 
- [ ]明确标记新的/更改的/停用的药物 
- [ ]出院情况 
- [ ]出院处置 
- [ ]随访预约 
- [ ]患者说明 
- [ ]返回预防措施
- [ ]记录待处理测试
- [ ]代码状态
- [ ]在 24-48 小时内完成
- [ ]发送给门诊提供者

### HIPAA合规性
- [ ]仅披露最低必要的 PHI
- [ ] PHI 安全和受保护
- [ ]获得患者授权（如果需要）
- [ ]业务伙伴协议（如果适用）
- [ ]维护审计跟踪（电子记录）
- [ ]违规通知程序遵循
- [ ]正确进行去标识化

### FDA/ICH-GCP 合规性（临床试验）
- [ ]遵循GCP 原则
- [ ]记录知情同意书
- [ ] IRB 批准当前
- [ ]遵守协议记录
- [ ]源文件充足
- [ ]满足ALCOA-CCEA原则
- [ ] 21 CFR Part 11合规性（电子记录）
- [ ]满足安全报告时间表
- [ ]基本文件维护

## 文档完整性检查表

### 法律和道德标准
- [ ]记录事实，而非意见
- [ ]相关时患者报价
- [ ]客观记录不合规情况
- [ ]未对原始记录进行任何更改
- [ ]用于更正的附录
- [ ]附录明确标记
- [ ]所有条目均签名并注明日期
- [ ]作者身份清晰

### 计费和编码支持
- [ ]记录医疗必要性
- [ ]记录护理复杂性
- [ ]记录时间（如果基于时间）计费）
- [ ] ICD-10 代码适当且具体
- [ ] CPT 代码与记录的服务相匹配
- [ ]修饰符适当
- [ ]文档支持计费的服务级别

## 最终审查清单

最终确定之前任何临床报告：

- [ ]通读整个文档
- [ ]检查完整性
- [ ]验证所有数据准确性
- [ ]确保逻辑流程
- [ ]检查拼写和语法
- [ ]验证患者标识符是否正确（或删除，如果去识别化）
- [ ]确保遵守法规
- [ ]确认所有必需的签名
- [ ]验证正确的分发
- [ ]适当地归档副本
