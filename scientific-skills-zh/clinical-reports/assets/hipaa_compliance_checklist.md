# 临床报告的 HIPAA 合规检查表

## 18 HIPAA 标识符 - 去识别检查表

验证以下所有标识符均已删除或更改：

- [ ] **1。姓名** - 患者姓名、家庭成员、医疗保健提供者（除非必要和同意）

- [ ] **2。小于州的地理分区**
  - 无街道地址
  - 无城市（除非人口>20,000，如果>20,000，则可以保留邮政编码的一部分）
  - 无县 
  - 仅当地理单位> 20,000 人时才可接受邮政编码的前 3 位数字
  - 邮政编码的所有其他部分已删除邮政编码

- [ ] **3。日期**（年份除外）
  - 无确切的出生日期（仅接受年份；>89 的出生年份必须汇总）
  - 无入院日期
  - 无出院日期
  - 无就职日期
  - 无死亡日期
  - 使用相对时间段（例如，“3 个月”）之前”）或仅年份

- [ ] **4。电话号码**
  - 没有任何类型的电话号码
  - 包括患者、家人、提供者联系号码

- [ ] **5。传真号码**
  - 无传真号码

- [ ] **6。电子邮件地址**
  - 没有患者或相关个人的电子邮件地址

- [ ] **7。社会安全号码**
  - 无 SSN 或部分 SSN

- [ ] **8。医疗记录编号**
  - 无 MRN、医院 ID 或诊所编号
  - 如果需要，请使用编码研究 ID 或病例编号

- [ ] **9。健康计划受益人号码**
  - 无保险 ID 号码
  - 无保单号码

- [ ] **10。帐号**
  - 无计费帐号
  - 无财务帐户信息

- [ ] **11。证书/执照号码**
  - 无驾驶执照号码
  - 无专业执照号码（除非作者凭证）

- [ ] **12。车辆标识符和序列号**
  - 无车牌号码
  - 无车辆识别号码

- [ ] **13。设备标识符和序列号**
  - 无起搏器序列号
  - 无植入设备序列号
  - 可接受的通用设备描述（例如“植入式心脏复律除颤器”）

- [ ] **14。 Web URL**
  - 没有个人网站
  - 没有识别个人的 URL

- [ ] **15。 IP 地址**
  - 无 IP 地址

- [ ] **16。生物识别标识符**
  - 无指纹
  - 无声纹
  - 无视网膜扫描
  - 无其他生物识别数据

- [ ] **17。全脸照片和类似图像**
  - 未经同意不得拍摄全脸照片
  - 如果显示脸部，则裁剪或模糊脸部
  - 删除识别特征（珠宝、纹身、胎记，如果与临床无关）
  - 眼睛上的黑条不够
  - 确保没有反射或背景识别

- [ ] **18。任何其他独特的识别特征或代码**
  - 没有可以识别个体的独特特征
  - 没有可以识别的罕见疾病组合
  - 考虑剩余数据点的组合是否可以识别个体

## 其他去识别考虑因素

### 年龄和日期

- [ ]年龄 ≤ 89 岁的患者：可接受的确切年龄或年龄范围
- [ ]年龄 > 89 岁的患者：必须汇总为“90 岁或以上”或“> 89 岁”
- [ ]日期：仅使用年份或使用相对时间段
  - 示例：“就诊前 3 个月”而不是“1 月 15 日， 2023"
  - 示例：“2023 年入学”而不是“2023 年 3 月 10 日入学”

### 地理信息

- [ ]可接受州或国家
- [ ]删除了特定城市（除非人口 >20,000 并且没有其他识别信息）信息）
- [ ]删除医院/诊所名称
- [ ]使用一般描述符：“中西部的社区医院”或“三级护理中心”

### 罕见病症和组合

- [ ]考虑是否仅通过非常罕见的疾病就可以识别患者
- [ ]考虑以下组合是否可以识别患者：
  - 年龄 + 诊断 + 地理区域 + 时间范围可以识别患者 
- [ ]可能需要对某些独特的细节含糊不清 
- [ ]提供临床信息和保护隐私之间的平衡

### 图像和图

- [ ]从图像标题/元数据中删除所有患者标识符
- [ ]删除DICOM数据
- [ ]从图像中删除日期
- [ ]删除医疗记录编号
- [ ]面部被裁剪、模糊或遮挡
- [ ]识别标记移除或遮盖：
  - 纹身
  - 珠宝
  - 胎记或独特的疤痕（如果与临床无关）
- [ ]比例尺和注释不包含识别信息
- [ ]背景环境已取消识别（房间号、铭牌、等）

### 语音和视频

- [ ]不得录制患者声音（除非获得同意）
- [ ]没有视频显示可识别特征（除非获得同意）
- [ ]如果需要视频，必须遮挡面部

## 知情同意清单（用于病例报告/出版物）

### 同意要求

- [ ]在提交出版物之前获得知情同意
- [ ]直接从患者处获得同意（如果有能力）
- [ ]如果患者死亡或丧失行为能力，则需获得法定代表人或近亲的同意
- [ ]对于儿科病例，已获得父母/监护人同意

### 同意书要素

知情同意书必须包括：

- [ ]出版目的（教育、医学知识）
- [ ]将出版什么（病例详细信息、图像、结果）
- [ ]期刊或出版地点（如果已知）
- [ ]开放获取与订阅（公开可用）
- [ ]去识别化工作说明
- [ ]重新识别的可能性已确认
- [ ]对临床护理无影响
- [ ]撤回同意书的权利（时间限制）
- [ ]问题联系信息
- [ ]患者签名和日期
- [ ]见证人签名（如果需要）

### 同意书文件

- [ ]文件中签署的同意书
- [ ]向患者提供副本
- [ ]可供编辑审阅的同意书
- [ ]手稿中的声明，确认已获得同意

* *手稿声明示例：**
“已从患者处获得书面知情同意书，以发表本病例报告和任何随附图像。书面知情同意书的副本同意书可供本期刊主编根据要求进行审查。“

## 最低必要标准

### 使用和披露

- [ ]仅使用达到目的所需的最低 PHI
- [ ]明确规定披露目的 
- [ ]仅限于相关信息 
- [ ]考虑去识别化数据或有限数据集作为替代方案 

### 最低必要条件的例外 

最低必要条件不适用于：
- 治疗目的（提供者可能需要完整信息）
- 患者授权的披露
- 法律要求的披露
- 向 HHS 披露以进行合规调查

## 授权使用/披露 PHI

### 需要授权时

需要授权用于：
- [ ]研究（除非获得 IRB 豁免）
- [ ]营销目的
- [ ]出售 PHI
- [ ]心理治疗说明
- [ ]治疗、付款、手术之外的用途 (TPO)

### 授权元素

如果需要授权，则必须包括：

- [ ]要使用/披露的PHI的具体描述
- [ ]授权披露的人员
- [ ]接收信息的人员
- [ ]披露的目的
- [ ]到期日期或事件
- [ ]撤销权及如何
- [ ]拒绝签名权
- [ ]接收者重新披露的可能性
- [ ]患者签名和日期

## 有限数据集

### 有限数据集选项

A 有限数据集删除 18 个标识符中的 16 个，但可能保留：
- [ ]日期（入院、出院、服务、出生、死亡）
- [ ]地理信息（城市、州、邮政编码）

### 有限数据集的要求

- [ ]数据使用协议 (DUA)必填
- [ ] DUA 指定允许的用途
- [ ]仅用于研究、公共卫生或医疗保健操作
- [ ]接收者同意不重新识别
- [ ]接收者同意保护数据

## 违规通知检查表

### 如果发生未经授权的泄露

- [ ]确定是否发生违规（未经授权的访问/使用/披露）
- [ ]评估对个人造成伤害的风险
- [ ]如果违规影响 <500 人：
  - 在 60 天内通知个人 
  - 每年向 HHS 报告
- [ ]如果违规影响 ≥ 500 人个人：
  - 在 60 天内通知个人
  - 在 60 天内通知 HHS
  - 如果在州/管辖区影响 ≥500 人，则通知媒体
- [ ]文件违规和响应
- [ ]实施纠正措施

### 违规通知内容

通知必须包括：
- [ ]违规描述
- [ ]涉及的信息类型
- [ ]个人应采取的步骤
- [ ]组织正在做什么
- [ ]联系方式问题
