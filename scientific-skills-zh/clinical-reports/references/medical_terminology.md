# 医学术语和编码标准

## 标准命名系统

### SNOMED CT（系统化医学命名法 - 临床术语）

* *目的：** 电子健康记录的综合临床术语

* *覆盖范围：**
- 临床发现
- 症状
- 诊断
- 程序
- 身体结构
- 生物体
- 物质
- 药品
- 标本

* *结构：**
- 具有独特的概念标识符
- 描述（首选和同义词）
- 概念之间的关系
- 分层组织

* *示例：**
- 概念：心肌梗死
- SNOMED CT 代码： 22298006
- 父级：心脏病
- 子级：急性心肌梗塞、陈旧性心肌梗塞

* *好处：**
- 实现语义互操作性
- 支持临床决策支持
- 促进数据分析
- 国际标准

### LOINC（逻辑观察标识符名称和代码）

* *用途：**用于实验室和临床观察的通用代码系统

* *LOINC代码的组成部分：**
1. **组分**（分析物或测量值）：测量的内容
2. **性质**：
3有什么特性（质量、体积等）。 **计时**：测量时（时间点，24小时）
4. **系统**：标本或系统（血清、尿液、动脉血）
5. **规模**：结果类型（定量、有序、名义）
6. **方法**：测量方法（与解释相关时）

* *示例：**
- **血清或血浆中的葡萄糖[质量/体积]**：2345-7
  - 组分：葡萄糖
  - 属性：质量浓度
  - 时间：点time
  - 系统：血清/血浆
  - 量表：定量

  - **血液中 A1c 血红蛋白/血红蛋白总含量**：4548-4
  - 成分：A1c 血红蛋白/血红蛋白总含量
  - 属性：质量分数
  - 计时：时间点
  - 系统：血液
  - 规模：定量

* *LOINC 部分：**
- 文档类型
- 调查仪器
- 临床附件
- 放射学代码
- 病理学代码

### ICD-10-CM（国际疾病分类，第10 次修订版，临床修改）

* * 用途：**用于计费、流行病学和健康统计的诊断和程序编码

* *结构：**
- 字母数字代码（3-7个字符）
- 第一个字符：字母（U除外）
- 字符2-3：数字
- 字符4-7：字母数字（第三位后的十进制）字符）
- 指定的偏侧性、严重程度、遭遇类型

* *代码结构示例：**
- **S72.001A**：右股骨颈未指定部分骨折，初次遭遇
  - S：损伤类别
  - 72：股骨
  - 001：颈部未指定部分
  - A：闭合性骨折初次遭遇
  - 右侧第5个位置用1表示

* *常见类别：**
- A00-B99：传染病
- C00-D49：肿瘤
- E00-E89：内分泌、营养、代谢
- F01-F99：精神和行为
- G00-G99：神经系统
- I00-I99：循环系统
- J00-J99：呼吸系统
- K00-K95：消化系统
- M00-M99：肌肉骨骼
- N00-N99：泌尿生殖系统
- S00-T88：损伤、中毒

* *第七个字符扩展：**
- A：初始遭遇
- D：后续遭遇
- S：后遗症

* *占位符X：**
- 当代码需要第7个字符但少于6个字符时使用
- 示例：T36.0X5A（青霉素的不良反应，初始遇到）

* *组合代码：**
- 描述两种诊断或有表现的诊断的单一代码
- 示例：E11.21（2型糖尿病合并糖尿病肾病）

### CPT（当前程序术语）

* *目的：**程序和服务编码计费

* *维护者：** 美国医学会（AMA）

* *类别：**
- **类别 I**：程序和服务（5 位数字代码）
- **类别 II**：绩效测量（4 位数字 + F）
- **类别 III**：新兴技术（4 位数字 + T）

  * *类别 I 部分：**
- 00100-01999：麻醉
- 10000-69990：手术
- 70000-79999：放射学
- 80000-89999：病理学和实验室
- 90000-99999：医学
- 99000-99607：评估和管理（E/M）

* *E/M 代码（常用）：**
- **99201-99215**：办公室就诊（新增和已建立）
- **99221-99239**：医院住院患者服务
- **99281-99285**：急诊科就诊
- **99291-99292**：重症监护
- **99304-99318**：护理设施服务

* *修饰符：**
- CPT 附加两位数代码代码
- 表示服务已更改但未更改
- 示例：
  - -25：重要的、可单独识别的E/M 服务
  - -50：双边程序
  - -59：独特的程序服务
  - -76：重复相同的程序医师
  - -RT/LT：右侧/左侧

### RxNorm

* *用途：**临床药物和给药装置的标准化名称

* *结构：**
- 包括品牌和通用名称
- 剂型
- 优点
- 链接到其他药物词汇（NDC、SNOMED CT）

* *示例：**
- 概念：阿莫西林 500 MG 口服胶囊
- RxNorm CUI：308191
- 成分：阿莫西林
- 规格：500 MG
- 剂型：口服胶囊

## 医学缩写

### 可接受的标准缩写

* *时间：**
- q：每一次（q4h = 每4小时）
- qd：每天（避免 - 使用“每天”）
- bid：每天两次 
- tid：每天三次 
- qid：每天四次 
- qhs：就寝时间 
- prn：根据需要 
- ac：之前餐
- pc：饭后
- hs：睡前

* *路线：**
- PO：口服（经口）
- IV：静脉注射
- IM：肌肉注射
- SC/SQ/subcut：皮下
- SL：舌下
- PR：经直肠
- NG：鼻胃管
- GT：胃造口管
- TD：透皮
- inh：吸入

* *频率：**
- 状态：立即
- 现在：立即
- 连续：不间断
- PRN：根据需要

* *实验室：**
- CBC：全血细胞计数
- BMP：基础代谢组
- CMP：综合代谢组
- LFT：肝功能检查
- PT/INR：凝血酶原时间/国际标准化比值
- PTT/aPTT：部分凝血活酶时间/活化PTT
- ESR：红细胞沉降率
- CRP：C反应蛋白
- ABG：动脉血气
- UA：尿液分析
- HbA1c：血红蛋白 A1c

* *诊断：**
- HTN：高血压
- DM：糖尿病
- CHF：充血性心力衰竭
- CAD：冠状动脉疾病
- COPD：慢性阻塞性肺疾病
- CVA：脑血管意外
- MI：心肌梗塞
- PE：肺栓塞
- DVT：深静脉血栓
- UTI：尿路感染
- CKD：慢性肾脏病
- ESRD：终末期肾病疾病

* *体检：**
- HEENT：头、眼、耳、鼻、喉
- PERRLA：瞳孔等长、圆形、对光和调节有反应
- EOMI：眼外运动完好
- JVP：颈静脉压
- RRR：正常频率和节律
- CTAB：双侧听诊清晰
- BS：肠鸣音或呼吸音（上下文相关）
- NT/ND：无压痛、无膨胀
- FROM：全范围运动

* *生命体征：**
- BP：血液压力
- HR：心率
- RR：呼吸频率
- T 或Temp：温度
- SpO2：氧饱和度
- Wt：体重
- Ht：身高
- BMI：体重指数

### Do不使用缩写（联合委员会）

* *禁止缩写：**

|缩写|预期含义|问题 |使用 |
|--------------|--------------------|---------|-------------|
|你|单位|误认为 0、4 或 cc |写“单位”|
| IU |国际单位|误认为 IV 或 10 |写“国际单位”|
| Q.D.，QD，q.d.，qd |每日 |误认为彼此|写“每日”|
| Q.O.D.，QOD，q.o.d.，qod |每隔一天 |误认为 QD 或 QID |写“每隔一天”|
|尾随零 (X.0 毫克) | X 毫克 |小数点漏掉了 |切勿在小数点后写零（写 X 毫克）|
|缺少前导零 (.X mg) | 0.X 毫克 |小数点漏掉了 |始终在小数点前写零（写 0.X mg）|
| MS、MSO4、MgSO4 |硫酸吗啡或硫酸镁|彼此迷茫|写“硫酸吗啡”或“硫酸镁”|

* *其他有问题的缩写：**
- µg：微克（误认为毫克）→写“mcg”
- cc：立方厘米→写“mL”
- hs：半强度或睡眠小时→写“半强度”或“就寝时间” 
- TIW：每周三次 → 写“每周三次” 
- SC、SQ：皮下 → 写“亚切”或“皮下” 
- D/C：出院或停止 → 写全字 
- AS、AD、AU：左耳、右耳、双耳 → 写“左耳”、“右耳” “双耳”
- OS、OD、OU：左眼、右眼、双眼→写“左眼”、“右眼”、“双眼”

## 药物命名法

### 通用名称与品牌名称

* *最佳实践：** 在医疗中使用通用名称文档

* *示例：**
- 对乙酰氨基酚（非专利）与泰诺（品牌）
- 布洛芬（非专利）与 Advil、美林（品牌）
- 阿托伐他汀（非专利）与立普妥（品牌）
- 二甲双胍（非专利）与二甲双胍（非专利）对比Glucophage（品牌）
- Lisinopril（仿制药）与 Zestril、Prinivil（品牌）

* *何时包含品牌：**
- 患者教育（认可）
- 无仿制药的新药
- 具有生物等效性问题的窄治疗指数药物
- 生物制品

## 实验室单位和换算

### 常用实验室单位

* *血液学：**
- 红细胞：× 10⁶/μL 或× 10^2/L
- 白细胞：× 103/μL 或 × 10⁹/L
- 血红蛋白：g/dL 或 g/L
- 血细胞比容：% 或分数
- 血小板：× 103/μL 或 × 10⁹/L
- MCV：fL
- MCHC：g/dL 或 g/L

* *化学成分：**
- 葡萄糖：mg/dL 或 mmol/L
- BUN：mg/dL 或 mmol/L
- 肌酐：mg/dL 或 μmol/L
- 钠、钾、氯化物：mEq/L 或 mmol/L
- 钙：mg/dL 或 mmol/L
- 白蛋白：g/dL 或 g/L
- 胆红素：mg/dL 或 μmol/L
- 胆固醇：mg/dL 或 mmol/L

* *治疗药物水平：**
- 通常：mcg/mL、ng/mL 或 μmol/L

### 单位换算（选定）

* *葡萄糖：**
- mg/dL ÷ 18 = mmol/L
- mmol/L × 18 = mg/dL

* *肌酐：**
- mg/dL × 88.4 = μmol/L
- μmol/L ÷ 88.4 = mg/dL

* *胆红素：**
- mg/dL × 17.1 = μmol/L
- μmol/L ÷ 17.1 = mg/dL

* *胆固醇：**
- mg/dL × 0.0259 = mmol/L
- mmol/L × 38.67 = mg/dL

* *血红蛋白：**
- g/dL × 10 = g/L
- g/L ÷ 10 = g/dL

## 分级和分期系统

### 癌症分期 (TNM)

* *T（原发性肿瘤）：**
- TX：无法评估
- T0：无原发性证据肿瘤
- Tis：原位癌
- T1-T4：原发肿瘤的大小和/或范围

* *N（区域淋巴结）：**
- NX：无法评估
- N0：无区域淋巴结转移
- N1-N3：区域淋巴结受累

* *M（远处转移）：**
- M0：无远处转移
- M1：存在远处转移

* *分期分组：**
- 0 期：Tis N0 M0
- I-III 期：各种 T 和 N 组合，M0
- IV 期：任何 T、任何 N、M1

### NYHA 心力衰竭分类 

- **I 级**：无限制。普通体力活动不会引起症状
- **II 级**：轻微限制。休息时舒适，普通活动引起症状
- **III 级**：明显限制。休息舒适，低于正常活动导致症状
- **IV 级**：无法在没有症状的情况下进行任何体力活动。静息时症状

### Child-Pugh 评分（肝脏疾病）

* *参数：** 胆红素、白蛋白、INR、腹水、脑病

* *类别：**
- **A 级（5-6 分）**：补偿良好
- **B 级（7-9 分）**：显着的功能损害
- **C 级（10-15 分）**：失代偿

### 格拉斯哥昏迷量表

* *开眼度 (1-4)：**
- 4：自发性
- 3：至言语
- 2: 疼痛
- 1: 无

* *言语反应 (1-5):**
- 5: 定向 
- 4: 困惑 
- 3: 不恰当的词语
- 2: 难以理解的声音
- 1: 无

* *运动反应 (1-6):**
- 6：服从命令
- 5：定位疼痛
- 4：退出疼痛
- 3：异常屈曲
- 2：伸展
- 1：无

* *总分：** 3-15（3 = 最差，15 =最好）
- 重度：≤8
- 中度：9-12
- 轻度：13-15

## 医学前缀和后缀

### 常见前缀

- **a-/an-**：无、缺席（贫血、失语症）
- **brady-**：缓慢（心动过缓）
- **dys-**：异常、困难（呼吸困难、排尿困难）
- **hyper-**：过度、高于（高血压、高血糖）
- **hypo-**：低于、缺乏（低血压、低血糖）
- **多-**：多（多尿、烦渴）
- **心动过速-**：快（心动过速、呼吸急促）
- **宏观-**：大（大头畸形）
- **微观-**：小（小头畸形）
- **hemi-**：一半（偏瘫）
- **bi-/di-**：两个（双侧、复视）

### 常用后缀

- **-痛觉**：疼痛（关节痛、神经痛）
- **-切除**：手术切除（阑尾切除术、胆囊切除术）
- **-emia**：血液状况（贫血、白血病）
- **-itis**：炎症（阑尾炎、关节炎）
- **-oma**：肿瘤（癌、黑色素瘤）
- **-osis**：异常状况（肝硬化、骨质疏松）
- **-病**：疾病（神经病、肾病）
- **-减少**：缺陷（血小板减少、中性粒细胞减少）
- **-整形**：手术修复（鼻整形、血管成形）
- **-镜检**：目视检查（结肠镜、支气管镜）
- **-stomy**：手术开口（结肠造口术、气管造口术）
