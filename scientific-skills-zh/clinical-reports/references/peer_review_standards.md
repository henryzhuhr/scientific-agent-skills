# 临床手稿同行评审标准

## 临床手稿同行评审概述

### 目的

同行评审确保临床手稿在出版前符合科学严谨性、道德行为和清晰沟通的标准。

* *目标：**
- 评估科学有效性和方法
- 评估临床意义
- 验证道德合规性
- 确保清晰度和完整性
- 提高稿件质量

* *同行评审类型：**
- 单盲（审稿人认识作者，作者不认识审稿人）
- 双盲（双方匿名）
- 开放同行评审（双方均已知）
- 发表后同行评审

### 审稿人职责

* *仅在以下情况下接受评审：**
- 在主题领域合格
- 无利益冲突
- 有足够的时间（通常为 2-3）周）
- 可以提供建设性的、公正的评价

* *维护机密：**
- 不分享稿件内容
- 不利用信息谋取个人利益
- 未经编辑许可不要涉及他人

* *提供及时审阅：**
- 在要求内完成时间范围
- 如果无法完成，请立即通知编辑

## 病例报告审核标准

### CARE 指南合规性

* *验证稿件包括：**
- [ ]标题将其标识为病例报告
- [ ]提供的关键字 (2-5)
- [ ]结构化或非结构化摘要
- [ ]介绍解释为何病例为新颖
- [ ]患者信息（去识别化）
- [ ]临床发现
- [ ]事件时间表
- [ ]诊断评估
- [ ]治疗干预措施
- [ ]随访和结果
- [ ]文献综述讨论
- [ ]患者视角（如果适用）
- [ ]知情同意书

### 新颖性和意义

* *评估：**
- 这个病例真的新颖吗？或者它是否增加了医学知识？
- 是什么让这个病例值得报告？
- 这种情况是否罕见或表现不寻常？
- 它是否挑战现有知识？
- 是否有可以推广的临床经验？

* *红色标志：**
- 常见情况的共同呈现
- 没有独特特征的单一病例
- 单一病例的过度概括
- 缺乏显示新颖性的文献综述

### 隐私和道德考虑

* *验证：**
- 获得知情同意并记录
- 患者充分去识别化（删除了18个HIPAA标识符）
- 未经明确同意，没有可识别的图像
- 删除或近似的日期
- 仅限于州/国家的地理信息
- 适当的年龄（确切的年龄或范围）
- 机构标识符已删除

* *道德问题：**
- 缺少同意文件
- 存在可识别信息
- 缺乏IRB 批准进行回顾性图表审查（如果适用）
- 没有额外保护的弱势群体

### 临床质量

* *诊断过程：**
- 针对出现症状进行适当的检查
- 考虑鉴别诊断
- 最终诊断的逻辑进展
- 充分记录结果

* *治疗：**
- 循证医学干预措施
- 治疗选择的理由
- 考虑的替代治疗
- 适当的监测和随访

* *结果：**
- 临床结果的清晰描述
- 适当的随访时间
- 并发症记录
- 如果可用的话，长期结果

### 文献综述

* *评估：**
- 对现有文献进行充分搜索
- 识别和讨论类似病例
- 当前对所审查病情的理解
- 案例适当背景化
- 参考当前和相关
- 与先前案例的比较

### 写作质量

* *结构：**
- 逻辑流程和组织
- 遵循 CARE 指南结构
- 清晰、简洁的写作
- 适当的医学术语

* * 清晰度：**
- 医学术语解释
- 时间线清晰易懂遵循
- 事件的年表逻辑
- 由案例细节支持的结论

## 临床试验手稿审查标准

### 研究设计和方法

* *评估：**
- 研究问题的适当研究设计
- 明确的目标和假设
- 明确的主要和次要终点
- 具有功效计算的足够样本量
- 适当的随机化和盲法
- 适当的对照组

* *危险信号：**
- 终点的事后更改
- 动力不足的研究声称等价
- 不适当的统计方法
- 可行时缺乏盲法
- 注册中的选择偏差

### CONSORT合规性

* *验证：**
- 标题标识为随机试验
- 结构化摘要
- 试验注册提供的数量
- 可访问的协议
- 包括CONSORT 流程图
- 基线特征表
- 报告的所有结果（不仅仅是重要的结果）
- 报告的不良事件
- 披露的资金来源
- 利益冲突声明

### 随机化和分配

* *评估：**
- 充分的序列生成方法
- 分配隐藏适当
- 基线特征平衡
- 指定的分层因子
- 交叉和协议偏差记录

### 参与者流程

* *验证：**
- 报告的筛选人数
- 提供的排除原因
- 随机清除的人数
- 记录的辍学和原因
- 最小化失访并解释
- 指定 ITT 和按方案分析
- CONSORT 图完整且准确

### 结果测量

* *主要结果：**
- 明确定义先验 
- 具有临床意义 
- 适合研究问题 
- 可靠且有效地测量 
- 适当的统计分析 

* * 次要结果：**
- 中预先指定协议
- 适当分析
- 如果需要的话进行多重比较校正
- 如果动力不足则不会过度解释

* *探索性结果：**
- 明确标记为探索性或事后
- 没有给予与主要相同的权重
- 假设生成，不是确认

### 统计分析

* *评估：**
- 揭盲前指定的分析计划
- 适当的统计测试
- 验证假设（正态性等）
- 适当处理缺失数据
- 多重调整需要
- 提供置信区间
- 报告效应大小

* *常见问题：**
- p-hacking（选择性报告）
- 未经校正的多次测试
- 不适当的亚组分析
- 在ITT和每个方案之间切换分析
- 忽略缺失数据或处理不当

### 安全报告

* *验证：**
- 报告所有不良事件
- 详细说明严重不良事件
- 充分描述死亡情况
- 评估因果关系
- 实验室异常报告
- 因记录的AE而停药

### 临床意义

* *评估：**
- 统计显着性与临床显着性
- 具有临床意义的影响程度
- 需要治疗的数量(NNT)，如果适用
- 效益风险比有利
- 实践的普遍性
- 成本效益考虑

## 诊断研究审查标准

### STARD指南（报告诊断准确性研究的标准）

* *评估合规性：**
- 描述的研究设计
- 参与者选择标准
- 抽样方法
- 数据收集程序
- 定义的参考标准
- 详细描述的指数测试
- 盲法处理
- 参与者流程清除
- 提供2×2表
- 诊断准确性估计

### 参考标准

* *验证：**
- 使用适当的黄金标准
- 所有参与者使用相同的参考标准
- 无论指数测试结果如何都执行参考标准
- 之间的时间适当的指数测试和参考标准
- 指数测试和参考标准的独立解释

### 测试性能

* *所需指标：**
- 敏感性和特异性
- 阳性和阴性预测值（与患病率）
- 似然比
- ROC曲线和AUC（如果连续结果）
- 所有估计的 95% 置信区间

* *考虑：**
- 测试前和测试后概率
- 超出准确性的临床实用性
- 与现有测试的比较
- 成本和可用性

### 频谱和验证偏差

* *评估：**
- 包括疾病严重程度谱
- 避免谱偏差（仅限严重病例）
- 避免验证偏差（所有参与者获得参考标准）
- 避免差异验证（不同参与者有不同的参考标准）

## 观察性研究回顾标准

### STROBE指南（加强流行病学观察研究报告）

* *对于队列、病例对照或横断面研究，验证：**
- 标题和摘要确定研究设计
- 明确的背景和理由
- 指定的目标
- 方法中存在的研究设计
- 描述的设置
- 描述的参与者
- 明确定义的变量
- 数据来源和测量详细
- 解决偏差
- 研究规模合理
- 描述的统计方法
- 报告结果与效应大小和CI

### 暴露和结果评估

* *评估：**
- 明确暴露定义
- 结果明确定义
- 测量方法有效且可靠
- 尽可能对评估者设盲
- 各组之间的一致测量
- 暴露与结果之间的时间关系适当

### 混杂和偏差

* *验证：**
- 识别出潜在的混杂因素
- 在分析中调整混杂因素
- 讨论残留混杂因素
- 解决选择偏差
- 考虑信息偏差
- 敏感性分析执行

### 因果关系

* *Bradford Hill标准考虑：**
- 关联强度
- 研究之间的一致性
- 特异性
- 暂时性（暴露先于结果）
- 生物梯度（剂量-反应）
- 合理性
- 与现有知识的一致性
- 实验证据
- 类比

* *避免：**
- 没有强有力证据的观察性研究的因果语言
- 与因果关系

## 系统评价和荟萃分析评价标准

### PRISMA 指南

* *验证：**
- 标题标识为系统评价/荟萃分析
- 结构化摘要
- 研究问题（PICO 格式）
- 协议和注册（PROSPERO）
- 检索策略综合
- 研究选择过程描述
- 数据提取过程
- 质量纳入研究的评估
- 适当的合成方法
- 森林图结果
- 异质性评估
- 评估发表偏倚
- 证据的确定性（等级）

### 搜索策略

* *评估：**
- 多个数据库搜索
- 全面搜索术语
- 合理的限制和过滤器
- 考虑灰色文献
- 手动搜索参考文献
- 与作者联系以获取缺失数据
- 搜索可重现

### 研究选择

* *验证：**
- 预先指定的纳入/排除标准
- 由≥2名审稿人进行独立筛选
- 适当解决分歧
- PRISMA流程图完整
- 排除原因的研究

### 质量评估

* *评估：**
- 使用适当的质量评估工具
  - RCT：Cochrane 偏差风险工具
  - 观察：纽卡斯尔-渥太华量表
  - 诊断：QUADAS-2
- 独立质量评估
- 报告的质量评估结果
- 纳入合成的质量

### 统计方法

* *用于荟萃分析：**
- 固定与随机效应模型合理
- 异质性评估（I²，Q统计）
- 森林图提供
- 发表偏倚评估（漏斗图，艾格检验）
- 进行敏感性分析
- 预先指定的亚组分析

### 等级评估

* *证据质量：**
- 高：对效果非常有信心估计
- 中等：有中等信心
- 低：信心有限
- 极低：信心很小

* *降低确定性的因素：**
- 偏见风险
- 不一致
- 间接性
- 不精确
- 出版偏差

## 稿件质量评估

### 结构和组织

* *评估：**
- 从介绍到讨论的逻辑流程
- 适当组织的章节
- 图形和表格支持文本
- 适当的补充材料

### 写作质量

* *清晰度：**
- 清晰、简洁的语言
- 行话最小化和定义
- 首次使用时定义的缩写
- 一致的术语

* * 语法和风格：**
- 正确的语法和拼写
- 适当的动词时态（过去用于研究结果，现在用于既定事实）
- 适当时使用主动语态
- 简洁而不牺牲清晰度

### 参考文献

* *验证：**
- 足够数量的参考文献
- 当前文献包括
- 引用的关键论文
- 参考文献格式正确
- 参考文献列表中的所有引文，反之亦然
- 没有过多的自引

### 表格和图形

* *评估：**
- 适合数据类型
- 清晰的标签和图例
- 高质量图像
- 可以独立使用
- 与文本无冗余
- 统计符号正确

## 审查中的道德考虑

### 冲突兴趣

* *披露并回避，如果：**
- 与作者的个人关系
- 对结果的经济利益
- 竞争研究
- 对主题的强烈偏见
- 制度冲突

### 公平和建设性审查

* *提供：**
- 平衡评估优点和缺点
- 具体的、可操作的建议
- 尊重的语气
- 客观评价
- 认识到研究设计的局限性

* *避免：**
- 人身攻击
- 轻蔑的语言
- 要求无理修改
- 期望完美学习
- 将个人偏好强加于标准

### 保密

* *维护：**
- 请勿分享手稿
- 未经许可请勿与同事讨论
- 请勿使用想法或数据
- 审阅后销毁副本

## 推荐类别

* *接受：**
- 稿件符合出版标准
- 仅进行少量编辑

* *少量修改：**
- 可以解决的小问题
- 无需额外数据
- 通常是一轮修订

* *主要修订：**
- 需要进行实质性更改的重大问题
- 可能需要额外分析
- 可能需要额外数据或实验
- 通常重新审查

* * 拒绝：**
- 无法解决的基本缺陷已更正
- 新颖性或意义不足
- 不道德行为
- 欺诈数据

* *拒绝并重新提交：**
- 研究有潜力但需要大量工作
- 重大更改后本质上是新提交

## 撰写评论报告

### 结构

* *摘要：**
- 简要概述（2-3句话）
- 总体评估
- 主要优势（2-3分）
- 主要弱点（2-3分）
- 推荐

* *主要评论：**
- 编号
- 影响有效性、解释或影响的重大问题
- 具体且可操作
- 优先

* *次要评论：**
- 编号
- 编辑、格式或澄清问题
- 行特定注释
- 表格/图形注释

### 语气和语言

* *使用：**
- 专业、同事语气
- “作者声明...”而不是“您声明...”
- “这项研究表明...”而不是“你的研究”显示...“
- 建设性批评
- 改进建议

* *避免：**
- 严厉或轻蔑的语言
- 人称代词
- 讽刺
- 含糊批评
- 不合理要求

### 具体且可操作的反馈

* *好：**
“样本量计算（第8页）未考虑预期辍学率。请修改以包括预期辍学率并解释这如何影响入学目标。”

* *差：**
“样本量不足。”

* *好：**
“如果误差线代表 95% CI 而不是 SEM，图 2 会更清晰。请相应地修改和更新图例。”

* *差：**
“图 2 令人困惑。”
