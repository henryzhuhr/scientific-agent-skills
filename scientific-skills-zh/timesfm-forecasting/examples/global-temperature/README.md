## 调查结果

### 主要观察结果

1. **预计略有降温趋势**：该模型预测平均异常温度比 2024 年水平低 0.07°C，表明在 2023-2024 年破纪录气温之后可能会趋于稳定。

2. **保留季节模式**：预测显示了预期的季节变化，冬末（2 月至 3 月）异常较高，秋末（11 月至 12 月）异常较低。

3. **不确定性扩大**：90% CI 从 1 月的 ±0.04°C 扩大到 12 月的 ±0.08°C，反映了典型的预测不确定性随着时间的推移而增长。

4. **峰值温度**：预计 2025 年 3 月的最高异常为 1.30°C，可能接近 2023 年 9 月记录的 1.47°C。

### 局限性

- TimesFM 是一个没有物理气候模型约束的零样本预报器
- 36 个月的训练窗口可能无法捕获多个十年的气候趋势
- 厄尔尼诺/拉尼娜周期未明确建模

### 建议

- 使用此预测作为基于物理的气候模型的基线比较
- 随着新观测的出现，每季度更新预测
- 考虑将 TimesFM 与其他方法相结合的集合方法

## 技术说明

### API 发现

TimesFM PyTorch API 与 GitHub README 文档不同：

* *已记录(GitHub README):**
```python
model = timesfm.TimesFm(
    context_len=512,
    horizon_len=128,
    backend="gpu",
)
model.load_from_google_repo("google/timesfm-2.5-200m-pytorch")
```

* *实际工作 API:**
```python
hparams = timesfm.TimesFmHparams(horizon_len=12)
checkpoint = timesfm.TimesFmCheckpoint(
    huggingface_repo_id="google/timesfm-1.0-200m-pytorch"
)
model = timesfm.TimesFm(hparams=hparams, checkpoint=checkpoint)
```

### TimesFM 2.5 PyTorch Issue

`google/timesfm-2.5-200m-pytorch` 检查点下载为 `model.safetensors`，但是TimesFM 加载程序需要 `torch_model.ckpt`。这会在模型加载时导致 `FileNotFoundError`。使用 TimesFM 1.0 PyTorch 可以解决此问题。
