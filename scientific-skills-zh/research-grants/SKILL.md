# 研究资助写作

## 概述

研究资助写作是为联邦机构和基金会制定有竞争力的资助提案的过程。掌握 NSF（美国国家科学基金会）、NIH（美国国立卫生研究院）、DOE（能源部）、DARPA（国防高级研究计划局）和台湾 NSTC（国家科学技术委员会）提交的机构特定要求、审查标准、叙述结构、预算准备和合规性。

* *关键原则：赠款是有说服力的文件，必须同时证明科学严谨性、创新性、可行性和更广泛的内容** 每个机构都有必须解决的独特优先事项、审查标准、格式要求和战略目标。

## 何时使用此技能

此技能应在以下情况下使用：
- 为 NSF、NIH、DOE、DARPA 或 NSTC 项目撰写研究提案
- 准备项目描述、具体目标或技术叙述
- 开发更广泛的影响或意义陈述
- 创建研究时间表和里程碑计划
- 准备预算理由和人员分配计划
- 响应计划招标或资助公告
- 在重新提交中解决审稿人意见
- 规划多机构合作提案
- 编写初步数据或可行性部分
- 准备生物草图、简历或设施描述

## 科学示意图的视觉增强

* *⚠️强制：每项研究资助提案必须包括至少1-2个使用scientific-schematics技能的人工智能生成的图形。**

这不是可选的。没有视觉元素的拨款提案是不完整的且竞争力较差。在最终确定任何文件之前：
1. 至少生成一个原理图或图表（例如项目时间表、方法流程图或概念框架）
2. 更喜欢 2-3 个图表来获取综合提案（研究工作流程、甘特图、初步数据可视化）

* *如何生成图表：**
- 使用 **scientific-schematics** 技能生成人工智能驱动的出版物质量图表
- 用自然语言简单描述您想要的图表
- Nano Banana Pro 将自动生成、审查和完善原理图

* *如何生成原理图：**
```bash
python scripts/generate_schematic.py "your diagram description" -o figures/output.png
```

人工智能将自动：
- 以正确的格式创建出版质量的图像
- 通过多次迭代进行审查和完善
- 确保可访问性（色盲友好，高对比度）
- 将输出保存在图/目录

* *何时添加原理图：**
- 研究方法和工作流程图
- 项目时间表甘特图
- 概念框架图
- 系统架构图（用于技术提案）
- 实验设计流程图
- 更广泛的影响活动图表
- 协作网络图
- 任何受益于可视化的复杂概念

有关创建原理图的详细指导，请参阅scientific-schematics 技能文档。

## 机构特定概述

### NSF（国家科学基金会）基金会）
* *使命**：促进科学进步，促进国民健康、繁荣和福利

* *主要特点**：
- 智力优点+更广泛的影响（同等权重）
- 15页项目描述限制（大多数程序）
- 强调教育、多样性和社会效益
- 鼓励合作研究
- 强调开放数据和开放科学
- 优点评审过程与小组+临时审稿人

### NIH（美国国立卫生研究院）
* *使命**：增强健康，延长寿命，减少疾病和残疾

* *关键特征**：
- 具体目标（1页）+研究策略（R01 12页）
- 作为核心审评的意义、创新、方法标准
- R01s 通常需要初步数据
- 强调严谨性、可重复性和临床相关性
- 大多数R01s 的模块化预算（25 万美元增量）
- 多次重新提交机会

### DOE（能源部）能源）
* *使命**：通过能源、环境和核挑战确保美国的安全与繁荣

* *主要特点**：
- 专注于能源、气候、计算科学、基础能源科学
- 通常需要成本分摊或行业合作
- 强调国家实验室合作
- 强大的计算和实验集成
- 能源创新和商业化途径
- 因办公室而异（ARPA-E、科学办公室、EERE等）

### DARPA（国防高级研究计划局）
* *使命**：对国家安全的突破性技术进行关键投资

* *主要特点**：
- 高风险、高回报的变革性研究
- 专注于“DARPA难题”（如果是真的，谁在乎）
- 强调原型、演示和过渡路径
- 通常需要多个阶段（可行性、开发、演示）
- 强大的项目管理和里程碑跟踪
- 经常需要团队和协作
- 因项目经理和 BAA（广泛机构公告）而异很大 

### NSTC（国家科学技术委员会 - 台湾）
* *使命**：在台湾推进科学突破、工业应用和社会影响。

* *主要特征**：
- **CM03表格**：核心技术提案格式。
- **双语**：需要中英文摘要。
- **创新与可行性**：初步审查重点。
- **初步数据**：对可信度至关重要。
- **研究架构图**：清晰可见的强制性视觉元素。

## 核心研究提案的组成部分

### 1. 执行摘要/项目摘要/摘要

每项提案都需要一个简明的概述，向技术评审员和项目官员传达研究的基本要素。

* *目的**：提供独立的摘要，以捕获研究愿景、意义和方法

* *长度**：
- NSF：1页（项目摘要，包含单独的概述、智力优点、更广泛的影响）
- NIH：30 行（项目摘要/摘要）
- DOE：各不相同（通常为 1 页）
- DARPA：各不相同（通常为 1-2 页）

* *必要要素**：
- 问题或研究问题的清晰陈述
- 为什么这个问题很重要（重要性、紧迫性、影响）
- 新颖的方法或创新
- 预期成果和可交付成果
- 团队的资格
- 更广泛的影响或转化途径

* *写作策略**：
- 以引人注目的钩子开头，确立重要性
- 使用易于理解的语言（避免在开头句子中使用行话）
- 陈述具体的、可衡量的目标
- 传达热情和信心
- 确保每句话都增加价值（无填充物）
- 以变革性的愿景或影响力结束声明

* *要避免的常见错误**：
- 过于技术性或过于详细（除了项目描述）
- 未能阐明“为什么现在”或“为什么这个团队”
- 模糊的目标或结果
- 忽略更广泛的影响或意义
- 可适用于任何提案

### 2.项目描述/研究策略

详细介绍研究计划的核心技术叙述。

* *结构因机构而异：**

* *NSF项目描述**（通常为15页）：
- 简介和背景
- 研究目标和问题
- 初步结果（如果适用）
- 研究计划和方法
- 时间表和里程碑
- 更广泛的影响（整个或单独的部分综合）
- 先前的NSF支持（如果适用）

* *NIH研究策略**（12页R01):
- 意义（为什么问题很重要）
- 创新（什么是新颖的和变革性的）
- 方法（详细的研究计划）
  - 初步数据
  - 研究设计和方法
  - 预期结果
  - 潜在问题和替代方法

* *DOE项目叙述**（可变）：
- 背景和意义
- 技术方法和创新
- 资格和经验
- 设施和资源
- 项目管理和时间表

* *DARPA技术卷** （可变）：
- 技术挑战和创新
- 方法和方法论
- 时间表和里程碑
- 可交付成果和指标
- 团队资格
- 风险评估和缓解

有关具体机构的详细指导，请参阅：
- `references/nsf_guidelines.md`
- `references/nih_guidelines.md`
- `references/doe_guidelines.md`
- `references/darpa_guidelines.md`
- `references/nstc_guidelines.md`

### 3. 具体目标(NIH)或目标 (NSF/DOE/DARPA)

构成研究计划的清晰、可测试的目标。

* *NIH 具体目标页面**（1 页）：
- 开头段落：知识和意义之间的差距
- 长期目标和近期目标
- 中心假设或研究问题
- 2-4 个具体目标和子目标
- 预期结果和影响
- 回报段落：为什么这很重要

* *每个目标的结构：**
- 目标陈述（1-2 个句子，以行动动词开头）
- 基本原理（为什么这个目标，初步）数据支持）
- 工作假设（可检验的预测）
- 方法总结（简要方法概述）
- 预期结果和解释

* *写作策略**：
- 使目标独立但互补
- 确保每个目标在时间表和预算内可以实现
- 提供足够的细节来判断可行性
- 包括应急计划或替代方法
- 跨目标使用并行结构
- 明确说明将从每个目标中学到什么

有关详细指导，请参阅`references/specific_aims_guide.md`.

### 4.更广泛的影响（NSF）/意义(NIH)

阐明研究的社会、教育或转化价值。

* *NSF 更广泛的影响**（关键组成部分，与智力价值同等重要）：

NSF 明确评估更广泛的影响。至少寻址以下区域之一：
1. **在促进教学、培训和学习的同时促进发现和理解**
  - 研究与教育的融合
  - 学生和博士后培训
  - 课程开发
  - 教育材料和资源

2. **扩大代表性不足群体的参与**
  - 招募和保留策略
  - 与少数族裔服务机构的伙伴关系
  - 扩展到代表性不足的社区
  - 指导计划

3. **加强研究和教育基础设施**
  - 共享设施或仪器
  - 网络基础设施和数据资源
  - 社区范围的工具或数据库
  - 开源软件或方法

4. **广泛传播以增强科学和技术理解**
  - 公众宣传和科学传播
  - K-12教育计划
  - 博物馆展览或媒体参与
  - 政策简报或利益相关者参与

5. **对社会的好处**
  - 经济影响或商业化
  - 健康、环境或国家安全效益
  - 知情决策
  - 劳动力发展

  * * NSF更广泛影响的写作策略**：
  - 具体的具体活动，而不是模糊的陈述
- 为更广泛的影响活动提供时间表和里程碑
- 解释如何衡量和评估影响
- 连接到机构资源和现有计划
- 通过初步努力或合作伙伴关系表明承诺
- 与研究计划相结合（未附加）

* *NIH意义**：
- 解决重要问题或进展的关键障碍
- 提高科学知识、技术能力或临床实践
- 有可能带来更好的结果、干预措施或理解
- 该领域先前研究的严谨性
- 与NIH使命和研究所优先事项保持一致

对于详细指导，参见`references/broader_impacts.md`.

### 5.创新和变革潜力

阐明研究的新颖性、创造性和范式转变。

* *重点创新要素**：
- **概念创新**：新的框架、模型或理论
- **方法论创新**：新的技术、方法或技术
- **集成创新**：以新的方式组合学科或方法
- **转化式创新**：从发现到应用的新途径
- **规模创新**：前所未有的范围或分辨率

* *写作策略**：
- 清楚地说明什么是创新的（不要认为它是显而易见的）
- 解释为什么当前的方法不足
- 描述你的创新如何克服限制
- 提供创新可行的证据（初步数据，概念验证）
- 区分增量与变革性进展
- 平衡创新与可行性（风险不太大）

* *常见错误**：
- 在不证明对先前工作的了解的情况下声称新颖性
- 混淆“对我来说是新的”与“该领域的新事物”
- 在没有证据支持的情况下过度承诺
- 过于增量（现有工作的微小变化）
- 过于投机（没有成功之路）

### 6. 研究方法和方法

详细描述如何进行研究。

* *基本组成部分**：
- 总体研究设计和框架
- 每个目标的详细方法
- 样本大小、统计功效和分析计划
- 活动的时间表和顺序
- 数据收集、管理和分析
- 质量控制和验证方法
- 潜在问题和替代策略
- 严格和再现性测量

* *写作策略**：
- 为再现性和可行性评估提供足够的细节
- 使用副标题和数字来改进组织
- 证明方法和途径的选择
- 主动解决潜在的局限性
- 包括证明可行性的初步数据
- 表明您已经对研究进行了思考过程
- 平衡细节与可读性（使用补充材料获取广泛的细节）

* *用于实验研究**：
- 描述实验设计（对照、重复、盲法）
- 指定材料、试剂和设备
- 详细数据收集协议
- 解释统计分析计划
- 地址严谨性和可重复性

* *用于计算研究**：
- 描述算法、模型和软件
- 指定数据集和验证方法
- 解释所需的计算资源
- 地址代码可用性和文档
- 描述基准测试和性能指标

* *用于临床或转化研究**：
- 描述研究人群和招募
- 详细干预或治疗方案
- 解释结果测量和评估
- 解决监管批准（IRB、IND、IDE）
- 描述临床试验设计和监测


### 7. 初步数据和可行性

证明研究是可以实现的并且团队有能力。

* *目的**：
- 证明所提出的方法可以工作
- 表明团队具有必要的专业知识
- 展示对所需资源的访问
- 降低感知风险审稿人
- 为拟议工作提供基础

* *包含内容**：
- 试点研究或概念验证结果
- 方法开发或优化
- 访问独特的资源（样本、数据、合作者）
- 您团队的相关出版物
- 初步模型或模拟
- 可行性评估或能力计算

* *NIH 要求**：
- R01 申请通常需要大量初步数据
- R21 申请可能有不太严格的要求
- 新研究人员的初步数据可能较少
- 初步数据应直接支持提出的目标

* *NSF 方法**：
- 初步比 NIH
 更不常用的数据 - 对于高风险或新颖的方法可能很重要
 - 可以加强竞争性项目的建议

  * *写作策略**：
  - 提供支持你的方法的最引人注目的数据
  - 清楚地将初步数据与提议的目标联系起来
  - 承认局限性以及提议的工作将如何解决
- 有效地使用图形和数据可视化
- 避免过度解释或夸大初步结果
- 显示您的研究计划的轨迹

### 8. 时间表、里程碑和管理计划

证明该项目经过精心规划，并且可以在拟议的范围内实现

* *基本要素**：
- 具有明确里程碑的分阶段时间表
- 逻辑顺序和依赖性
- 每项活动的实际时间框架
- 决策点和进行/不进行标准
- 风险缓解策略
- 跨部门的资源分配时间
- 多机构团队的协调计划

* *演示文稿格式**：
- 显示重叠活动的甘特图
- 逐年活动细目
- 季度里程碑和可交付成果
- 目标/任务表以及时间表和人员

* *写作策略**：
- 对可以完成的事情保持现实态度
- 及时应对意外的延误或挫折
- 表明时间表与预算和人员相一致
- 展示对监管时间表（IRB、IACUC）的理解
- 包括传播时间和更广泛的影响
- 说明如何监控进展并评估了

* *DARPA重点**：
- 对于DARPA提案特别重要
- 具有可衡量指标的明确技术里程碑
- 季度可交付成果和报告
- 具有退出标准的基于阶段的结构
- 示范和过渡规划


### 9. 团队资质和协作

证明团队拥有成功所需的专业知识、经验和资源。

* *基本要素**：
- PI资质和相关专业知识
- Co-I和合作者角色和贡献
- 研究跟踪记录领域
- 跨团队的互补专业知识
- 机构支持和资源
- 先前的合作历史（如果适用）
- 指导和培训计划（针对学生/博士后）

* *写作策略**：
- 突出最相关的出版物和成就
- 明确定义角色和职责
- 表明团队组成是必要的（不仅仅是方便）
- 展示之前成功的合作
- 解决如何管理和协调团队
- 解释机构承诺和支持

* *生物草图/简历**：
- 遵循机构特定的格式（NSF，NSF， NIH、DOE、DARPA 不同）
- 突出最相关的出版物和成就
- 包括协同活动和合作
- 显示轨迹和生产力
- 解决任何职业差距或中断

* *合作函**：
- 具体承诺和贡献
- 展示真正的伙伴关系
- 包括资源共享或访问协议
- 已签署并带有信笺抬头


### 10. 预算和预算理由

制定与拟议工作和机构相一致的切合实际的预算

* *预算类别**（典型）：
- **人员**：PI、co-Is、博士后、学生、员工的工资和福利
- **设备**：> 5,000 美元的物品（因机构而异）
- **旅行**：会议、合作、实地考察
- **材料和用品**：消耗品、试剂、软件
- **其他直接成本**：出版成本、参与者激励、咨询
- **间接成本（F&A）**：机构管理费用（费率有所不同）
- **子奖励**：合作机构的成本

* *机构特定注意事项**：

* *NSF**：
- 需要完整的预算理由
- 通常不需要成本分摊（但可能会加强提案）
- 教师最多 2 个月的夏季工资
- 鼓励研究生支持

* *NIH**：
- 模块化预算每年 ≤ 25 万美元的直接成本 (R01)
- > 25 万美元或复杂奖励的详细预算
- 适用工资上限（2024 年约为 221,900 美元）
- 大多数人仅限 1 个月（8.33% FTE） PIs

* *DOE**：
- 通常需要成本分摊（尤其是 ARPA-E）
- 包含季度细目的详细预算
- 需要机构承诺函
- 单独的国家实验室合作预算

* *DARPA**：
- 按阶段和时间划分的详细预算任务
- 需要支持大型采购的成本数据
- 通常需要成本加成或固定价格结构
- 计划会议的差旅预算

* *预算理由写作**：
- 根据研究计划证明每个项目的合理性
- 解释人员的工作百分比
- 描述特定设备以及为什么必要
- 证明差旅（会议、协作）
- 解释顾问的角色和费率
- 显示预算如何与时间轴


## 机构审查标准

了解如何评估提案对于编写竞争性申请至关重要。

### NSF审查标准

* *智力优点**（主要）：
- 拟议活动推进知识的潜力是什么？
- 拟议的构思和组织如何良好活动？
- 是否有足够的资源获取？
- 个人、团队或机构开展拟议活动的资格如何？

* *更广泛的影响**（同样重要）：
- 拟议活动造福社会的潜力有多大？
- 提案在多大程度上有意义地解决更广泛的影响

* *其他注意事项**：
- 研究和教育的整合
- 多样性和包容性
- 先前 NSF 支持的结果（如果适用）

### NIH 审查标准

* *评分标准**（1-9 等级，1 = 特殊，9 =差）：

1. **意义**
  - 解决重要问题或关键障碍
  - 提高科学知识、技术能力或临床实践
  - 与 NIH 使命 

2 保持一致。 **研究者**
 - 非常适合该项目
  - 成就记录
  - 足够的培训和专业知识

3. **创新**
  - 新颖的概念、方法、方法或干预措施
  - 挑战现有范式
  - 以创造性的方式解决重要问题

4. **方法**
  - 合理且适当的
  - 严谨且可重复的
  - 充分考虑潜在问题
  - 在时间表内可行

5. **环境**
  - 机构支持和资源
  - 科学环境有助于成功的可能性

  * *其他审查注意事项**（未评分但已讨论）：
  - 对人类受试者的保护
  - 纳入妇女、少数民族和儿童
  - 脊椎动物福利
- 生物危害
- 重新提交响应（如果适用）
- 预算和时间表适当性

### DOE 审查标准

因项目办公室而异，但通常包括：
- 科学和/或技术优点
- 提议方法的适当性或方法
- 人员能力和设施充足性
- 预算的合理性和适当性
- 与DOE任务和计划目标的相关性

### DARPA审查标准

* *DARPA特定考虑因素**：
- 总体科学和技术优点
- 对DARPA任务的潜在贡献
- 拟议成本和资金可用性的现实性

### NSTC审查标准

* *核心评估维度**：
1. **创新性**：概念和方法的新颖性。
2. **可行性（吸力）**：方法论严谨性和初步数据。
3. **PI能力（主持人能力）**：业绩记录和专业知识。
4. **价值（价值）**：学术贡献和社会/产业影响。

详细评审标准，请参阅`references/nstc_guidelines.md`。
- **如果你成功了怎么办？**（如果研究有效的话会产生影响）
- **如果你是对的怎么办？**（你的假设的含义）
- **谁在乎？** （为什么它对国家安全很重要）


## 竞争性提案的写作原则

### 清晰度和可访问性

* *为多个受众撰写**：
- 您所在领域的技术审稿人（将仔细审查方法）
- 相关但不相同领域的审稿人（需要上下文）
- 项目官员（寻求与机构目标的一致性）
- 小组成员阅读15个以上提案（需要明确）组织）

* *策略**：
- 使用清晰的章节标题和副标题
- 以概述段落开始章节
- 定义技术术语和缩写
- 使用图形、图表和表格来阐明复杂的想法
- 尽可能避免使用行话；必要时进行解释
- 使用主题句来引导读者

### 有说服力的论证

* *构建一个令人信服的叙述**：
- 建立问题及其重要性
- 显示当前知识或方法中的差距
- 将您的解决方案呈现为创新和可行
- 证明你是正确的团队
- 表明成功将产生重大影响

* *说服结构**：
1. **挂钩**：有意义地吸引注意力
2. **问题**：确定什么是未知的或不起作用的
3. **解决方案**：展示您的创新方法
4. **证据**：初步数据支持
5. **影响**：显示变革潜力
6. **团队**：展示交付的能力

* *语言选择**：
- 使用主动语态以获得清晰度和信心
- 选择强有力的动词（调查、阐明、发现与观察、研究）
- 自信但不傲慢（避免“显然”， “清楚”）
- 适当地承认不确定性
- 使用精确的语言（避免“几个”、“各种”等模糊术语）

### 视觉传达

* *图形的有效使用**：
- 显示研究框架的概念图
- 初步数据演示可行性
- 时间表和甘特图
- 显示方法的工作流程图
- 预期结果或预测

* *设计原则**：
- 使图形不言自明，并附有完整的标题
- 使用一致的配色方案和字体
- 确保可读性（足够大的字体，清晰的标签）
- 将图形与文本集成（参考具体图形）
- 遵循机构特定的格式要求

### 解决风险和可行性

* *平衡创新与风险**：
- 承认潜在挑战
- 提供替代方法
- 显示降低风险的初步数据
- 展示应对挑战的专业知识
- 包括应急计划

* *常见问题**：
- 时间表/预算过于雄心勃勃
- 技术上不可行
- 团队缺乏必要的专业知识
- 初步数据不足
- 方法描述不充分
- 缺乏创新或意义

### 集成和连贯性

* *确保所有部分对齐**：
- 预算支持项目描述中的活动
- 时间表与目标和里程碑相匹配
- 团队组成与所需的专业知识相匹配
- 与研究计划相关的更广泛影响
- 支持信确认所述合作

* *避免矛盾**：
- 初步数据与规定的差距
- 声称的专业知识与出版物记录
- 规定的目标与实际方法
- 预算与规定的活动

## 常见提案类型

### NSF 提案类型

- **标准研究提案**：最常见，最多50 万美元和 5 年
- **职业奖**：早期职业教师，综合研究/教育，5 年 400-50 万美元
- **合作研究**：多个机构，单独提交，共享研究计划
- **快速**：紧急研究机会，高达 20 万美元，无需初步数据
- **EAGER**：高风险、高回报的探索性研究，最高可达 300K
- **早期探索性研究概念补助金 (EAGER)**：早期探索性工作

### NIH 奖励机制

- **R01**：研究项目资助，每年 25 万美元以上，3-5 年，最常见
- **R21**：探索性/开发研究，2 年内最高 275,000 美元，无初步数据
- **R03**：小额资助计划，2 年内最高 10 万美元
- **R15**：学术研究增强奖（AREA），主要针对本科院校
- **R35**：MIRA（最大化研究者研究奖），特定项目
- **P01**：计划项目资助，多项目综合研究
- **U01**：研究项目合作协议，NIH 参与开展

* *奖学金机制**：
- **F30**：博士前医学博士/博士奖学金
- **F31**：博士前奖学金
- **F32**：博士后奖学金
- **K99/R00**：独立奖之路
- **K08**：指导临床科学家研究职业发展奖

### DOE项目

- **科学办公室**：物理科学、生物科学、计算方面的基础研究
- **ARPA-E**：变革性能源技术，需要成本分摊
- **EERE**：可再生能源和能源效率的应用研究
- **国家实验室**：与DOE 实验室

### DARPA 计划

- **因办公室而异**：BTO、DSO、I2O、MTO、STO、TTO
- **特定计划的 BAAs**：针对具体目标的广泛机构公告
- **青年教师奖 (YFA)**：早期职业研究人员，最多可达$500K
- **主任奖学金**：高风险、范式转换研究


## 重新提交策略

### NIH 重新提交 (A1)

* * 重新提交简介**（1 页）：
- 总结之前的主要批评审查
- 描述响应中所做的具体更改
- 使用要点以确保清晰
- 尊重审阅者的意见
- 突出显示实质性改进

* *策略**：
- 解决所有重大批评
- 使更改可见（但不要在最终版本中使用跟踪更改）
- 加强薄弱环节（初步数据、方法、意义）
- 如果存在根本缺陷，请考虑更改目标
- 在重新提交之前获取外部反馈
- 如果满足以下条件，请使用完整的37 个月窗口新数据所需

* *何时不重新提交**：
- 基本概念缺陷
- 缺乏创新或意义
- 缺少关键专业知识或资源
- 需要进行大量修改（考虑新提交）

### NSF 重新提交

* *NSF 允许修改后重新提交**：
- 解决修订提案中审稿人的担忧
- 没有正式的“重新提交简介”部分
- 可能由相同或不同的小组审阅
- 考虑项目官员的反馈
- 可能需要等待下一个提交周期


## 常见错误避免

### 概念错误

1. **未能解决审查标准**：未明确讨论意义、创新、方法等。
2. **与机构使命不匹配**：提出与机构目标不符的研究
3. **意义不明确**：未能阐明研究为何重要
4. **创新不足**：增量工作表现为变革性的
5. **模糊目标**：不具体或不可衡量的目标

### 写作错误

1. **组织不良**：缺乏清晰的结构和流程
2. **过多的行话**：更广泛的审查小组无法访问
3. **冗长**：不必要的复杂或冗长的写作
4. **缺少上下文**：假设审稿人深入了解您的领域
5. **术语不一致**：对同一概念使用不同的术语

### 技术错误

1. **方法不充分**：判断可行性的细节不足
2. **过于雄心勃勃**：对于时间表/预算
3提出了太多建议。 **无初步数据**：对于需要证明可行性的机制
4. **时间表不佳**：不切实际或不合理的时间表
5. **预算不一致**：预算不支持提议的活动

### 格式错误

1. **超出页数限制**：自动拒绝
2. **字体或边距错误**：格式不合规
3. **缺少必填部分**：申请表不完整
4. **图形质量差**：图形难以辨认或不专业
5. **引用不一致**：参考文献中的格式错误

### 战略错误

1. **错误的程序或机制**：提出不适当的机会
2. **团队薄弱**：专业知识不足或缺少关键合作者
3. **没有更广泛的影响**：对于 NSF，未能充分解决 
4. **忽略计划优先事项**：与当前重点领域
5不相符。 **延迟提交**：技术问题或仓促准备

## 赠款开发工作流程

### 第1阶段：规划和准备（截止日期前2-6个月）

* *活动**：
- 确定适当的资助机会
- 审查计划公告和要求
- 与计划官员协商（如果适当）
- 组建团队并确认合作
- 开发初步数据（如果需要）
- 概述研究计划和具体目标
- 审查成功的提案（如果有）

* *输出**：
- 选定的资助机会
- 组建具有明确定义的团队角色
- 具体目标的初步大纲
- 所需初步数据的差距分析

### 阶段2：起草（截止日期前2-3个月）

* *活动**：
- 写出具体的目的或目标（从这里开始！）
- 制定项目描述/研究策略
- 创建图形和数据可视化
- 起草时间表和里程碑
- 准备初步预算
- 写出更广泛的影响或意义部分
- 请求信件支持/协作

* *输出**：
- 完成叙述部分的初稿
- 带有理由的初步预算
- 时间表和管理计划
- 合作者要求的信件

### 第3阶段：内部审查（提前1-2个月）截止日期）

* *活动**：
- 将草稿分发给共同研究者
- 寻求同事和导师的反馈
- 请求机构审查（如果需要）
- 模拟审查会议（如果可能）
- 根据反馈进行修改
- 完善预算和预算理由

* *输出**：
- 纳入反馈的修订草案
- 与修订计划一致的细化预算
- 确定的弱点和缓解策略

### 阶段4：最终确定（截止日期前2-4周）

* *活动**：
- 最终修改叙述
- 准备所有必需的表格和文件
- 最终确定预算和预算理由
- 编译生物草图、简历以及当前和待定的
- 收集支持信
- 准备数据管理计划（如果需要）
- 编写项目摘要/摘要
- 校对所有材料

* *输出**：
- 完整、完善的提案
- 所有必需的补充文件
- 根据机构要求格式化

### 第5阶段：提交（提前1周）截止日期）

* *活动**：
- 机构审查和批准
- 上传到提交门户
- 验证所有文件和格式
- 在截止日期前24-48小时提交
- 确认成功提交
- 接收确认和提案编号

* *输出**：
- 提交的提案
- 提交确认
- 所有材料的存档副本

  * *关键提示**：永远不要等到截止日期。门户崩溃、文件损坏、紧急情况发生。提前 48 小时为目标。
