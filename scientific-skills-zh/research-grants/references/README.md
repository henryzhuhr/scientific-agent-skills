# 研究资助技能

## 概述

撰写竞争性研究资助提案的综合技能，重点关注美国四大资助机构：
- **NSF**（国家科学基金会）
- **NIH**（国立卫生研究院）
- **DOE**（能源部）
- **DARPA** （国防高级研究项目局）

## 该技能提供什么

### 机构特定指导

每个资助机构的详细参考材料，包括：
- 任务和优先事项
- 审查标准和评分
- 提案结构和页数限制
- 预算要求
- 提交流程
- 竞争性应用的提示

### 核心组件

- **具体目标页面** (NIH)：关键一页目标页面的模板和详细指南
- **项目摘要** (NSF)：所需概述、智力优点和更广泛内容的模板影响
- **更广泛的影响**：NSF 等权审查标准的综合策略
- **预算合理性**：人员、设备、旅行和用品的模板和示例
- **审查标准**：了解审查者在每个机构寻找什么

### 模板

即用模板：
- NSF 项目摘要
- NIH 特定目标页面
- 预算理由
- （正在开发中的其他模板）

## 如何使用此技能

### 快速开始

编写资助提案时，指定机构和资助类型：

```
> Help me write an NSF proposal for computational biology research
> I need to draft NIH R01 Specific Aims for my cancer research project
> What should I include in a DOE ARPA-E concept paper?
> I'm applying for a DARPA program - help me structure the proposal
```

### 详细指导

有关特定组件的深入帮助：

```
> Help me write compelling broader impacts for my NSF proposal
> Review my NIH Specific Aims page
> What should I include in my budget justification?
> How do I respond to reviewer comments in an NIH resubmission?
```

### 机构比较

```
> What are the key differences between NSF and NIH proposals?
> Should I apply to DOE or DARPA for my energy technology project?
```

## 主要特点

### NSF 提案

- **智力优点 + 更广泛的影响**（同等权重）
- 实现实质性、可衡量的更广泛影响的策略
- 研究与研究的整合教育
- 扩大对STEM的参与
- 15页项目描述限制（大多数项目）

### NIH 提案

- **具体目标页面**：最关键的页面（包括详细的 1 页指南）
- **研究策略**：意义、创新、方法部分
- **初步数据**：R01 应用的基本
- 严格性和可重复性要求
- 模块化与详细预算
- 重新提交策略（A1 申请）

### DOE 提案

- **能源相关性** 以及与 DOE 使命的一致性
- **技术准备水平** (TRL)
- 国家实验室合作
- 成本分摊要求（特别是ARPA-E)
- 商业化途径
- 用户设施访问

### DARPA 提案

- **DARPA 难题**：高风险、高回报
- **Heilmeier 教义问答**：8 个关键问题
- 项目经理参与（关键！）
- 具有里程碑的阶段性结构
- 技术过渡规划
- 演示和原型

## 成功指标

按机构划分的典型成功率：
- **NSF**：15-30%（因机构而异）计划）
- **NIH R01**：总体约 20%（早期研究人员约 27%）
- **DOE 科学办公室**：20-40%（因计划而异）
- **ARPA-E**：2-5%（获奖概念论文）
- **DARPA**：高度可变程序

## 最佳实践

### 尽早开始
- NSF/NIH 提案：在截止日期前3-6 个月开始
- DOE/DARPA 提案：4-6 个月（特别是涉及国家实验室时）

### 获取反馈
- 模拟评审会议
- 您所在领域内外的同事
- 机构拨款支持办公室
- 项目官员（适当时）

### 了解评审标准
- NSF：智力优点+更广泛的影响（同等）权重）
- NIH：重要性、研究者、创新、方法、环境（得分 1-9）
- DOE：技术优点、资格、预算、相关性
- DARPA：创新、影响、团队、可行性、过渡

### 常见成功因素

✅ 清晰、引人注目的意义和创新
✅ 强大的初步数据（NIH、DOE）
✅ 详细、严格的方法
✅ 现实的时间表和预算
✅ 具体的、可衡量的结果
✅ 具有相关专业知识的强大团队
✅ 整合更广泛的影响（NSF）
✅ 技术转型计划（DOE、 DARPA)

## 最大效率的提示

### 对于 NSF 提案
1. 从具体目标开始（即使不是必需的）
2. 以与研究计划 
3 相同的严谨性发展更广泛的影响。自由使用图形和图表（使其易于浏览）
4. 明确解决这两个审查标准
5. 从您直接领域之外获取反馈

### 对于 NIH 提案
1. 首先完善您的具体目标页面（10 多个草稿）
2. 包括大量初步数据
3. 明确强调严谨性和可重复性
4. 使用替代方案
5 主动识别潜在问题。确保您的目标是独立的但具有协同作用

### 对于 DOE 提案
1. 强调能源相关性和影响
2. 包括定量指标（成本、效率、排放​​）
3. 开发部署或商业化途径
4. 考虑国家实验室合作伙伴关系
5. 解决 DARPA 提案的技术准备水平 

###
1. 尽早联系项目经理（必要！）
2. 参加提案者日活动
3. 专注于突破性创新（10 倍，而不是 10%）
4. 明确回答 Heilmeier 教义问答 
5. 制定明确的过渡策略

## 疑问或问题？

此技能旨在全面，但可能无法涵盖所有具体情况。使用该技能时：

1. **具体**说明您的机构、计划和资助类型
2. **提供有关您的研究领域和职业阶段的背景**
3. **提出后续问题**以进行澄清
4. **针对您正在处理的特定部分的请求示例**
