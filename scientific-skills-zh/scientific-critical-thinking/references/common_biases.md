# 科学研究中的常见偏见

## 影响研究人员的认知偏见

### 1.确认偏见
* *描述：**倾向于搜索、解释和回忆确认预先存在的信念的信息。

* *表现：**
- 设计只能支持事实的研究假设
- 将模棱两可的结果解释为支持性
- 记住命中并忘记失误
- 选择性引用同意的文献

* *缓解：**
- 预先注册假设和分析计划
- 积极寻找反驳证据
- 使用盲态数据分析
- 考虑替代假设

### 2. 事后诸葛亮偏见（我知道一直效应）
* *描述：** 事件发生后，人们认为它比实际情况更可预测。

* *表现：**
- 倾听（假设之后结果已知）
- 声称未做出的预测
- 低估结果的惊喜

* *缓解：**
- 数据收集前的文档预测
- 预先注册研究
- 区分探索性与验证性分析

### 3. 发表偏差（文件抽屉问题）
* *描述：** 阳性/显着结果比阴性/无效结果更有可能发表。

* *表现：**
- 文献似乎支持不存在的效应
- 高估效应尺寸
- 无法估计已发表文献的真实效果

* *缓解：**
- 发布无效结果
- 使用预注册和注册报告
- 使用灰色文献进行系统审查
- 检查元分析中漏斗图的不对称性

### 4.锚定偏差
* *描述：**过度依赖遇到的第一条信息。

* *表现：**
- 初始假设过度影响解释
- 领域内的首次研究设定了期望
- 试点数据偏差主要研究解释

* *缓解：**
- 考虑多个初始假设
- 独立评估证据
- 使用结构化决策

### 5. 可用性启发式
* *描述：** 根据想到的例子的容易程度高估事件的可能性。

* *表现：**
- 过分强调最近或戏剧性的发现
- 忽略基本利率
- 轶事证据掩盖统计

* *缓解：**
- 查阅系统评论，而不是令人难忘的论文
- 明确考虑基本利率
- 使用统计思维，而不是直觉

### 6.从众效应
* *描述：**采用信念，因为许多其他人持有

* *表现：**
- 跟随研究趋势而不进行批判性评估
- 不阅读而引用被广泛引用的论文
- 不加批判地接受“教科书知识”

* * 缓解：**
- 独立评估证据
- 阅读原文来源
- 问题假设

### 7.信念坚持
* *描述：**即使在证据反驳后仍保持信念。

* *表现：**
- 尽管证据相矛盾，仍捍卫理论
- 寻找差异的临时解释结果
- 消除复制失败

* *缓解：**
- 明确考虑哪些证据会改变你的想法
- 根据证据更新信念
- 区分理论和自我

### 8. 结果偏见
* *描述：**根据结果而不是当时决策的质量来判断决策。

* *表现：**
- 重视幸运的猜测而不是合理的方法
- 驳回没有结果的好的研究
- 奖励耸人听闻的发现而不是严格的方法

* *缓解措施：**
- 独立于结果评估方法
- 重视严谨性和透明度
- 认识机会的作用

## 实验和方法偏差

### 9. 选择偏差
* * 描述：** 选择进行研究的人和未选择的人之间的系统差异

* *类型：**
- **抽样偏差：** 非随机样本
- **损耗偏差：** 系统性退出
- **志愿者偏差：** 自选参与者不同
- **伯克森偏差：** 医院患者与一般人群不同
- **幸存者偏差：**仅检查“幸存者”

* *检测：**
- 比较参与者与目标人群的特征
- 分析退出模式
- 考虑样本中缺少谁

* *缓解：**
- 随机抽样
- 跟踪和分析无应答者
- 使用策略尽量减少脱落
- 报告参与者流程图

### 10. 观察者偏差（检测偏差）
* *描述：** 研究人员的期望影响观察或测量。

* * 表现：**
- 不同人群以不同方式测量结果组
- 根据小组分配解释不明确的结果
- 无意识地提示参与者

* *缓解：**
- 观察者/评估者的盲法
- 客观、自动化的测量
- 标准化协议
- 评估者间的可靠性检查

### 11. 表现偏差
* *描述：** 向比较组提供的护理存在系统性差异。

* *表现：**
- 以不同方式对待实验组
- 对一组提供额外关注
- 差异依从性协议

* *缓解：**
- 标准化所有程序
- 盲人参与者和提供者
- 使用安慰剂对照
- 监测协议遵守情况

### 12.测量偏差（信息偏差）
* *描述：**测量变量。

* *类型：**
- **回忆偏差：** 回忆准确性的系统性差异
- **社会愿望偏差：** 以社会可接受的方式做出反应
- **访调员偏差：** 访调员的特征影响反应
- **仪器偏差：** 系统地测量工具err

* *缓解：**
- 使用经过验证的客观措施
- 标准化数据收集
- 盲目参与者进行假设
- 使用客观数据验证自我报告

### 13. 混杂偏差
* *描述：** 无关变量的影响

* *示例：**
- 运动与健康之间的年龄混杂关系
- 社会经济地位混杂教育和结果
- 治疗研究中的指示偏差

* * 缓解：**
- 随机化
- 匹配
- 统计调整
- 分层
- 限制

### 14. 报告偏差
* *描述：** 选择性报告结果。

* * 类型：**
- **结果报告偏差：** 选择性报告结果
- **时滞偏差：** 延迟发布阴性结果
- **语言偏差：** 用英语发布阳性结果
- **引用偏差：** 优先引用阳性研究

* *缓解：**
- 预先注册所有结果
- 报告所有计划分析
- 区分主要结果和次要结果
- 使用研究登记

### 15.谱偏差
* *描述：**测试性能根据样本中疾病严重程度的范围而变化。

* *表现：**
- 诊断测试在极端病例
- 治疗效果因严重程度而异

* *缓解：**
- 在代表性样本中进行测试
- 报告整个疾病谱系的表现
- 避免诊断研究的病例对照设计

### 16.前置时间偏差
* *描述：**明显的生存获益由于早期检测，结果并未改善。

* *示例：**
- 早期筛查发现疾病使生存期看起来更长，即使死亡发生在同一年龄

* *缓解：**
- 衡量死亡率，而不仅仅是诊断后的生存期
- 使用随机筛选试验
- 考虑时长和过度诊断偏差

### 17. 时长-时间偏差
* *描述：**筛查不成比例地检测到生长缓慢、侵袭性较低的病例。

* *示例：**
- 生长缓慢的癌症比生长快速的癌症更常见，使筛查显得有益

* *缓解：**
- 具有死亡率终点的随机试验
- 考虑疾病自然历史

### 18. 响应偏差
* *描述：**参与者如何响应的系统模式。

* *类型：**
- **默许偏差：**同意倾向
- **极端响应：**总是选择极端选项
- **中性响应：**避免极端响应
- **需求特征：** 根据感知期望进行响应

* *缓解：**
- 混合正面和负面项目
- 使用多种响应格式
- 盲目参与者进行假设
- 使用行为测量

## 统计和分析偏见

### 19. P-Hacking（数据挖掘）
* *描述：**操纵数据或分析直到出现显着结果。

* *表现：**
- 收集数据直到达到显着性
- 测试多个结果，仅报告显着结果
- 尝试多重分析方法
- 排除“异常值”以达到显着性
- 亚组分析直至发现显着性

* *检测：**
- 可疑的完美p值（略低于0.05）
- 许多研究人员自由度
- 未公开分析
- 钓鱼探险

* *缓解：**
- 预注册分析计划
- 报告进行的所有分析
- 纠正多重比较
- 区分探索性与验证性

### 20. 认真思考（已知结果后进行假设）
* *描述：** 提出事后假设，就好像它们是先验预测的一样。

* *为什么有问题：**
- 夸大明显的证据
- 将探索与确认混为一谈
- 歪曲科学流程

* *缓解：**
- 预先注册假设
- 明确标记探索性分析
- 需要复制意外发现

### 21. 基本率忽略
* *说明：** 评估时忽略先验概率证据。

* *示例：**
- 罕见疾病测试准确度为 95%（患病率 1%）：阳性结果仅 16% 可能表明疾病

* *缓解：**
- 始终考虑基本率/先验概率
- 使用贝叶斯推理
- 报告阳性和阴性预测值

### 22.回归均值
* *描述：**极端测量结果往往伴随着不太极端的测量结果。

* *表现：**
- 极端组的治疗效果可能是回归伪影
- 高位中的“大二低迷”表演者

* *缓解：**
- 使用对照组
- 考虑自然变化
- 不要在没有控制的情况下根据极端基线值进行选择

### 23. 德克萨斯神枪手谬误
* *说明：** 在看到模式后选择数据，例如射箭然后在周围绘制目标

* *表现：**
- 在随机数据中查找模式
- 事后选择的亚组分析
- 未经校正的地理聚类研究

* *缓解：**
- 预先指定假设
- 纠正多个比较
- 在独立数据中复制结果

## 减少偏差：最佳实践

### 研究设计
1. 随机化
2. 盲板（单、双、三）
3. 对照组
4. 足够的样本量
5. 预登记

### 数据收集
1. 标准化协议
2. 已验证的仪器
3. 尽可能采取客观措施
4. 多个观察者/评估者
5. 完整数据采集

### 分析
1. 意向治疗分析
2. 预先指定的分析
3. 适当的统计检验
4. 多重比较修正
5. 敏感性分析

### 报告
1. 完全透明
2. CONSORT、PRISMA 或类似指南
3. 报告所有结果
4. 区分探索性和验证性
5. 分享数据和代码

### 元级别
1. 对抗性协作
2. 复制研究
3. 开放科学实践
4. 同行评审
5. 系统评论
