# 实验设计清单

## 研究问题表述

### 问题格式是否正确？
- [ ] **具体：** 明确定义变量和关系
- [ ] **可回答：** 可以用可用的方法解决
- [ ] **相关：** 解决知识或实践方面的差距需要
- [ ] **可行：** 资源、时间和道德考虑允许
- [ ] **可证伪：** 如果不正确则可以被证明是错误的

### 你复习过文献了吗？
- [ ]确定了已知的内容
- [ ]发现了与以下内容的差距或矛盾地址
- [ ]从方法论的成功和失败中学习
- [ ]确定适当的结果测量
- [ ]确定该领域的典型效应大小

## 假设发展

### 你的假设可检验吗？
- [ ]使具体的、可量化的预测
- [ ]变量是可操作定义的
- [ ]指定预期关系的方向/性质
- [ ]可以通过潜在的观察来证伪

### 假设类型
- [ ] **零假设（H₀）：** 无影响/关系存在
- [ ] **替代假设（H₁）：**效果/关系存在
- [ ] **定向与非定向：** 单尾与双尾测试

## 研究设计选择

### 什么类型的研究是合适的？

* *实验（干预）研究：**
- [ ] **随机对照试验 (RCT)：** 因果关系的黄金标准
- [ ] **准实验：** 非随机分配但操纵
- [ ] **受试者内：** 所有条件下的相同参与者
- [ ] **受试者之间：** 每个条件不同的参与者
- [ ] **因子：** 多个自变量
- [ ] **交叉：** 参与者按顺序接受多种干预措施

* *观察性研究：**
- [ ] **队列：** 随着时间的推移跟踪各组
- [ ] **病例对照：** 比较有/无结果的结果
- [ ] **横截面：** 一个时间点的快照
- [ ] **生态：** 人口水平数据

* *考虑：**
- [ ]你能随机分配参与者吗？
- [ ]你能操纵自变量吗？
- [ ]结果是罕见（有利于病例对照）还是常见？
- [ ]你需要建立时间序列吗？
- [ ]在道德、实用的情况下什么是可行的约束？

## 变量

### 自变量（操纵/预测）
- [ ]明确定义和操作
- [ ]选择适当的级别/类别
- [ ]操纵足以检验假设
- [ ]计划操纵检查（如果适用）

### 因变量（结果/响应）
- [ ]直接测量感兴趣的结构
- [ ]经过验证且可靠的测量
- [ ]足够灵敏，可以检测预期效果
- [ ]适用于计划的统计分析
- [ ]主要结果明确指定

### 控制变量
- [ ] **确定的混杂变量：**
  - 影响 IV 和 DV
 的变量 - 结果的替代解释
- [ ] **控制策略：**
  - 随机化
  - 匹配
  - 分层
  - 统计调整
  - 限制（纳入/排除标准）
  - 盲法

### 无关变量
- [ ]识别潜在噪声源
- [ ]标准化程序最小化
- [ ]控制环境因素
- [ ]时间、设置、标准化设备

## 采样

### 人群定义
- [ ] **目标人群：** 您想要推广到的人群
- [ ] **可访问人群：** 您实际上可以从中抽样的人群
- [ ] **样本：** 实际参与的人群
- [ ]这些记录之间的差异

### 抽样方法
- [ ] **概率抽样（优先考虑普遍性）：**
  - 简单随机抽样
  - 分层抽样
  - 整群抽样
  - 系统抽样
- [ ] **非概率抽样（常见但限制普遍性）：**
  - 便利性采样
  - 目的采样
  - 雪球采样
  - 配额采样

### 样本大小
- [ ] **进行先验功效分析** 
  - 预期效果大小（来自文献或试点）
  - 所需功效（通常为0.80或.90)
  - 显着性水平（通常为 0.05）
  - 要使用的统计检验
- [ ]考虑预期流失/流失
- [ ]足以进行计划的子组分析
- [ ]实际约束承认

### 纳入/排除标准
- []明确定义和合理
- []没有过度限制（限制普遍性）
- []基于理论或实践考虑
- []解决道德考虑
- []记录并应用一致

## 盲法和随机化

### 随机化
- [ ] **随机化内容：**
  - 参与者分配给条件
  - 条件顺序（受试者内）
  - 呈现的刺激/项目
- [ ] **随机化方法：**
  - 计算机生成的随机数
  - 随机数字表
  - 硬币翻转（适用于非常小的研究）
- [ ] **分配隐藏：**
  - 招募前生成的序列
  - 分配在注册后隐藏
  - 按顺序编号、密封的信封（如果需要）
- [ ] **分层随机化：**
  - 平衡各组之间的重要变量
  - 分块随机化以确保相同的组大小
- [ ] **检查随机化：**
  - 比较基线各组
  - 报告任何显着差异

### Blinding
- [ ] **单盲：**参与者不知道分组分配
- [ ] **双盲：**参与者和研究人员不知道
- [ ] **三盲：**参与者、研究人员和数据分析师不知道
- [ ] **盲法可行性：**
  - 是真正的盲法可能吗？
  - 需要安慰剂/假对照吗？
  - 干预措施的外观相同？
- [ ] **盲法检查：**
  - 评估是否维持盲法
  - 要求参与者/研究人员猜测分配

## 对照组和条件

### 什么类型的对照？
- [ ] **无治疗对照：**自然病程
- [ ] **安慰剂对照：**用于比较的惰性治疗
- [ ] **主动对照：**标准治疗比较
- [ ] **等待名单对照：**延迟治疗
- [ ] **注意力控制：** 匹配无活性成分的接触时间

### 多重条件
- [ ]多因素因子设计
- [ ]剂量-反应关系评估
- [ ]通过成分分析进行机制测试

## 程序

### 协议开发
- [ ] **详细的书面协议：**
  - 分步程序
  - 标准化指令脚本
  - 处理问题的决策规则
  - 数据收集表格
- [ ]在主要研究之前进行试点测试
- [ ]培训人员标准
- [ ]计划合规监测

### 标准化
- [ ]对所有参与者的相同说明
- [ ]相同的设备和材料
- [ ]尽可能相同的环境/设置
- [ ]相同的评估时间
- [ ]与协议的偏差记录

### 数据收集
- [ ] **收集时：**
  - 基线测量
  - 干预后
  - 随访时间点
- [ ] **谁收集：**
  - 训练有素的研究人员
  - 尽可能采用盲法
  - 建立评估者间的可靠性
- [ ] **如何收集：**
  - 有效、可靠的仪器
  - 标准化管理
  - 如果可能的话多种方法（三角测量）

## 测量

### 有效性
- [ ] **表面有效性：** 似乎衡量构造
- [ ] **内容有效性：** 涵盖构造
- [ ] **标准有效性：** 与黄金标准相关
  - 并发有效性
  - 预测有效性
- [ ] **构造有效性：** 测量理论构造
  - 收敛有效性（与相关测量相关）
  - 区分有效性（与不相关测量不相关）

### 可靠性
- [ ] **重测：** 随着时间的推移保持一致
- [ ] **内部一致性：** 项目测量相同的结构（Cronbach's α）
- [ ] **评估者间可靠性：** 评估者之间的协议（Cohen's κ，ICC）
- [ ] **平行形式：** 替代版本一致

### 测量注意事项
- [ ]尽可能首选客观测量
- [ ]可用时使用经过验证的仪器
- [ ]关键结构的多种测量
- [ ]考虑的变化敏感性
- [ ]避免地板/天花板效应
- [ ]响应格式适当的
- [ ]回忆期适当的
- [ ]考虑文化适当性

## 偏差最小化

### 选择偏差
- [ ]尽可能随机抽样
- [ ]明确定义的资格标准
- [ ]记录谁拒绝和为什么
- [ ]最小化自我选择

### 性能偏差
- [ ]标准化协议
- [ ]提供者盲法
- [ ]监控协议遵守情况
- [ ]文档偏差

### 检测偏差
- [ ]结果评估者采用盲法
- [ ]尽可能采取客观措施
- [ ]标准化评估程序
- [ ]进行可靠性检查的多个评估者

### 磨损偏差
- [ ]最小化策略辍学
- [ ]跟踪辍学原因
- [ ]将辍学者与完成者进行比较
- [ ]计划意向治疗分析

### 报告偏差
- [ ]预先注册研究和分析计划
- [ ]指定主要与次要结果
- [ ]承诺报告所有结果
- [ ]区分计划分析和探索性分析

## 数据管理

### 数据收集
- [ ]设计和测试的数据收集表格
- [ ] REDCap、Qualtrics 或类似工具平台
- [ ]范围检查和验证规则
- [ ]定期备份
- [ ]安全存储（如果需要，符合HIPAA/GDPR）

### 数据质量
- [ ]实时数据验证
- [ ]常规质量检查
- [ ]监测缺失数据模式
- [ ]识别并调查异常值
- [ ]记录协议偏差

### 数据安全
- [ ]去识别程序
- [ ]访问控制
- [ ]审核跟踪
- [ ]遵守法规（IRB、HIPAA、GDPR）

## 统计分析规划

### 分析计划（在数据之前预先指定）集合）
- [ ] **初步分析：**
  - 指定的统计检验
  - 明确陈述的假设
  - 显着性水平集（通常 α = .05）
  - 单尾或双尾
- [ ] **次要分析：**
  - 明确指定为次要
  - 标记为此类的探索性分析
- [ ] **多重比较：**
  - 指定调整方法（如果需要）
  - 主要结果防止通货膨胀

### 假设
- [ ]已识别的统计测试假设
- [ ]计划检查假设
- [ ]备份非参数替代方案
- [ ]考虑的转换选项

### 缺失数据
- [ ]预期缺失量
- [ ]缺失数据机制（MCAR， MAR, MNAR)
- [ ]处理策略：
  - 完整案例分析
  - 多重插补
  - 最大似然
- [ ]计划敏感性分析

### 效应量
- [ ]适当的效应量测量已识别
- [ ]将与p 值一起报告
- [ ]计划的置信区间

### 统计软件
- [ ]选择的软件（R、SPSS、Stata、Python 等）
- [ ]记录的版本
- [ ]准备的分析脚本advance
- [ ]将提供（开放科学）

## 伦理考虑

### 伦理批准
- [ ]获得IRB/伦理委员会批准
- [ ]研究注册（ClinicalTrials.gov 等）（如果适用）
- [ ]协议如下赫尔辛基声明或同等声明

### 知情同意
- [ ]自愿参与
- [ ]易于理解的解释
- [ ]风险和收益披露
- [ ]不受处罚的退出权
- [ ]隐私保护解释
- [ ]补偿披露

### 风险效益分析
- [ ]潜在收益大于风险
- [ ]风险最小化
- [ ]弱势群体受到保护
- [ ]数据安全监控（若高风险）

### 保密
- [ ]数据去识别
- [ ]安全存储
- [ ]有限访问
- [ ]报告不允许重新识别

## 有效性威胁

### 内部有效性（因果关系）
- [ ] **历史记录：** 之间的外部事件测量
- [ ] **成熟度：** 参与者随时间的变化
- [ ] **测试：** 重复测量的效果
- [ ] **仪器：** 测量随时间的变化
- [ ] **回归均值：** 极端分数变得不那么极端
- [ ] **选择：** 各组在基线上有所不同
- [ ] **损耗：** 差异退出
- [ ] **扩散：** 对照组接受治疗元素

### 外部有效性（普遍性）
- [ ]群体样本代表
- [ ]设置现实/自然
- [ ]现实世界实施的典型处理
- [ ]结果措施生态有效
- [ ]适当的时间范围

### 构造有效性（测量）
- [ ]措施实际利用预期构造
- [ ]操作与理论相符定义
- [ ]结构无混杂
- [ ]结构充分覆盖

### 统计结论有效性
- [ ]足够的统计功效
- [ ]满足假设
- [ ]适当的测试使用
- [ ] Alpha 级别适当
- [ ]多重比较解决

## 报告和透明度

### 预注册
- [ ]研究预注册（OSF、ClinicalTrials.gov、AsPredicted）
- [ ]先验假设
- [ ]记录分析计划
- [ ]区分验证性与探索性

### 报告指南
- [ ] **随机对照试验：** CONSORT 检查表
- [ ] **观察性研究：** STROBE 检查表
- [ ] **系统评价：** PRISMA 检查表
- [ ] **诊断研究：** STARD 检查表
- [ ] **定性研究：** COREQ检查清单
- [ ] **病例报告：** CARE 指南

### 透明度
- [ ]报告所有措施
- [ ]披露所有操作
- [ ]样本量确定说明
- [ ]报告排除标准和数字
- [ ]记录了磨损
- [ ]记录了与协议的偏差
- [ ]披露了利益冲突

### 开放科学
- [ ]计划数据共享（符合道德标准）
- [ ]共享分析代码
- [ ]材料可用
- [ ]发布预印本
- [ ]尽可能开放获取出版物

## 研究后注意事项

### 数据分析
- [ ]遵循预先注册的计划
- [ ]清楚地标记偏差和探索性分析
- [ ]检查假设
- [ ]报告所有结果
- [ ]报告效应大小和置信区间，而不仅仅是p 值

### 解释
- [ ]数据支持的结论
- [ ]承认的局限性
- [ ]替代解释考虑了
- [ ]讨论了普遍性
- [ ]解决了临床/实际意义

### 传播
- [ ]无论结果如何都发表（减少发表偏倚）
- [ ]出席会议
- [ ]与参与者分享研究结果（当适当）
- [ ]与相关利益相关者沟通
- [ ]简单语言摘要

### 后续步骤
- [ ]需要复制吗？
- [ ]已确定后续研究
- [ ]计划进行机制研究
- [ ]考虑的临床应用

## 要避免的常见陷阱

- [ ]无功效分析 → 动力不足的研究
- [ ]看到数据后形成的假设（HARKing）
- [ ]可行时不致盲 → 偏差
- [ ] P-hacking（数据钓鱼，可选停止）
- [ ]多次测试而不校正→ false阳性
- [ ]对照组不充分
- [ ]未解决混淆问题
- [ ]未验证仪器
- [ ]未解决高流失问题
- [ ]择优报告结果
- [ ]来自相关性的因果语言数据
- [ ]忽略统计测试的假设
- [ ]不预先注册改变文献偏差
- [ ]未披露利益冲突

- [ ]混淆得到控制

- [ ]备份计划存在问题

## 记住

* *好的实验设计是：**
- 提出明确的问题
- 最小化偏差
- 最大化有效性
- 适当的推理
- 透明度
- 再现性

* *思考这些问题的最佳时间是在收集数据之前，而不是之后。**
