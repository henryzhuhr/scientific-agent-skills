# 科学批判性思维

## 概述

批判性思维是评估科学严谨性的系统过程。使用 GRADE 和 Cochrane ROB 框架评估方法、实验设计、统计有效性、偏差、混杂因素和证据质量。应用此技能对科学主张进行批判性分析。

## 何时使用此技能

此技能应在以下情况下使用：
- 评估研究方法和实验设计
- 评估统计有效性和证据质量
- 识别研究中的偏差和混杂因素
- 审查科学主张和结论
- 进行系统评价或荟萃分析
- 应用GRADE或Cochrane偏倚风险评估
- 提供研究论文的批判性分析

## 核心功能

### 1.方法论批判

E评估研究方法的严谨性、有效性和潜在缺陷。

* *应用时间：**
- 审查研究论文
- 评估实验设计
- 评估研究方案
- 规划新研究

* * 评估框架：**

1. **研究设计评估**
  - 设计是否适合研究问题？
  - 设计能否支持所做的因果主张？
  - 比较组是否适当且充分？
  - 考虑实验、准实验或观察设计是否合理

2. **有效性分析**
  - **内部有效性：** 我们可以相信因果推断吗？
  - 检查随机化质量
  - 评估混杂控制
  - 评估选择偏差
  - 审查损耗/退出模式
  - **外部有效性：** 做结果
  - 评估样本代表性
  - 考虑设置的生态有效性
  - 评估条件是否匹配目标应用
  - **构造有效性：** 措施是否捕获预期构造？
  - 审查测量验证
  - 检查操作定义
  - 评估措施是否是直接的或proxy
  - **统计结论有效性：** 统计推断是否合理？
  - 验证足够的功效/样本量
  - 检查假设合规性
  - 评估测试的适当性

3. **控制和盲法**
  - 随机化是否正确实施（序列生成、分配隐藏）？
  - 盲法是否可行并实施（参与者、提供者、评估者）？
  - 控制条件是否适当（安慰剂、主动对照、无治疗）？
  - 性能或检测偏差会影响结果吗？

4. **测量质量**
  - 仪器是否经过验证且可靠？
  - 测量是否尽可能客观，或具有已知局限性的主观测量？
  - 结果评估是否标准化？
  - 是否使用多种测量来三角测量结果？

  * *参考：** 请参阅 `references/scientific_method.md` 了解详细原理，参阅 `references/experimental_design.md` 了解详细原理综合设计清单。

### 2. 偏差检测

识别和评估可能扭曲研究结果的潜在偏差来源。

* *适用于：**
- 审查已发表的研究
- 设计新研究
- 解释相互矛盾的证据
- 评估研究质量

* *系统偏差审查：**

1. **认知偏差（研究员）**
  - **确认偏差：** 仅强调支持性发现？
  - **思考：** 假设是先验陈述还是在看到结果后形成？
  - **发表偏差：** 文献中是否缺少阴性结果？
  - **精挑细选：** 证据是否有选择性报告？
  - 检查预注册和分析计划透明度

2. **选择偏差**
  - **抽样偏差：** 样本是否代表目标人群？
  - **志愿者偏差：** 参与者是否以系统的方式进行自我选择？
  - **消耗偏差：** 组间的退出率是否存在差异？
  - **幸存者偏差：** 样本中是否只有“幸存者”可见？
  - 检查参与者流程图并比较基线特征

3. **测量偏差**
  - **观察者偏差：**期望会影响观察结果吗？
  - **回忆偏差：**回顾性报告是否系统地不准确？
  - **社会期望：**反应是否偏向于可接受性？
  - **仪器偏差：**系统地使用测量工具错误？
  - 评估盲法、验证和测量客观性

4. **分析偏差**
  - **P-hacking：** 是否进行了多项分析直至出现显着性？
  - **结果切换：** 非显着性结果是否被显着性结果替换？
  - **选择性报告：** 是否报告了所有计划分析？
  - **分组钓鱼：** 是否在没有进行分组分析的情况下进行分组分析？更正？
  - 检查研究注册并与已发布的结果进行比较

5. **混杂**
  - 哪些变量可能影响暴露和结果？
  - 混杂因素是否被测量和控制（统计或设计）？
  - 未测量的混杂因素可以解释结果吗？
  - 是否有合理的替代解释？

* *参考：** 请参阅 `references/common_biases.md` 了解具有检测和缓解策略的综合偏差分类法。

### 3. 统计分析评估

严格评估统计方法、解释和报告。

* *适用于：**
- 审查定量研究
- 评估数据驱动索赔
- 评估临床试验结果
- 审查荟萃分析

* *统计审查清单：**

1. **样本量和功效**
  - 是否进行了先验功效分析？
  - 样本是否足以检测有意义的效应？
  - 研究动力是否不足（常见问题）？
  - 小样本的显着结果是否会引发夸大效应大小的标志？

2. **统计测试**
  - 测试是否适合数据类型和分布？
  - 是否检查并满足测试假设？
  - 参数测试是否合理，或者是否应该使用非参数替代方案？
  - 分析是否与研究设计匹配（例如，配对与独立）？

3. **多重比较**
  - 是否测试了多个假设？
  - 是否应用了校正（Bonferroni、FDR 等）？
  - 主要结果是否与次要/探索性结果区分开来？
  - 多重测试的结果是否可能是假阳性？

4. **P 值解释**
  - p 值是否正确解释（如果 null 为 true，则数据的概率）？
  - 非显着性是否被错误地解释为“无影响”？
  - 统计显着性是否与实际重要性混为一谈？
  - 是否报告了精确的 p 值，或仅“p < .05"?
  - 0.05 以下是否存在可疑聚类？

5. **效应大小和置信区间**
  - 效应大小是否与显着性一起报告？
  - 是否提供置信区间以显示精度？
  - 效应大小在实际中有意义吗？
  - 标准化效应大小是否用特定领域的上下文来解释？

6. **缺失数据**
  - 缺失了多少数据？
  - 是否考虑了缺失数据机制（MCAR、MAR、MNAR）？
  - 如何处理缺失数据（删除、插补、最大似然）？
  - 缺失数据是否会产生偏差？

7. **回归和建模**
  - 模型是否过度拟合（预测变量过多，无交叉验证）？
  - 预测是否超出数据范围（外推）？
  - 多重共线性问题是否得到解决？
  - 是否检查模型假设？

8. **常见陷阱**
  - 相关性被视为因果关系
  - 忽略均值回归
  - 基本率忽略
  - 德克萨斯神枪手谬误（噪声中的模式发现）
  - 辛普森悖论（混淆

* *参考：**参见`references/statistical_pitfalls.md`了解详细的陷阱和正确做法。

### 4.证据质量评估

E系统地评估证据的强度和质量。

* *适用于：**
- 权衡决策的证据
- 进行文献综述
- 比较相互矛盾的发现
- 确定结论的置信度

* *证据评估框架：**

1. **研究设计层次**
  - 系统评价/荟萃分析（干预效果最高）
  - 随机对照试验
  - 队列研究
  - 病例对照研究
  - 横断面研究
  - 病例系列/报告
  - 专家意见（最低）

  * *重要：** 更高级别的设计并不总是更好的质量。精心设计的观察性研究可能比实施不佳的随机对照试验更有力。

2. **设计类型内的质量**
  - 偏倚风险评估（使用适当的工具：Cochrane ROB、Newcastle-Ottawa 等）
  - 方法严谨性
  - 透明度和报告完整性
  - 利益冲突

3. **等级注意事项（如果适用）**
  - 从设计类型开始（RCT = 高，观察=低）
  - **降级为：**
  - 偏倚风险
  - 研究之间的不一致
  - 间接性（错误的人群/干预/结果）
  - 不精确（宽置信度）间隔，小样本）
  - 发表偏差
  - **升级为：**
  - 大效应量
  - 剂量-反应关系
  - 混杂因素会减少（而不是增加）效果

4. **证据收敛**
  - **更强时：**
  - 多次独立重复
  - 不同的研究组和设置
  - 不同的方法收敛于同一结论
  - 机制和经验证据对齐
  - **弱时：**
  - 单一研究或研究小组
  - 文献中的矛盾发现
  - 明显的发表偏倚
  - 没有复制尝试

5. **情境因素**
  - 生物学/理论合理性
  - 与既定知识的一致性
  - 时间性（原因先于效果）
  - 关系的特异性
  - 关联的强度

  * *参考：** 详细信息请参见`references/evidence_hierarchy.md` 

### 5. 逻辑谬误识别

检测并命名科学论证和主张中的逻辑错误。

* *适用于：**
- 评估科学主张
- 审查讨论/结论部分
- 评估科普沟通
- 识别有缺陷的推理

* *科学中的常见谬误：**

1. **因果谬误**
  - **事后故此：**“B跟随A，所以A导致了B”
  - **相关性=因果关系：**与因果关系的令人困惑的关联
  - **反向因果关系：**误认为效果的原因
  - **单一原因谬误：**归因于复杂性结果为一个因素

2. **泛化谬误**
  - **草率泛化：**小样本得出广泛结论
  - **轶事谬误：**个人故事作为证据
  - **择优挑选：**仅选择支持性证据
  - **生态谬误：**应用于个人的群体模式

3. **权威和来源谬论**
  - **诉诸权威：**“专家说了，所以是真的”（无证据）
  - **人身攻击：**攻击人，而不是争论
  - **遗传谬误：**以起源来判断，而不是优点
  - **诉诸自然：**“自然 =良好/安全”

4. **统计谬误**
  - **基本率忽略：**忽略先验概率
  - **德克萨斯神枪手：**在随机数据中寻找模式
  - **多重比较：**不纠正多个测试
  - **检察官的谬误：**混淆P(E|H)与P(H|E)

5. **结构谬误**
  - **错误二分法：**存在更多选择时“A或B”
  - **移动球门柱：**满足后改变证据标准
  - **回避问题：**循环推理
  - **稻草人：**歪曲攻击论点其中

6. **特定于科学的谬论**
  - **伽利略策略：**“他们嘲笑伽利略，所以我的边缘想法是正确的”
  - **来自无知的论证：**“没有被证明是错误的，所以是真的”
  - **必杀技谬误：**拒绝不完美的解决方案
  - **不可证伪性：**做出不可检验的主张

* *识别谬误时：**
- 说出具体谬误 
- 解释为什么推理有缺陷 
- 确定有效推理需要什么证据 
- 请注意，谬误推理并不能证明结论错误，只是这个论证不支持它

  * *参考：** 参见 `references/logical_fallacies.md`包含示例和检测策略的综合谬误目录。

### 6. 研究设计指导

为规划严谨的研究提供建设性指导。

* *适用于：**
- 帮助设计新实验
- 规划研究项目
- 审查研究提案
- 改进研究协议

* *设计流程：**

1. **研究问题细化**
  - 确保问题具体、可回答且可证伪
  - 验证它解决了文献中的差距或矛盾
  - 确认可行性（资源、道德、时间）
  - 定义可操作的变量

2. **设计选择**
  - 将设计与问题相匹配（因果→实验；关联→观察）
  - 考虑可行性和道德约束
  - 选择受试者间、受试者内或混合设计
  - 如果测试多个因素，则规划因子设计

3. **偏差最小化策略**
  - 尽可能实施随机化
  - 在所有可行级别（参与者、提供者、评估者）计划盲法
  - 识别并计划控制混杂（随机化、匹配、分层、统计调整）
  - 标准化所有程序
  - 计划最小化磨损

4. **样本规划**
  - 进行先验功效分析（指定预期效果、期望功效、α）
  - 考虑样本量中的损耗
  - 定义明确的纳入/排除标准
  - 考虑招募策略和可行性
  - 规划样本代表性

5. **测量策略**
  - 选择经过验证的可靠工具
  - 尽可能使用客观测量
  - 规划关键结构的多项测量（三角测量）
  - 确保测量对预期变化敏感
  - 建立评估者间可靠性程序

6. **分析计划**
  - 预先指定所有假设和分析
  - 明确指定主要结果
  - 计划带有假设检查的统计测试
  - 指定如何处理缺失数据
  - 计划报告效应大小和置信区间
  - 考虑多重比较校正

7. **透明度和严谨性**
  - 预先注册研究和分析计划
  - 使用报告指南（CONSORT、STROBE、PRISMA）
  - 计划报告所有结果，而不仅仅是重要结果
  - 区分验证性分析和探索性分析
  - 提交数据/代码分享

* *参考：**参见`references/experimental_design.md`全面的设计清单，涵盖从问题到传播的所有阶段。

### 7.声明评估

系统地评估科学声明的有效性和支持性。

* *适用于：**
- 评估论文中的结论
- 评估研究的媒体报道
- 审查摘要或介绍声明
- 检查数据是否支持结论

* *声明评估过程：**

1. **识别主张**
  - 到底主张什么？
  - 是因果主张、关联主张还是描述性主张？
  - 主张有多强（已证明、可能、建议、可能）？

2. **评估证据**
  - 提供了什么证据？
  - 证据是直接的还是间接的？
  - 证据是否足以证明主张的强度？
  - 是否排除了其他解释？

3. **检查逻辑连接**
  - 从数据中得出结论吗？
  - 是否存在逻辑跳跃？
  - 相关数据是否用于支持因果关系？
  - 是否承认局限性？

4. **评估比例**
  - 置信度与证据强度成正比吗？
  - 是否适当使用了对冲词？
  - 限制是否被淡化？
  - 猜测是否被明确标记？

5. **检查过度概括**
  - 主张是否超出了研究样本范围？
  - 是否承认人口限制？
  - 是否认识到上下文依赖性？
  - 是否包括有关概括的警告？

6. **危险信号**
  - 相关研究中的因果语言
  - “证明”或绝对确定性
  - 精心挑选的引文
  - 忽略矛盾证据
  - 消除限制
  - 外推超出数据

* *提供具体反馈：**
- 引用有问题的主张
- 解释需要什么证据来支持它
- 如果有保证，建议适当的对冲语言
- 区分数据（发现了什么）和解释（它意味着什么）

## 应用指南

### 一般方法

1. **具有建设性**
  - 识别优点和缺点
  - 建议改进而不是仅仅批评
  - 区分致命缺陷和次要局限性
  - 认识到所有研究都有局限性

2. **具体**
  - 指向具体实例（例如，“表 2 显示...”或“在方法部分...”）
  - 引用有问题的陈述
  - 提供问题的具体示例
  - 参考违反的具体原则或标准

3. **保持比例**
  - 将批评的严重性与问题的重要性相匹配
  - 区分对有效性的主要威胁和次要问题
  - 考虑问题是否影响主要结论
  - 承认你自己的评估中的不确定性

4. **应用一致的标准**
  - 在所有研究中使用相同的标准
  - 不要对您不喜欢的发现应用更严格的标准
  - 承认您自己的潜在偏见
  - 根据方法而不是结果进行判断

5. **考虑背景**
  - 承认实际和道德约束
  - 考虑效果大小和方法的特定领域规范
  - 识别探索性与验证性背景
  - 考虑评估研究中的资源限制

### 在提供批评时

* *结构反馈如：**

1. **摘要：** 评估内容的简要概述
2. **优点：** 哪些方面做得好（对于可信度和学习很重要）
3. **关注点：** 按严重性组织的问题
  - 关键问题（威胁主要结论的有效性）
  - 重要问题（影响解释但不致命）
  - 次要问题（值得注意但不改变结论）
4. **具体建议：** 可操作的改进建议
5. **总体评估：**关于证据质量和可以得出的结论的平衡结论

* *使用精确的术语：**
- 指出具体的偏见、谬误和方法论问题
- 参考既定的标准和指南
- 引用科学方法论的原则
- 准确使用技术术语

### 何时不确定

- **承认不确定性：**“这可能是 X 或 Y；需要的附加信息是 Z”
- **提出澄清问题：**“[方法细节]完成了吗？这会影响解释。”
- **提供条件评估：**“如果 X 完成，则 Y 随之而来；如果没有，则 Z 值得关注”
- **注意哪些附加信息将解决不确定性**

## 记住

* *科学批判性思维是关于：**
- 使用既定原则进行系统评估
- 提高科学水平的建设性批评
- 与证据成比例的置信度强度
- 对不确定性和局限性的透明度
- 标准的一致应用
- 认识到所有研究都有局限性
- 怀疑与证据开放之间的平衡

* * 始终区分：**
- 数据（观察到的内容）和解释（观察到的内容）表示）
- 相关性和因果关系
- 统计意义和实际重要性
- 探索性和验证性发现
- 已知的和不确定的
- 反对主张的证据和无效的证据

* *关键目标思考：**
1. 准确识别优势和劣势
2. 确定
3支持什么结论。认识到局限性和不确定性
4. 对今后的工作提出改进建议
5. 推进科学认识
