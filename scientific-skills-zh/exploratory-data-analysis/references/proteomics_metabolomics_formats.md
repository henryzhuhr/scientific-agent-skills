# 蛋白质组学和代谢组学文件格式参考

此参考涵盖蛋白质组学、代谢组学、脂质组学和相关组学工作流程特有的文件格式。

## 基于质谱的蛋白质组学

### .mzML - 质谱标记语言
* *说明：** MS 的标准 XML 格式数据
* *典型数据：** MS1 和 MS2 谱图、保留时间、强度
* *用例：** 蛋白质组学、代谢组学流程
* *Python 库：**
- `pymzml`：`pymzml.run.Reader('file.mzML')`
- `pyteomics.mzml`： `pyteomics.mzml.read('file.mzML')`
- `pyopenms`：OpenMS Python 绑定
* *EDA 方法：**
- 扫描计数和 MS 水平分布
- 总离子色谱图 (TIC)分析
- 基峰色谱图 (BPC)
- m/z覆盖率和分辨率
- 保留时间范围
- 前体选择模式
- 数据完整性
- 质量控制指标（锁定质量、标准）

### .mzXML - 传统MS XML 格式
* *说明：** 旧的基于XML 的MS格式
* *典型数据：**带有元数据的质谱
* *用例：**传统蛋白质组数据
* *Python库：**
- `pyteomics.mzxml`
- `pymzml`：可以读取mzXML
* *EDA方法：**
- 类似于 mzML
- 格式版本兼容性
- 转换质量验证
- 元数据保存检查

### .mzIdentML - 肽鉴定格式
* *说明：** 肽鉴定的PSI 标准
* *典型数据：** 肽谱匹配、蛋白质、分数
* * 使用案例：** 搜索引擎结果、蛋白质组学工作流程
* *Python 库：**
- `pyteomics.mzid`
- `pyopenms`：MzIdentML 支持
* *EDA方法：**
- PSM计数和得分分布
- FDR计算和过滤
- 修饰分析
- 漏切统计
- 蛋白质推断结果
- 搜索参数验证
- 诱饵命中分析
- 排名 1 与较低排名

### .pepXML - 跨蛋白质组管道肽 XML
* *描述：** 用于肽鉴定的 TPP 格式
* *典型数据：** 具有统计验证的搜索结果
* *用例：** 蛋白质组数据库搜索输出
* *Python 库：**
- `pyteomics.pepxml`
* *EDA 方法：**
- 搜索引擎比较
- 分数分布（XCorr、期望值等）
- 电荷态分析
- 修饰频率
- 肽先知概率
- 蛋白质覆盖范围
- 光谱计数

### .protXML - 蛋白质推断结果
* *描述：** TPP 蛋白质水平鉴定
* *典型数据：** 蛋白质组、概率、肽
* * 使用案例：** 蛋白质水平分析
* *Python文库：**
- `pyteomics.protxml`
* *EDA 方法：**
- 蛋白质组统计数据
- 简约蛋白质集
- 蛋白质先知概率
- 每个蛋白质的覆盖率和肽计数
- 独特与共享肽
- 蛋白质分子量分布
- GO术语富集制备

### .pride.xml - PRIDE XML格式
* *描述：**蛋白质组学鉴定数据库格式
* *典型数据：**完整的蛋白质组学实验数据
* *用例：**公共数据沉积（旧版）
* *Python 库：**
- `pyteomics.pride`
- 自定义 XML 解析器
* *EDA 方法：**
- 实验元数据提取
- 识别完整性
- 交叉链接到光谱
- 协议信息
- 仪器详细信息

### .tsv / .csv（蛋白质组学）
* *描述：**制表符或逗号分隔的蛋白质组学结果
* *典型数据：**肽或蛋白质定量表
* *用例：** MaxQuant、Proteome Discoverer、Skyline 输出
* *Python 库：**

- 识别计数
- 定量值分布
- 缺失值模式
- 基于强度的分析
- 无标签定量评估
- 同量异位标签比率分析
- 变异系数
- 批次效应

### .msf - Thermo MSF 数据库
* *描述：** Proteome Discoverer 结果数据库
* *典型数据：** 带搜索功能的SQLite 数据库结果
* *用例：** Thermo Proteome Discoverer 工作流程
* *Python 库：**
- `sqlite3`：数据库访问
- 自定义 MSF 解析器
* *EDA 方法：**
- 数据库模式探索
- 肽和蛋白质表
- 分数阈值
- 定量数据
- 处理节点信息
- 置信水平

### .pd结果 - Proteome Discoverer 结果
* *描述：** Proteome Discoverer 研究结果
* *典型数据：**全面搜索和量化
* *用例：** PD 研究导出
* *Python 库：**
- 用于转换的供应商工具
- 导出到 TSV 以进行 Python 分析
* *EDA 方法：**
- 研究设计验证
- 结果过滤标准
- 定量比较组
- 插补策略

### .pep.xml - 肽摘要
* *描述：** 紧凑肽鉴定格式
* *典型数据：** 肽序列、修饰、分数
* *用例：**下游分析输入
* *Python 库：**
- `pyteomics`：XML 解析

- PTM 位点本地化

* *描述：** 带有外部文件的Skyline 文档
* * 典型数据：** 完整的Skyline 分析
* * 使用案例：** 共享Skyline项目
* *Python库：**
- `zipfile`：提取用于处理
* *EDA方法：**
- 文档结构
- 外部文件引用

### .wiff - SCIEX WIFF 格式
* *描述：** 带定量的 SCIEX 仪器数据
* *典型数据：** 具有 MRM 离子对的 LC-MS/MS
* * 使用案例：** SCIEX QTRAP、TripleTOF 数据
* *Python 库：**
- 供应商工具（有限的 Python）访问）
- 转换为 mzML
* *EDA 方法：**
- MRM 转换性能
- 停留时间优化
- 周期时间分析
- 峰值积分质量

### .raw (Thermo)
* *描述：** Thermo 原始仪器文件
* *典型数据：** 来自 Orbitrap、Q Exactive 的完整 MS 数据
* *使用案例：** 无标签和 TMT 定量
* *Python 库：**
- `pymsfilereader`：Thermo RawFileReader
- `ThermoRawFileParser`：跨平台 CLI
* *EDA 方法：**
- MS1 和 MS2 采集速率
- AGC 目标和填充时间
- 分辨率设置
- 隔离窗口验证
- SPS 离子选择（TMT）
- 污染评估

### .d (Agilent)
* *描述：**安捷伦数据目录
* *典型数据：**LC-MS 和 GC-MS 数据
* *使用案例：**安捷伦仪器工作流程
* *Python 库：**
- 社区解析器

- 保留时间稳定性
