# 生物信息学和基因组学文件格式参考

此参考涵盖基因组学、转录组学、序列分析和相关生物信息学应用中使用的文件格式。

## 序列数据格式

### .fasta / .fa / .fna - FASTA 格式
* *说明：** 基于文本的核苷酸或蛋白质格式序列
* *典型数据：**带有标头的DNA、RNA或蛋白质序列
* *用例：**序列存储、BLAST搜索、比对
* *Python库：**
- `Biopython`：`SeqIO.parse('file.fasta', 'fasta')`
- `pyfaidx`：快速索引FASTA接入
- `screed`：快速序列解析
* *EDA方法：**
- 序列计数和长度分布
- GC含量分析
- N含量（模糊碱基）
- 序列ID解析
- 重复检测
- 组件的质量指标（N50，L50）

### .fastq / .fq - FASTQ格式
* *描述：**具有碱基质量分数的序列数据
* *典型数据：**具有Phred质量的原始测序读取分数
* *用例：** NGS 数据、质量控制、读取映射
* *Python 库：**
- `Biopython`：`SeqIO.parse('file.fastq', 'fastq')`
- `pysam`：快速 FASTQ/BAM 操作
- `HTSeq`：测序数据分析
* *EDA方法：**
- 片段计数和长度分布
- 质量得分分布（每个碱基，每个片段）
- GC含量和偏差
- 重复率估计
- 适配器污染检测
- k-mer频率分析
- 编码格式验证（Phred33/64）

### .sam - 序列比对/映射
* *描述：**用于比对的制表符分隔文本格式
* *典型数据：**比对测序读取与映射质量
* *用例：**读取比对存储，变体调用
* *Python库：**
- `pysam`： `pysam.AlignmentFile('file.sam', 'r')`
- `HTSeq`：`HTSeq.SAM_Reader('file.sam')`
* *EDA 方法：**
- 映射率和质量分布
- 覆盖率分析
- 插入大小分布（配对端）
- 对齐标志distribution
- CIGAR 字符串模式
- 不匹配和插入率
- 重复和补充对齐计数

### .bam - 二进制对齐/映射
* *说明：** SAM
 的压缩二进制版本**典型数据：** 对齐读取压缩格式
* *用例：**高效存储和处理比对
* *Python库：**
- `pysam`：带索引的完整BAM支持
- `bamnostic`：纯Python BAM阅读器
* *EDA方法：**
- 与 SAM 相同加上：
- 压缩比分析
- 索引文件 (.bai)验证
- 染色体统计
- 链偏倚检测
- 读取组分析

### .cram - CRAM格式
* *描述：**高度压缩的对齐格式
* *典型数据：**参考压缩对齐读取
* *用例：**长期存储、节省空间的存档
* *Python库：**
- `pysam`：CRAM支持（需要参考）
- 参考基因组必须可访问
* *EDA 方法：**
- 压缩效率与 BAM
- 参考依赖性验证
- 有损与无损压缩评估
- 解压性能
- 与 BAM

 类似的对齐指标### .bed - 浏览器可扩展数据
* *描述：**基因组特征的制表符分隔格式
* *典型数据：**带注释的基因组间隔（字符、开始、结束）
* *用例：**峰调用、变异注释、基因组浏览
* *Python 库：**
- `pybedtools`: `pybedtools.BedTool('file.bed')`
- `pyranges`: `pyranges.read_bed('file.bed')`
- `pandas`: 简单 BED 读取
* *EDA 方法:**
- 特征计数和尺寸分布
- 染色体分布
- 链偏差
- 分数分布（如果存在）
- 重叠和邻近分析
- 覆盖率统计
- 特征之间的差距分析

### .bedGraph - 带图形数据的BED
* *说明：** 带每个碱基信号的BED 格式值
* *典型数据：**连续值基因组数据（覆盖率、信号）
* *用例：**覆盖率轨迹、ChIP-seq信号、甲基化
* *Python库：**
- `pyBigWig`：可以转换为bigWig
- `pybedtools`：BedGraph操作
* *EDA方法：**
- 信号分布统计
- 基因组覆盖百分比
- 信号动态（峰、谷）
- 染色体信号模式
- 分位数分析
- 零覆盖区域

### .bigWig / .bw - 二进制 BigWig
* *描述：**全基因组信号数据的索引二进制格式
* *典型数据：**连续基因组信号（压缩和索引）
* *用例：**高效基因组浏览器轨迹，大规模数据
* *Python库：**
- `pyBigWig`：`pyBigWig.open('file.bw')`
- `pybbi`：BigWig/BigBed接口
* *EDA方法：**
- 信号统计提取
- 缩放级别分析
- 区域信号提取
- 高效全基因组摘要
- 压缩效率
- 索引结构分析

### .bigBed / .bb - 二进制 BigBed
* *描述：** 索引二进制 BED 格式
* *典型数据：** 基因组特征（压缩和索引）
* *用例：** 大型特征集、基因组浏览器
* *Python 库：**
- `pybbi`：BigBed 读取
- `pybigtools`：现代 BigBed 界面
* *EDA 方法：**
- 特征密度分析
- 高效间隔查询
- 缩放级别验证
- 索引性能指标
- 特征大小统计数据

### .gff / .gff3 - 通用特征格式
* *描述：**基因组注释的制表符分隔格式
* *典型数据：**基因模型、转录本、外显子、调控元件
* *用例：**基因组注释、基因预测
* *Python库：**
- `BCBio.GFF`：Biopython GFF 模块
- `gffutils`：`gffutils.create_db('file.gff3')`
- `pyranges`：GFF 支持
* *EDA方法：**
- 特征类型分布（基因、外显子、CDS 等）
- 基因结构验证
- 链平衡
- 层次关系验证
- CDS 的阶段验证
- 属性完整性
- 基因模型统计（内含子、每个基因的外显子）

### .gtf - 基因转移格式
* *描述：**基于 GFF2 的基因注释格式
* *典型数据：**基因和转录本注释
* *用例：** RNA-seq 分析、基因定量
* *Python库：**
- `pyranges`：`pyranges.read_gtf('file.gtf')`
- `gffutils`：GTF 数据库创建
- `HTSeq`：GTF 读取计数
* *EDA 方法：**
- 成绩单isoform分析
- 基因结构完整性
- 外显子数量分布
- 转录本长度分布
- TSS和TES分析
- 生物型分布
- 重叠基因检测

### .vcf - 变异调用格式
* *描述：**遗传变异的文本格式
* *典型数据：** SNP、插入缺失、带注释的结构变异
* *用例：**变异调用、群体遗传学、GWAS
* *Python 库：**
- `pysam`：`pysam.VariantFile('file.vcf')`
- `cyvcf2`：快速VCF解析
- `PyVCF`：较旧但全面
* *EDA方法：**
- 按类型划分的变体计数（SNP、indel、 SV)
- 质量得分分布
- 等位基因频谱
- 转换/颠换比率
- 杂合率
- 缺失基因型分析
- Hardy-Weinberg 平衡
- 注释完整性（如果带注释）

### .bcf - 二进制VCF
* *描述：**压缩二进制变体格式
* *典型数据：**与VCF相同，但二进制
* *用例：**高效变体存储和处理
* *Python库：**
- `pysam`：完全BCF支持
- `cyvcf2`：优化BCF读取
* *EDA方法：**
- 与VCF相同加上：
- 压缩效率
- 索引验证
- 读取性能指标

### .gvcf - 基因组VCF
* *描述：**带有参考置信块的VCF
* *典型数据：**所有位置（变异和非变异）
* *用例：**联合基因分型工作流程，GATK
* *Python文库：**
- `pysam`：GVCF 支持
- 标准 VCF 解析器
* *EDA 方法：**
- 参考块分析
- 覆盖均匀度
- 变异密度
- 基因型质量基因组
- 参考置信分布

## RNA-Seq和表达数据

### .counts - 基因计数矩阵
* *描述：**制表符分隔的基因表达计数
* *典型数据：**每个样本的基因 ID 和读取计数
* *用例：** RNA-seq 定量、差异表达
* *Python 库：**
- `pandas`：`pd.read_csv('file.counts', sep='\t')`
- `scanpy`（用于单细胞）：`sc.read_csv()`
* *EDA 方法：**
- 文库大小分布
- 检测率（每个样本的基因）
- 零膨胀分析
- 计数分布（对数刻度）
- 离群样本检测
- 重复之间的相关性
- 样本关系的PCA

### .tpm / .fpkm - 标准化表达
* *描述：** 标准化基因表达值
* *典型数据：** TPM（每百万份转录本）或 FPKM 值
* *用例：** 跨样本比较、可视化
* *Python 库：**
- `pandas`：标准 CSV 读取
- `anndata`：用于集成分析
* *EDA方法：**
- 表达分布
- 高表达基因鉴定
- 样本聚类
- 批量效应检测
- 变异系数分析
- 动态范围评估

### .mtx - Matrix Market格式
* *描述：**稀疏矩阵格式（单细胞中常见）
* *典型数据：**稀疏计数矩阵（细胞×基因）
* *用例：**单细胞RNA-seq，大型稀疏矩阵
* *Python库：**
- `scipy.io`: `scipy.io.mmread('file.mtx')`
- `scanpy`: `sc.read_mtx('file.mtx')`
* *EDA 方法：**
- 稀疏性分析
- 细胞和基因过滤阈值
- 双峰检测指标
- 线粒体分数
- UMI 计数分布
- 每个细胞的基因检测

### .h5ad - Anndata 格式
* *描述：**基于 HDF5 的注释数据矩阵
* *典型数据：**带有元数据（细胞、基因）的表达矩阵
* *用例：**使用 Scanpy
 进行单细胞 RNA-seq 分析**Python 库：**
- `scanpy`：`sc.read_h5ad('file.h5ad')`
- `anndata`：直接 AnnData 操作
* *EDA 方法：**
- 细胞和基因计数
- 元数据完整性
- 层可用性（原始、归一化）
- 嵌入存在（PCA、UMAP）
- QC 指标分布
- 批次信息
- 细胞类型注释覆盖范围

### .loom - Loom 格式
* *说明：** 基于 HDF5 的组学格式数据
* *典型数据：**带有元数据的表达矩阵
* *用例：**单细胞数据，RNA速度分析
* *Python库：**
- `loompy`：`loompy.connect('file.loom')`
- `scanpy`：可以导入loom 文件
* *EDA 方法：**
- 层分析（拼接、未拼接）
- 行和列属性探索
- 图连通性分析
- 聚类分配
- 特定于速度的度量

### .rds - R 数据序列化
* *描述：** R对象存储（通常是Seurat对象）
* *典型数据：** R分析结果，特别是单细胞
* *用例：** R-Python数据交换
* *Python库：**
- `pyreadr`： `pyreadr.read_r('file.rds')`
- `rpy2`：用于完整的 R 集成
- AnnData 的转换工具
* *EDA 方法：**
- 对象类型识别
- 数据结构探索
- 元数据提取
- 转换验证

* *EDA 方法：**
- 比对块统计
- 物种覆盖范围
- 缺口分析
- 保守评分
- 比对质量metrics

### .axt - 成对比对格式

- 比对分数分布
- 同一性百分比
- 同线性块识别

### .chain - 链比对格式

* *Python库：**

- 链格式的自定义解析器
* *EDA方法：**
- 链分数分布
- 源基因组的覆盖范围
- 缺口分析
- 反演检测
- 映射质量评估

### .psl - 模式空间布局
* *描述：** BLAT/BLAST 比对格式
* *典型数据：** BLAT
 的比对结果**用例：** 转录本映射、相似性搜索
* *Python库：**
- 自定义解析器（制表符分隔）
- `pybedtools`：可以处理 PSL
* *EDA 方法：**
- 匹配百分比分布
- 间隙统计
- 查询覆盖率
- 多重映射分析
- 比对质量指标

- 装配分析工具
* *EDA 方法：**
- 支架统计（N50、L50）
- 间隙类型和尺寸分布
- 组件长度分析
- 装配邻接度量
- 未放置的重叠群分析

- 掩蔽区域分析
- N 含量和分布

### .sizes - 染色体大小
* *说明：** 带有染色体长度的简单格式

* *用例：**基因组浏览器，坐标验证
* *Python库：**
- 使用pandas进行简单文件读取
- 内置于许多基因组工具
* *EDA方法：**
- 基因组大小计算
- 染色体count
- 大小分布
- 核型验证
- 对照参考的完整性检查
