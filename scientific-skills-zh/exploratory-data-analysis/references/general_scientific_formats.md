# 通用科学数据格式参考

此参考涵盖跨多个学科使用的通用科学数据格式。

## 数值和数组数据

### .npy - NumPy 数组
* *描述：** 二进制 NumPy 数组格式
* *典型数据：** 任何数据的 N 维数组类型
* *用例：**用于数值数据的快速 I/O，中间结果
* *Python 库：**
- `numpy`：`np.load('file.npy')`、`np.save()`
- 内存映射访问：`np.load('file.npy', mmap_mode='r')`
* *EDA方法：**
- 数组形状和维数
- 数据类型和精度
- 统计摘要（平均值、标准差、最小值、最大值、百分位数）
- 缺失或无效值（NaN、inf）
- 内存占用
- 值分布和直方图
- 稀疏性分析
- 相关结构（如果是2D）

### .npz - 压缩的NumPy 存档
* *说明：** 一个文件中的多个NumPy 数组
* * 典型数据：** 相关数据的集合数组
* *用例：**将多个数组保存在一起，压缩存储
* *Python库：**
- `numpy`：`np.load('file.npz')`返回类似字典的对象
- `np.savez()`或`np.savez_compressed()`
* *EDA方法：**
- 包含的数组列表
- 单个数组分析
- 数组之间的关系
- 总文件大小和压缩比
- 命名约定
- 数据一致性检查

### .csv - 逗号分隔值
* *描述：**纯文本表格数据
* *典型数据：**实验测量、结果表
* *用例：**通用数据交换、电子表格导出
* *Python库：**
- `pandas`： `pd.read_csv('file.csv')`
- `csv`：内置模块
- `polars`：高性能CSV读取
- `numpy`：`np.loadtxt()`或`np.genfromtxt()`
* *EDA方法：**
- 行和列计数
- 数据类型推断
- 缺失值模式和频率
- 列统计（数字：平均值、标准差；分类：频率）
- 异常值检测
- 相关矩阵
- 重复行检测
- 标头和索引验证
- 编码问题检测

### .tsv / .tab - 制表符分隔值
* *说明：** 制表符分隔的表格数据
* * 典型数据：** 与 CSV 类似，但制表符分隔
* * 使用案例：**生物信息学、文本处理输出
* *Python 库：**
- `pandas`: `pd.read_csv('file.tsv', sep='\t')`
* *EDA 方法：**
- 与 CSV 格式相同
- 制表符与空格验证
- 引用处理

### .xlsx / .xls - Excel 电子表格
* *说明：** Microsoft Excel 二进制/XML 格式
* *典型数据：** 带格式的表格数据、公式
* *用例：** 实验室笔记本、数据输入、报告
* *Python库：**
- `pandas`：`pd.read_excel('file.xlsx')`
- `openpyxl`：完整的 Excel 文件操作
- `xlrd`：读取 .xls（旧版）
* *EDA 方法：**
- 表枚举和名称
- 每表数据分析
- 公式评估
- 合并单元格处理
- 隐藏行/列
- 数据验证规则
- 命名范围
- 仅格式化单元格检测

### .json - JavaScript 对象表示法
* *描述：** 分层文本数据格式
* *典型数据：** 嵌套数据结构、元数据
* *用例：** API 响应、配置、结果
* *Python 库：**
- `json`：内置模块
- `pandas`：`pd.read_json()`
- `ujson`：更快的JSON解析
* *EDA方法：**
- 模式推断
- 嵌套深度
- 键值分布
- 数组长度
- 数据类型一致性
- 缺少键
- 重复检测
- 大小和复杂性指标

### .xml - 可扩展标记语言
* *说明：** 分层标记格式
* *典型数据：**带元数据的结构化数据
* *用例：**基于标准的数据交换，API
* *Python库：**
- `lxml`：`lxml.etree.parse()`
- `xml.etree.ElementTree`：内置XML
- `xmltodict`：将 XML 转换为 dict
* *EDA 方法：**
- 架构/DTD 验证
- 元素层次结构和深度
- 命名空间处理
- 属性与元素内容
- CDATA section
- 文本内容提取
- 兄弟姐妹和孩子计数

### .yaml / .yml - YAML
* *描述：** 人类可读的数据序列化
  * *典型数据：** 配置、元数据、参数
  * *用例：** 实验配置， pipelines
* *Python 库：**
- `yaml`：`yaml.safe_load()` 或 `yaml.load()`
- `ruamel.yaml`：YAML 1.2 支持
* *EDA 方法：**
- 配置结构
- 数据类型处理
- 列表和字典深度
- 锚点和别名使用
- 多文档文件
- 注释保存
- 针对模式的验证

### .toml - TOML 配置
* *说明：**配置文件格式
* *典型数据：**设置、参数
* *用例：**Python 包配置、设置
* *Python 库：**
- `tomli` / `tomllib`：TOML 读取 (tomllib在Python 3.11+中）
- `toml`：读取和写入
* *EDA方法：**
- 节结构
- 键值对
- 数据类型推断
- 嵌套表验证
- 必需与可选字段

### .ini - INI 配置
* *描述：**简单配置格式
* *典型数据：**应用程序设置
* *用例：**遗留配置，简单设置
* *Python 库：**
- `configparser`：内置INI解析器
* *EDA 方法：**
- 节枚举
- 键值提取
- 类型转换
- 注释处理
- 区分大小写

## 二进制和压缩数据

### .hdf5 / .h5 - 分层数据格式 5
* *描述：**大型科学数据集的容器
* *典型数据：**多维数组、元数据、组
* *用例：**大型数据集、多模态数据、并行 I/O
* *Python 库：**
- `h5py`：`h5py.File('file.h5', 'r')`
- `pytables`：高级 HDF5 接口
- `pandas`：通过 HDFStore 进行 HDF5 存储
* *EDA 方法：**
- 组和数据集层次结构
- 数据集形状和数据类型
- 属性和元数据
- 压缩和分块策略
- 内存高效采样
- 数据集关系
- 文件大小和效率
- 访问模式优化

### .zarr - 分块数组存储
* *描述：**云优化分块数组
* *典型数据：**大型N维数组
* *用例：**云存储、并行计算、流
* *Python库：**
- `zarr`： `zarr.open('file.zarr')`
- `xarray`：Zarr 后端支持
* *EDA 方法：**
- 数组元数据和维度
- 块大小优化
- 压缩编解码器和比率
- 同步器和存储类型
- 多尺度层次结构
- 并行访问性能
- 属性元数据

### .gz / .gzip - Gzip压缩
* *描述：**压缩数据文件
* *典型数据：**任何压缩文本或二进制
* *用例：**用于存储/传输的压缩
* *Python库：**
- `gzip`：内置gzip模块
- `pandas`：读取函数中的自动gzip处理
* *EDA方法：**
- 压缩比
- 原始文件类型检测
- 解压验证
- 头信息
- 多成员存档

### .bz2 - Bzip2 压缩
* *说明：** Bzip2 压缩
* *典型数据：** 高度压缩的文件
* *使用案例：** 比 gzip 更好的压缩
* *Python 库：**
- `bz2`：内置 bz2 模块
- pandas 中自动处理
* *EDA 方法：**
- 压缩效率
- 解压time
- 内容验证

### .zip - ZIP 存档
* *描述：** 包含多个文件的存档
* *典型数据：** 文件集合
* *用例：** 文件分发、存档
* *Python 库：**
- `zipfile`：内置 ZIP 支持
- `pandas`：可以读取压缩的 CSV
* *EDA 方法：**
- 存档成员列表
- 每个文件的压缩方法
- 总大小与压缩大小
- 目录结构
- 文件类型分布
- 提取验证

### .tar / .tar.gz - TAR 存档
* *描述：** Unix 磁带存档
* *典型数据：**多个文件和目录
* *用例：**软件分发、备份
* *Python 库：**
- `tarfile`：内置 TAR支持
* *EDA方式：**
- 成员文件列出
- 压缩（如果是.tar.gz、.tar.bz2）
- 目录结构
- 权限保存
- 提取测试

## 时序和波形数据

### .wav - 波形音频
* *描述：**音频波形数据
* *典型数据：**声学信号、录音
* *用例：**声学分析、超声波、信号处理
* *Python库：**
- `scipy.io.wavfile`: `scipy.io.wavfile.read()`
- `wave`: 内置模块
- `soundfile`: 增强型音频 I/O
* *EDA 方法:**
- 采样率和持续时间
- 位深度和通道
- 幅度分布
- 频谱分析（FFT）
- 信噪比
- 削波检测
- 频率内容

### .mat - MATLAB 数据
* *说明：** MATLAB 工作区变量
* *典型数据：** 数组、结构体、单元格
* *用例：** MATLAB-Python 互操作性
* *Python 库：**
- `scipy.io`：`scipy.io.loadmat()`
- `h5py`：对于 MATLAB v7.3 文件（基于 HDF5）
- `mat73`：用于 v7.3 的纯 Python
* *EDA 方法：**
- 变量名称和类型
- 数组维度
- 结构字段探索
- 单元阵列处理
- 稀疏矩阵检测
- MATLAB版本兼容性
- 元数据提取

### .edf - 欧洲数据格式
* *描述：**时间序列数据（尤其是医疗）
* *典型数据：**脑电图、生理信号
* *用例：**医疗信号存储
* *Python库：**
- `pyedflib`：EDF/EDF+读取和写作
- `mne`：神经生理学数据（支持EDF）
* *EDA方法：**
- 信号计数和名称
- 采样频率
- 信号范围和单位
- 记录持续时间
- 注释事件
- 数据质量（饱和度、噪声）
- 患者/研究信息

### .csv（时间序列）
* *描述：** 带有时间戳列的 CSV
* * 典型数据：** 时间索引测量
* * 使用案例：** 传感器数据、监控、实验
* *Python库：**
- `pandas`：`pd.read_csv()`与`parse_dates`
* *EDA方法：**
- 时间范围和分辨率
- 采样规律
- 缺失时间点
- 趋势和季节性
- 平稳性测试
- 自相关
- 异常检测

## 地理空间和环境数据

### .shp - Shapefile
* *描述：** 地理空间矢量数据
* *典型数据：**地理特征（点、线、多边形）
* *用例：**GIS分析、空间数据
* *Python库：**
- `geopandas`：`gpd.read_file('file.shp')`
- `fiona`：下层shape文件访问
- `pyshp`：纯Python shape文件阅读器
* *EDA方法：**
- 几何类型和计数
- 坐标参考系
- 边界框
- 属性表分析
- 几何有效性
- 空间分布
- 多部分特征
- 关联文件（.shx、.dbf、.prj）

### .geojson - GeoJSON
* *描述：** 地理数据的 JSON 格式
* *典型数据：** 具有几何和属性的特征
* *用例：** Web 制图、空间分析
* *Python 库：**
- `geopandas`：本机 GeoJSON 支持
- `json`：解析为 JSON 然后处理
* *EDA 方法：**
- 特征计数和类型
- CRS 规范
- 边界框计算
- 属性模式
- 几何复杂度
- 嵌套结构

### .tif / .tiff（地理空间）
* *描述：**具有空间参考的GeoTIFF
* *典型数据：**卫星图像、DEM、栅格
* *用例：**遥感、地形分析
* *Python库：**
- `rasterio`：`rasterio.open('file.tif')`
- `gdal`：地理空间数据抽象库
- `xarray` 和 `rioxarray`：N 维地理空间数组
* *EDA方法：**
- 栅格尺寸和分辨率
- 波段计数和描述
- 坐标参考系
- 地理变换参数
- 无数据值处理
- 像素值分布
- 直方图分析
- 概述和金字塔

### .nc / .netcdf - 网络通用数据形式
* *描述：**基于自描述数组的数据
* *典型数据：**气候、大气、海洋数据
* *用例：**科学数据集、模型输出
* *Python库：**
- `netCDF4`：`netCDF4.Dataset('file.nc')`
- `xarray`：`xr.open_dataset('file.nc')`
* *EDA 方法：**
- 变量枚举
- 维度分析
- 时间序列属性
- 空间覆盖
- 属性元数据（CF 约定）
- 坐标系
- 分块和压缩
- 数据质量标志

### .grib / .grib2 - 网格二进制
* *描述：**气象数据格式
* *典型数据：**天气预报、气候数据
* *用例：**数值天气预报
* *Python库：**
- `pygrib`：GRIB文件读取
- `xarray` 和 `cfgrib`：GRIB 到 xarray
* *EDA 方法：**
- 消息库存
- 参数和级别类型
- 空间网格规范
- 时间覆盖范围
- 集成成员
- 预测与分析
- 数据打包和精度

### .hdf4 - HDF4 格式
* *描述：** 较旧的HDF 格式
* * 典型数据：** NASA 地球科学数据
* * 使用案例：** 卫星数据（MODIS、等）
* *Python 库：**
- `pyhdf`：HDF4 访问
- `gdal`：可以读取 HDF4
* *EDA 方法：**
- 科学数据集列表
- Vdata 和属性
- 维度尺度
- 元数据提取
- 质量标志
- 转换为HDF5 或NetCDF

## 专业科学格式

### .fits - 灵活的图像传输系统
* *描述：** 天文数据格式
* *典型数据：**来自望远镜的图像、表格、光谱
* *用例：**天文观测
* *Python库：**
- `astropy.io.fits`：`fits.open('file.fits')`
- `fitsio`：替代拟合库
* *EDA方法：**
- HDU（标头数据单元）结构
- 图像尺寸和WCS
- 标头关键字分析
- 表格列描述
- 数据类型和缩放
- FITS 约定合规性
- 校验和验证

### .asdf - 高级科学数据格式
* *描述：**天文学的下一代数据格式
* *典型数据：**复杂的分层科学数据
* *用例：**詹姆斯·韦伯太空望远镜数据
* *Python库：**
- `asdf`：`asdf.open('file.asdf')`
* *EDA 方法：**
- 树结构探索
- 模式验证
- 内部与外部数组
- 压缩方法
- YAML 元数据
- 版本兼容性

### .root - ROOT数据格式
* *描述：** CERN ROOT框架格式
* *典型数据：**高能物理数据
* *用例：**粒子物理实验
* *Python库：**
- `uproot`：纯Python ROOT阅读
- `ROOT`：官方PyROOT绑定
* *EDA方法：**
- T树结构
- 分支类型和条目
- 直方图库存
- 事件循环统计
- 文件压缩
- 分层分析

### .txt - 纯文本数据
* *描述：**基于通用文本的数据
* *典型数据：**制表符/空格分隔，自定义格式
* *用例：**简单数据交换，日志
* *Python库：**
- `pandas`：带有自定义分隔符的 `pd.read_csv()`
- `numpy`：`np.loadtxt()`、`np.genfromtxt()`
- 内置文件读取
* *EDA 方法：**
- 格式检测（分隔符、 header)
- 数据类型推断
- 注释行处理
- 缺失值代码
- 列对齐
- 编码检测

### .dat - 通用数据文件
* *说明：** 二进制或文本数据
* *典型数据：**仪器输出，自定义格式
* *用例：**各种科学仪器
* *Python库：**
- 格式特定：需要结构知识
- `numpy`：二进制的`np.fromfile()`
- `struct`：解析二进制结构
* *EDA方法：**
- 二进制与文本确定
- 标头检测
- 记录结构推断
- 字节序
- 数据类型模式
- 验证文档

### .log - 日志文件
* *描述：** 来自软件/仪器的文本日志
* *典型数据：** 带时间戳的事件、消息
* *用例：** 故障排除、实验跟踪
* *Python 库：**
- 内置文件读取
- `pandas`：结构化日志解析
- 正则表达式解析
* *EDA方法：**
- 日志级别分布
- 时间戳解析
- 错误和警告频率
- 事件排序
- 模式识别
- 异常检测
