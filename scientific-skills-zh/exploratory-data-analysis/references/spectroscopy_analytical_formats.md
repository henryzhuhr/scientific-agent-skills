# 光谱和分析化学文件格式参考

此参考涵盖了各种光谱技术和分析化学仪器中使用的文件格式。

## NMR 光谱

### .fid - NMR 免费感应衰减
* *说明：** 来自 Bruker、Agilent、 JEOL
* *典型数据：**复杂时域信号
* *用例：** NMR 波谱、结构解析
* *Python 库：**
- `nmrglue`：`nmrglue.bruker.read_fid('fid')` 或 `nmrglue.varian.read_fid('fid')`
- `nmrstarlib`：NMR 数据处理
* *EDA 方法：**
- 时域信号衰减
- 采样率和采集时间
- 数据点数量
- 信噪比估计
- 基线漂移评估
- 数字滤波器效果
- 采集参数验证
- 变迹函数选择

### .ft / .ft1 / .ft2 - NMR 频域
* *描述：** 傅里叶变换NMR 谱
* * 典型数据：** 处理后的频域数据
* *用例：** NMR 分析、峰积分
* *Python 库：**
- `nmrglue`：频域读数
- 自定义处理管道
* *EDA 方法：**
- 峰选取和积分
- 化学位移范围
- 基线校正质量
- 相位校正评估
- 参考峰识别
- 光谱分辨率
- 伪影检测
- 多重性分析

### .1r / .2rr - Bruker NMR 处理数据
* *描述：**布鲁克处理的谱图（真实部分）
* *典型数据：**1D或2D处理的NMR谱
* *用例：**使用Bruker软件进行NMR数据分析
* *Python库：**
- `nmrglue`：Bruker格式支持
* *EDA方法：**
- 处理参数审查
- 窗函数效应
- 零填充评估
- 线性预测验证
- 光谱伪影

### .dx - NMR JCAMP-DX
* *描述：** NMR
 的 JCAMP-DX 格式**典型数据：**标准化 NMR 谱
* *用例：**软件
* *Python 库之间的数据交换：**
- `jcamp`：JCAMP阅读器
- `nmrglue`：可以导入 JCAMP
* *EDA 方法：**
- 格式合规性
- 元数据完整性
- 峰表验证
- 积分值
- 化合物识别信息

### .mnova - Mnova 格式
* *描述：** Mestrelab 研究 Mnova 格式
* *典型数据：** 带有处理信息的 NMR 数据
* *使用案例：** Mnova 软件工作流程
* *Python 库：**
- `nmrglue`：有限的 Mnova 支持
- 标准格式转换工具
* *EDA 方法：**
- 多谱图处理
- 处理流程审查
- 定量数据
- 结构分配

## 质谱分析

### .mzML - 质谱标记语言
* *描述：**基于XML的标准MS格式
* *典型数据：**MS谱图、色谱图、元数据
* *用例：**蛋白质组学、代谢组学、脂质组学
* *Python库：**
- `pymzml`： `pymzml.run.Reader('file.mzML')`
- `pyteomics.mzml`：`pyteomics.mzml.read('file.mzML')`
- `MSFileReader`：各种包装器
* *EDA 方法：**
- 扫描计数和 MS 水平分布
- 保留时间范围和TIC
- m/z 范围和分辨率
- 母离子选择
- 裂解模式
- 仪器配置
- 质量控制指标
- 数据完整性

### .mzXML - 质谱法XML
* *描述：**传统 XML MS 格式
* *典型数据：**质谱和色谱图
* *用例：**蛋白质组学工作流程（较旧）
* *Python 库：**
- `pyteomics.mzxml`
- `pymzml`：可以读取mzXML
* *EDA方法：**
- 与mzML
类似-版本兼容性
- 转换质量评估
