# 科学研究报告指南

## 概述

报告指南是基于证据的建议，针对报告特定类型的研究时应包含哪些信息。他们提供清单和流程图，以确保报告完整、准确和透明，这对于读者评估研究有效性和其他研究人员复制工作至关重要。

EQUATOR 网络（增强健康研究的质量和透明度）维护着一个综合的报告指南库。使用适当的报告指南可以提高稿件质量并增加发表接受的可能性。

## 为什么使用报告指南？

### 好处

* *对于作者：**
- 确保不会忘记任何重要的事情
- 提高接受率
- 改进稿件组织
- 减少审稿人对额外内容的要求信息

* *对于读者和审稿人：**
- 能够对研究有效性进行严格评估
- 促进系统评价和荟萃分析
- 提高对实际完成情况的理解

* *对于科学：**
- 增强可重复性
- 减少研究浪费
- 提高透明度
- 实现更好的证据合成

### 何时使用

- **在研究设计期间**：许多指南包括方案版本（例如，用于试验方案的SPIRIT）
- **在稿件起草过程中**：使用清单确保涵盖所有项目
- **之前提交**：验证遵守情况并经常提交稿件检查表
- **许多期刊要求**：报告指南检查表作为提交的一部分

## 按研究类型划分的主要报告指南

### CONSORT - 随机对照试验

* *全名：**报告试验综合标准

* *何时使用：**任何随机对照试验 (RCT)，包括试点和可行性试验

* *最新版本：** CONSORT 2010（更新声明）

* *关键组成部分：**
- **清单**：25 个项目，涵盖标题、摘要、简介、方法、结果、讨论
- **流程图**：参与者流程包括注册、分配、跟进、分析

* *主要检查清单项目：**
1. 标题将研究标识为随机试验 
2. 结构化摘要
3. 科学背景和基本原理
4. 具体目标和假设
5. 试验设计说明（并行、交叉、阶乘等）
6. 参加者资格标准
7. 数据收集的设置和位置
8. 对于复制
9 的干预措施进行了足够详细的描述。主要和次要结果定义为
10. 样本量确定和功效计算
11. 随机化序列生成
12. 配置隐蔽机构
13. 致盲实施
14. 统计方法
15. 包含退出原因的参与者流程
16. 招募日期和后续日期
17. 基线特性表
18. 每个结果的分析结果
19. 危害和不良事件
20. 试用限制
21. 通用性
22. 解释与结果一致
23. 试用注册号
24. 完整协议访问
25. 资金来源

* *特定设计的扩展：**
- 整群随机试验的CONSORT
- 非劣效性和等效性试验的CONSORT
- 实用试验的CONSORT
- 交叉试验的CONSORT
- 交叉试验的CONSORT N-of-1 试验
- CONSORT 阶梯楔形设计

* *访问位置：** http://www.consort-statement.org/

### STROBE - 观察性研究

* *全名：** 加强流行病学观察性研究的报告

* *何时使用：**队列研究、病例对照研究和横断面研究

* *最新版本：** STROBE 2007（广泛采用的标准）

* *涵盖的关键研究设计：**
- **队列**：及时跟踪暴露组和未暴露组
- **病例对照**：比较病例和病例之间的暴露史控制
- **横截面**：同时测量暴露和结果

* *主要检查表项目（22项）：**
1. 标题和摘要表明研究设计
2. 背景和基本原理
3. 目标
4. 研究设计原理
5. 设置、地点和日期
6. 资格标准及评选方法
7. 明确定义的变量（结果、暴露、混杂因素）
8. 数据来源及测量方法
9. 偏差管理策略
10. 研究尺寸合理性
11. 定量变量的处理
12. 统计方法包括混杂和相互作用
13. 敏感性分析
14. 未参加原因的参加者流程
15. 描述性数据包括随访时间
16. 结果数据
17. 未调整和调整估计的主要结果
18. 其他分析（亚组、敏感性分析）
19. 主要结果摘要
20. 潜在偏见讨论的局限性
21. 解释和概括性
22. 资金来源和作用

* *扩展：**
- STROBE-ME（分子流行病学）
- RECORD（定期收集的健康数据）
- STROBE-RDS（受访者驱动采样）

* *访问位置：** https://www.strobe-statement.org/

### PRISMA - 系统评价和元分析

* *全名：**系统评价和元分析的首选报告项目

* *何时使用：**带或不带元分析的系统评价

* *最新版本：** PRISMA 2020（重要更新）

* *关键组成部分：**
- **清单**：涵盖所有部分的 27 个项目
- **流程图**：研究选择过程

  * *主要部分：**
1. **标题**：确定为系统评价/荟萃分析
2. **摘要**：结构化摘要
3. **简介**：基本原理和目标
4. **方法**：
  - 资格标准
  - 信息来源（数据库、日期）
  - 搜索策略（至少一个数据库的完整策略）
  - 选择过程
  - 数据收集过程
  - 提取的数据项
  - 偏差风险评估
  - 效果测量
  - 综合方法
  - 报告偏倚评估
  - 确定性评估（例如，GRADE）
5. **结果**：
  - 研究选择流程图
  - 研究特征
  - 偏倚风险评估结果
  - 综合结果（荟萃分析，如果适用）
  - 报告偏倚
  - 证据的确定性
6. **讨论**：
  - 限制
  - 解释
  - 含义

  * *扩展：**
- PRISMA for Abstracts
- PRISMA for Protocols (PRISMA-P)
- PRISMA for Network荟萃分析
- 用于范围界定审查的 PRISMA (PRISMA-ScR)
- 用于个体患者数据的 PRISMA
- 用于诊断测试准确性的 PRISMA
- 用于以股权为中心的审查的 PRISMA

* * 访问位置：** http://www.prisma-statement.org/

## 如何在学习计划期间使用报告指南

###

1. **根据研究设计
2确定相关指南**。 **审查需要规划的清单项目**（例如随机化、盲法）
3. **设计研究**以确保捕获所有必需的元素
4. **考虑方案指南**（例如，用于试验的 SPIRIT）

### 在手稿起草期间

1. **从指南网站
2下载清单**。 **系统地完成每个项目**
3. **注意手稿中每个项目的地址**（页码/行号）
4. **修改手稿**以包括缺失的项目
5. **酌情使用流程图**

### 提交之前

1. **完整的正式清单**，页码为
2. **查看所有项目**已充分解决
3. **如果期刊需要
4，请在提交时包含清单**。 **在求职信或方法中注意遵循指南**

### 检查清单条目示例

```
Item 7: Eligibility criteria for participants, and the settings and locations where the data were collected
Page 6, lines 112-125: "Participants were community-dwelling adults aged 60-85 years with mild cognitive impairment (MCI) as defined by Petersen criteria. Recruitment occurred from three memory clinics in Boston, MA, between January 2022 and December 2023."
```

## 常见错误以及如何避免它们

### 错误1：完全不使用指南

* *影响：**缺少关键信息，接受机会较低

* *解决方案：**从研究计划阶段识别并使用适当的指南

### 错误2：仅在手稿完成后使用指南

* *影响：**可能意识到未收集关键数据或记录

* *解决方案：** 在研究设计和数据收集期间审查指南

### 错误 3：清单完成不完整

* *影响：** 遗漏的项目仍未报告

* *解决方案：** 系统地处理每个清单项目

### 错误 4：使用过时的指南

* *影响：** 缺少报告标准的最新改进

* *解决方案：** 始终检查最新版本官方指南网站

### 错误5：使用错误的研究设计指南

* *影响：** 未报告重要的设计特定元素

* *解决方案：** 仔细地将研究设计与适当的指南匹配

### 错误6：未在需要时提交检查表

* *影响：** 编辑部拒绝或延迟

* *解决方案：** 检查期刊提交指南并包括清单

### 错误7：没有具体性的通用报告

* *影响：** 复制或评估的细节不足

* *解决方案：** 为每个项目提供具体、详细的信息

## 期刊要求

### 许多期刊现在需要：

1. **遵守方法
2 中报告指南的声明**。 **已完成的清单**作为补充文件
3上传。 **清单上的页/行号**指示项目的地址
4. **流程图**如手稿中的图

### 示例方法声明：

```
"This study is reported in accordance with the Strengthening the Reporting of
Observational Studies in Epidemiology (STROBE) statement. A completed STROBE
checklist is provided as Supplementary File 1."
```

### 具有强烈要求的期刊：

- PLOS 期刊（需要特定设计的检查表）
- BMJ（需要 CONSORT、PRISMA 和其他）
- The Lancet（需要遵守声明）
- JAMA 和 JAMA Network 期刊（需要清单）
- Nature 组合期刊（鼓励指南）

## 特定地点报告要求

### 按地点类型划分的报告标准

|场地类型 |使用指南 |透明度要求|
|---------|--------------|----------------------------------------|
| **医学期刊** |强制（CONSORT、STROBE 等）|提交时需要核对清单 |
| **PLOS/BMC** |学习类型强制 |作为补充上传的清单|
| **自然/科学** |推荐|强调方法完整性|
| **机器学习会议** |没有正式的指导方针|所需的重现性详细信息 |

### ML 会议报告标准

* *NeurIPS/ICML/ICLR 重现性要求：**
- **数据集**：名称、版本、访问方法、预处理
- **代码**：可用性声明； GitHub common
- **超参数**：报告的所有设置（学习率、批量大小等）
- **种子**：用于再现性的随机种子
- **计算资源**：使用的 GPU、训练时间
- **统计意义**：误差线、置信区间、多次运行
- **更广泛的影响**声明 (NeurIPS)：社会影响

* *要包括的内容（通常在附录中）：**
- 完整的超参数设置
- 训练细节和收敛标准
- 硬件规格
- 软件版本（PyTorch 2.0 等）
- 数据集分割和任何预处理
- 评估指标和协议

### 执行和评估

* *检查的内容：**
- **医学期刊**：已上传清单；方法中的遵守声明；系统完整性
- **PLOS/BMC**：某些设计的强制性检查表；强调再现性
- **高影响力**：复制方法的充分性（通常不需要检查表）
- **机器学习会议**：再现性检查表（NeurIPS）；代码可用性越来越令人期待

* *导致拒绝的常见问题：**
- 缺少所需的清单（医学期刊）
- 复制方法细节不足
- 缺少关键信息（随机化、致盲、功效计算）
- 需要时没有数据/代码可用性声明

* *方法声明示例：**

* *期刊(STROBE):**
```
This study followed STROBE reporting guidelines. Checklist provided in Supplement 1.
```

* *ML 会议（再现性）:**
```
Code available at github.com/user/project. All hyperparameters in Appendix A.
Training used 4×A100 GPUs (~20 hours). Seeds: {42, 123, 456}.
```
