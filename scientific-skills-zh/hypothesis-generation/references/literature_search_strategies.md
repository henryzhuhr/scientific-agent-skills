# 文献检索策略

## 寻找科学证据的有效技巧

全面的文献检索对于在现有证据中建立假设至关重要。本参考文献提供了 PubMed（生物医学文献）和一般科学检索的策略。

## 检索策略框架

### 三相方法

1. **广泛探索：** 了解景观并确定关键概念
2. **有针对性的搜索：** 针对特定的机制、理论或发现
3. **引文挖掘：**遵循关键论文中的参考文献和相关文章

### 搜索之前

* *明确搜索目标：**
- 现象的哪些方面需要证据？
- 哪些类型的研究最相关（评论、初步研究、方法）？
- 哪些时间范围相关（仅限最近或历史） 
- 需要什么级别的证据（机械、相关、因果）？

## PubMed 搜索策略

### 何时使用 PubMed

将 WebFetch 与 PubMed URL 结合使用用于：
- 生物医学和生命科学研究
- 临床研究和医学文献
- 分子、细胞和生理机制
- 疾病病因学和病理学
- 药物和治疗研究

### 有效的PubMed 搜索技术

#### 1. 从回顾开始文章

* *为什么：**评论综合文献，识别关键概念，并提供全面的参考列表。

* *搜索策略：**
- 在搜索词中添加“评论”
- 使用 PubMed 过滤器：文章类型 → 评论、系统评论、荟萃分析
- 查找最近的评论（最后 2-5 条）年）

* *示例搜索：**
- `https://pubmed.ncbi.nlm.nih.gov/?term=wound+healing+diabetes+review`
- `https://pubmed.ncbi.nlm.nih.gov/?term=gut+microbiome+cognition+systematic+review`

#### 2. 使用 MeSH 术语（医学主题词）

* *原因：** MeSH 术语是捕获概念变体的标准化词汇。

* *策略：**
- PubMed 自动建议 MeSH 术语
- 帮助查找针对同一概念使用不同术语的论文
- 比仅关键字搜索更全面

* *示例：**
- 使用 MeSH 术语“心肌”而不是“心脏病”梗塞”
- 捕获使用“MI”、“心脏病”、“心肌梗塞”等的论文。

#### 3. 布尔运算符和高级语法

* *AND:** 缩小搜索范围（必须存在所有术语）
- `diabetes AND wound healing AND inflammation`

* *OR:** 扩大搜索范围（任何术语都可以）存在）
- `(Alzheimer OR dementia) AND gut microbiome`

* *不：** 排除术语
- `cancer treatment NOT surgery`

* *引号：** 精确短语
- `"oxidative stress"`

* *通配符：**变体
- `gene*` 查找基因、基因、遗传、遗传学

#### 4. 按出版物类型和日期过滤

* *出版物类型：**
- 临床试验
- 荟萃分析
- 系统评价
- 研究支持，NIH
- 随机对照试验

* *日期过滤器：**
- 近期工作（过去 2-5 年）：前沿发现
- 历史工作：基础研究
- 特定时间段：跟踪理解的发展

#### 5. 使用“类似文章”和“引用者”

* *策略：**
- 查找一篇高度相关的论文
- 点击“类似文章”查看相关工作
- 使用工具引用来查找在此基础上构建的更新工作

### PubMed 按假设目标搜索示例

* *机制理解：**
```
https://pubmed.ncbi.nlm.nih.gov/?term=(mechanism+OR+pathway)+AND+[phenomenon]+AND+(molecular+OR+cellular)
```

* *因果关系：**
```
https://pubmed.ncbi.nlm.nih.gov/?term=[exposure]+AND+[outcome]+AND+(randomized+controlled+trial+OR+cohort+study)
```

* *生物标志物和关联：**
```
https://pubmed.ncbi.nlm.nih.gov/?term=[biomarker]+AND+[disease]+AND+(association+OR+correlation+OR+prediction)
```

* *治疗有效性：**
```
https://pubmed.ncbi.nlm.nih.gov/?term=[intervention]+AND+[condition]+AND+(efficacy+OR+effectiveness+OR+clinical+trial)
```

## 一般科学网络搜索策略

### 何时使用网络搜索

使用网络搜索：
- 非生物医学科学（物理、化学、材料、地球科学）
- 跨学科主题
- 最近的预印本和未发表的作品
- 灰色文献（技术报告、会议记录）
- 更广泛的背景和跨领域类比

### 有效的网络搜索技巧

#### 1. 使用特定领域的搜索术语

* *包括特定领域的术语：**
- 化学：“机制”、“反应途径”、“合成”
- 物理：“模型”、“理论”、“实验验证”
- 材料科学： “性质”、“表征”、“合成”
- 生态学：“种群动态”、“群落结构”

#### 2. 目标学术来源

* *搜索运算符：**
- `site:arxiv.org` - 预印本（物理、CS、数学、定量生物学）
- `site:biorxiv.org` - 生物学预印本
- `site:edu` - 学术机构
- `filetype:pdf` - 学术论文（经常）

* *示例搜索：**
- `superconductivity high temperature mechanism site:arxiv.org`
- `CRISPR off-target effects site:biorxiv.org`

#### 3. 搜索作者和实验室

* *当您找到相关论文时：**
- 搜索作者的其他作品
- 查找他们的实验室网站以获取未发表的作品
- 识别该领域的关键研究小组

#### 4. 使用Google Scholar 方法

* *策略：**
- 使用“引用者”查找较新的相关工作
- 使用“相关文章”扩大搜索
- 设置日期范围以关注最近的工作
- 使用作者：运算符查找特定研究人员

#### 5. 结合一般性和特定性术语

* *结构：**
- 具体现象+一般概念
- “番茄植株生长”+“细菌促进”
- “认知衰退”+“肠道微生物组”

* *布尔逻辑：**
- 使用引号表示确切的短语： `"spike protein mutation"`
- 使用 OR 替代：`(transmissibility OR transmission rate)`
- 组合：`"spike protein" AND (transmissibility OR virulence) AND mutation`

## 跨数据库检索策略

### 综合文献检索工作流程

1. **从评论开始（PubMed 或网络搜索）：**
  - 识别关键概念和术语
  - 记下有影响力的论文和研究人员
  - 了解该领域的当前状态

2. **重点初级研究（PubMed）：**
  - 搜索特定机制
  - 查找实验证据
  - 确定方法

3. **通过网络搜索扩大：**
  - 查找其他领域的相关工作
  - 找到最近的预印本
  - 识别类似的系统

4. **引文挖掘：**
  - 关注关键论文的参考文献
  - 使用“引用者”查找最近的工作
  - 跟踪有影响力的研究

5. **迭代细化：**
  - 添加论文中发现的新术语
  - 如果结果太多则缩小范围
  - 如果相关结果太少则扩大

## 主题特定搜索策略

### 机制和路径

* *目标：**了解某事如何作品

* *搜索成分：**
- 现象+“机制”
- 现象+“途径”
- 现象+可疑的特定分子/途径

* *示例：**
- `diabetic wound healing mechanism inflammation`
- `autophagy pathway cancer`

### 关联和相关性

* *目标：**查找相关因素

* *搜索组件：**
- 变量 A + 变量 B +“关联”
- 变量 A + 变量 B + “相关性”
- 变量 A +“预测”+ 变量 B

* *示例：**
- `vitamin D cardiovascular disease association`
- `gut microbiome diversity predicts cognitive function`

### 干预和治疗

* *目标：** 证据作品

* *搜索组件：**
- 干预+条件+“疗效”
- 干预+条件+“随机对照试验”
- 干预+条件+“治疗结果”

* *示例：**
- `probiotic intervention depression randomized controlled trial`
- `exercise intervention cognitive decline efficacy`

### 方法与技术

* *目标：**如何检验假设

* *搜索组件：**
- 方法名称+应用领域
- “如何测量”+现象
- 技术+验证

* *示例：**
- `CRISPR screen cancer drug resistance`
- `measure protein-protein interaction methods`

### 类似系统

* *目标：** 从相关现象中找到见解

* *搜索组成部分：**
- 机制+不同系统
- 相似现象+不同有机体/条件

* *示例：**
- 如果研究植物-微生物共生：搜索 `nitrogen fixation rhizobia legumes`
- 如果研究耐药性：搜索 `antibiotic resistance evolution mechanisms`

## 评估论文影响力和质量

### 引用计数显着性

引用计数表明影响力以及在该领域的重要性。解释相对于论文年龄和领域规范的引用：

|纸时代|引文|解读|
|---------|-----------|----------------|
| 0-3岁| 20+ |值得注意 - 获得关注 |
| 0-3岁| 100+ |极具影响力 - 已经产生重大影响 |
| 3-7年| 100+ |重大既定贡献|
| 3-7年| 500+ |里程碑-领域重大贡献|
| 7 年以上 | 500+ |开创性的 - 广泛认可的重要工作 |
| 7 年以上 | 1000+ |基础 - 领域定义论文 |

* *特定领域的考虑因素：**
- 生物医学/临床：较高的引用规范（NEJM 论文通常超过 1000 篇）
- 计算机科学：会议引用比期刊更重要
- 数学/物理：较低的引用规范，较长的引用half-lives
- 社会科学：中等引用规范，高图书引用率

### 期刊影响因子指南

* *1 级 - 顶级场地（始终首选）：**
- **普通科学：** Nature (IF ~65)、Science (IF ~55)、Cell (IF ~65)、PNAS (IF ~12)
- **医学：** NEJM (IF ~175)、Lancet (IF ~170)、JAMA (IF ~120)、BMJ (IF ~93)
- **领域旗舰：** 自然医学、自然生物技术、自然方法、自然遗传学

* *第 2 层 - 高影响专业（强）偏好）：**
- 影响因子 >10
- 示例：JAMA Internal Medicine、Annals of Internal Medicine、Circulation、Blood
- 顶级 ML/AI 会议：NeurIPS、ICML、ICLR（相当于 IF 15-25）

* *第 3 级 - 受尊重的专业期刊（相关时包括）：**
- 影响因子 5-10
- 知名学会期刊
- 索引良好的专业期刊

  * *第 4 级 - 其他同行评审（谨慎使用）：**
- 影响因子<5
- 仅在直接相关且不存在更好来源的情况下引用

### 作者跟踪记录评估

优先选择知名研究人员的论文：

* *强作者指标：**
- **高 h 指数：** 在已建立的领域>40，对于早期职业明星>20
- **多个 Tier-1出版物：** 自然/科学/细胞家族的记录
- **隶属机构：** 领先的研究大学和研究所
- **认可：** 奖项、奖学金、编辑职位
- **第一/最后作者：** 多篇高被引论文

* *如何检查作者声誉：**
1. Google Scholar 简介：查看 h-index、i10-index、总引用次数
2. PubMed：搜索作者姓名，评论发表地点
3. 机构页面：查看职位、奖项、补助金
4. ORCID 简介：完整出版历史

### 会议排名意识（计算机科学/人工智能）

对于 ML/AI 和计算机科学主题，会议排名很重要：

* *A*（旗舰）- 相当于自然/科学：**
- NeurIPS（神经信息处理系统）
- ICML（机器学习国际会议）
- ICLR（学习表示国际会议）
- CVPR（计算机视觉和模式识别）
- ACL（计算语言学协会）

* *A（优秀）- 相当于 Tier-2期刊：**
- AAAI、IJCAI（AI 通用）
- EMNLP、NAACL (NLP)
- ECCV、ICCV（计算机视觉）
- SIGKDD、WWW（数据挖掘）

* *B（良好）- 相当于 Tier-3期刊：**
- COLING、CoNLL (NLP)
- WACV、BMVC（计算机视觉）
- 大多数 ACM/IEEE 专业会议

## 评估源质量

### 主要研究质量指标

* *强质量信号：**
- 在一级或二级场所发表
- 论文年龄的高引用计数
- 由具有良好跟踪记录的知名研究人员撰写
- 大样本量（统计功效）
- 预注册研究（减少偏见）
- 适当的控制和方法
- 与其他发现一致
- 透明的数据和方法

* *危险信号：**
- 发表在掠夺性或低影响期刊
- 由没有既定记录的作者撰写
- 没有同行评审（使用谨慎）
- 未披露利益冲突
- 未明确描述方法
- 没有非凡证据的非凡主张
- 在没有解释的情况下与大量证据相矛盾

### 审查质量指标

* *系统审查（最高质量）：**
- 发表在 Tier-1/2 场所（Cochrane、Nature Reviews、Annual Reviews）
- 预定义的检索策略
- 明确的纳入/排除标准
- 纳入研究的质量评估
- 定量综合（荟萃分析）

* *叙述评论（质量参差不齐）：**
- 领域的专家综合
- 可能有选择偏差
- 对于上下文和框架很有用
- 检查作者的专业知识和引文
- 更喜欢按领域的Tier-1/2 期刊中的评论领导者

## 文献检索中的时间管理

### 适当分配检索时间

* *对于简单的假设（30-60分钟）：**
- 1-2篇广泛的评论文章
- 3-5篇有针对性的主要研究论文
- 最近的快速网络搜索进展

* *对于复杂的假设（1-3小时）：**
- 不同方面的多篇评论
- 10-15篇主要研究论文
- 跨数据库的系统搜索
- 关键论文的引文挖掘

* *对于有争议的主题（3小时以上）：**
- 系统审查方法
- 识别竞争观点
- 跟踪历史发展
- 交叉参考结果

### 回报递减

* *你搜索得足够多的迹象：**
- 找到相同的论文重复地
- 新的搜索大多产生不相关的论文
- 有足够的证据来支持/将假设置于背景中
- 多个独立的证据线汇聚

* *何时搜索更多：**
- 理解上仍然存在主要差距
- 相互矛盾的证据需要解决
- 假设似乎与文献不一致
- 需要具体的方法信息

## 记录搜索结果

### 要捕获的信息

* *对于每篇相关论文：**
- 完整引用（作者，年份，期刊，标题）
- 与假设相关的主要发现
- 研究设计和方法
- 作者指出的局限性
- 它与假设的关系

### 组织发现

* *分组依据：**
- 支持假设A、B、C
- 方法论方法
- 需要的冲突发现解释
- 当前知识中的差距

* *综合笔记：**
- 什么是公认的？
- 什么是有争议或不确定的？
- 其他系统中存在哪些类比？
- 常用的方法是什么？

### 假设的引用组织报告

* *对于报告结构：**为两个受众组织引文：

* *正文（15-20个关键引文）：**
- 最有影响力的论文（被高度引用的开创性研究）
- 最近的明确证据（过去2-3年）
- 直接支持每个假设的关键论文（每个假设3-5篇）假设）
- 综合该领域的主要评论

* *附录 A：综合文献综述（40-60+ 引文）：**
- **历史背景：** 建立领域的基础论文
- **当前理解：** 最近的评论和荟萃分析
- **假设特定证据：** 每个假设 8-15 篇论文，涵盖：
  - 直接支持证据
  - 相关系统中的类似机制
  - 方法论先例
  - 理论框架论文
- **冲突的发现：** 代表不同观点的论文
- **知识差距：** 识别局限性或未解答问题的论文

  * *目标引用密度：** 目标引用总数超过50篇，为所有主张提供全面支持并论证透彻文献基础。

* *附录A的分组策略：**
1. 背景和背景文件
2. 目前的理解和建立的机制
3. 支持每个假设的证据（单独的小节）
4. 矛盾或替代结果
5. 方法论和技术论文

## 实用搜索工作流程

### 分步过程

1. **定义搜索目标（5 分钟）：**
  - 现象的哪些方面需要证据？
  - 什么会支持或反驳假设？

2. **广泛的评论搜索（15-20 分钟）：**
  - 查找 1-3 篇评论文章
  - 浏览摘要以了解相关性
  - 注意关键概念和术语

3. **有针对性的初步研究（30-45 分钟）：**
  - 搜索特定机制/证据
  - 阅读摘要、扫描图表和结论
  - 遵循最有希望的参考文献

4. **跨域搜索（15-30 分钟）：**
  - 寻找其他系统中的类比
  - 查找最近的预印本
  - 识别新兴趋势

5. **引文挖掘（15-30 分钟）：**
  - 遵循关键论文的参考文献
  - 在最近的工作中使用“引用者”
  - 识别开创性研究

6. **综合发现（20-30 分钟）：**
  - 总结每个假设的证据
  - 记录模式和矛盾
  - 识别知识差距

### 迭代和细化

 * *当初始搜索不足时：**
  - 如果太少，则扩大术语结果
- 如果结果太多，请添加特定机制/途径
- 尝试替代术语
- 搜索相关现象
- 查阅评论文章以获得更好的搜索词

* *需要更多搜索的危险信号：**
- 只找到弱或间接证据
- 所有证据来自单个实验室或来源
- 证据似乎与基本原则不一致
- 现象的主要方面缺乏任何相关文献

## 常见搜索陷阱

### 要避免的陷阱

1. **确认偏倚：**仅寻找支持首选假设
的证据 - **解决方案：**积极寻找矛盾的证据

2. **近期偏差：** 仅考虑最近的工作，缺少基础研究
  - **解决方案：** 包括历史搜索，跟踪思想的发展

3. **太窄：**由于限制性术语
而缺少相关工作 - **解决方案：**使用OR运算符，尝试替代术语

4. **太宽泛：**被不相关的结果淹没
  - **解决方案：**添加特定术语，使用过滤器，将概念与AND

5结合起来。 **单一数据库：** 缺少其他领域的重要工作
 - **解决方案：** 搜索 PubMed 和一般网络，尝试特定领域的数据库

6. **停止得太早：** 没有足够的证据支持假设
  - **解决方案：** 设定最低目标（例如，每个假设方面2篇评论+ 5篇主要论文）

7. **精挑细选：**仅引用支持性论文
  - **解决方案：**代表全方位证据，承认矛盾

## 特殊案例

### 新兴主题（有限文献）

* *当很少发表的工作存在时：**
- 搜索相关系统中的类似现象
- 寻找预印本（arXiv、bioRxiv）
- 查找会议摘要和海报
- 识别可能适用的理论框架
- 注意假设生成中的有限证据

### 有争议的主题（冲突）文献）

* *当证据相互矛盾时：**
- 系统地记录双方
- 寻找解释冲突的方法差异
- 检查时间趋势（理解是否发生了变化？）
- 确定什么可以解决争议
- 生成解释差异的假设

### 跨学科主题

* *跨越多个领域时：**
- 搜索每个领域的主要数据库
- 对每个领域使用特定于领域的术语
- 查找跨领域引用的桥接论文
- 考虑咨询领域专家
- 仔细翻译学科之间的概念

## 与假设生成的集成

### 利用文献来告知假设

* *直接应用：**
- 建立应用于新背景的机制
- 与现象相关的已知路径
- 相关系统中的类似现象
- 验证方法测试

* *间接应用：**
- 来自不同系统的类比
- 应用的理论框架
- 提出新颖机制的差距
- 需要解决的矛盾

### 平衡文献依赖性

* * 也是依赖于文献：**
- 假设只是重述已知的机制
- 没有新颖的见解或预测
- “假设”实际上是已成立的事实

* * 太独立于文献：**
- 假设忽略相关证据
- 提出不可信的建议机制
- 重新发明已经测试过的想法
- 与既定原则不一致

* *最佳平衡：**
- 以现有证据为基础
- 以新颖的方式扩展理解
- 确认支持性和挑战性证据
- 生成超出当前知识的可测试预测
