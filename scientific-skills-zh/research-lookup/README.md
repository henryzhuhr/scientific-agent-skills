# 研究查找技能

该技能通过OpenRouter使用Perplexity的Sonar Pro搜索模型提供实时研究信息查找。

## Setup

1. **获取 OpenRouter API 密钥：**
  - 访问 [openrouter.ai](https://openrouter.ai)
  - 创建帐户并生成 API 密钥
  - 将积分添加到您的帐户

2. **配置环境：**
 ```bash
 导出 OPENROUTER_API_KEY="your_api_key_here"
 ```

3. **测试设置：**
 ```bash
 python script/research_lookup.py --model-info
 ```

## 使用

### 命令行使用

```bash
# Single research query
python scripts/research_lookup.py "Recent advances in CRISPR gene editing 2024"

# Multiple queries with delay
python scripts/research_lookup.py --batch "CRISPR applications" "gene therapy trials" "ethical considerations"

# Claude Code integration (called automatically)
python lookup.py "your research query here"
```

### 克劳德代码集成

当您执行以下操作时，Claude Code 中会自动提供研究查找工具：

1. **提出研究问题：**“研究量子计算的最新进展”
2. **请求文献综述：**“查找当前有关气候变化影响的研究”
3. **需要引用：** “变压器注意力机制的最新论文有哪些？”
4. **想要技术信息：**“流式细胞术标准协议”

## 特点

- **学术重点：** 优先考虑同行评审的论文和信誉良好的来源
- **当前信息：** 重点关注最近发表的出版物 (2020-2024)
- **完整引文：** 提供完整的引用DOIs
- **多种格式：** 支持各种查询类型和研究需求
- **高搜索上下文：** 始终使用高搜索上下文进行更深入、更全面的研究
- **质量优先级：** 自动优先考虑来自顶级场所的高被引论文
- **通常具有成本效益：**每个研究查询 0.01-0.05 美元

## 论文质量优先 

这项技能**总是优先考虑高影响力、有影响力的论文**，而不是不起眼的出版物。结果排名如下：

### 基于引文的排名

|纸时代|引用阈值 |分类|
|---------|--------------------------------|----------------|
| 0-3岁| 20+ 次引用 |值得注意|
| 0-3岁| 100 多次引用 |极具影响力|
| 3-7年| 100 多次引用 |重要|
| 3-7年| 500 多次引用 |地标|
| 7 年以上 | 500 多次引用 |开创性|
| 7 年以上 | 1000+ 次引用 |基础 |

### 场地质量等级

来自较高等级场地的论文始终优先：

- **第 1 级（最高优先级）：** Nature、Science、Cell、NEJM、Lancet、JAMA、PNAS、Nature Medicine、Nature Biotechnology
- **第 2 级（高优先级）：** 高影响力期刊(IF>10)、顶级会议 (NeurIPS、ICML、ICLR for ML/AI)
- **Tier 3 (Good):** 受尊敬的专业期刊 (IF 5-10)
- **Tier 4 (Use Sparingly):** 其他同行评审场所

### 作者声誉 

技能优先选择来自以下人士的论文：
- 具有高h指数的高级研究人员
- 在公认机构建立的研究小组
- 在一级场所发表多篇论文的作者
- 具有公认专业知识（奖项、编辑职位）的研究人员

### 相关性优先

1. 直接解决研究问题
2的论文。适用方法/数据的论文
3. 切线相关论文（仅来自顶级场地或高被引）

## 回复格式

每个研究结果包括：
- **摘要：**关键概述结果
- **关键研究：** 3-5篇最相关的近期论文
- **引文：** 完整的书目信息
- **使用统计：** 用于成本跟踪的代币使用情况
- **时间戳：** 研究进行时

2的当前研究。 **方法验证：** 根据当前标准

4 进行比较。 **讨论支持：**争论的最新证据

## 故障排除

* *“未找到API密钥”**
- 确保设置了`OPENROUTER_API_KEY`环境变量
- 检查您的OpenRouter帐户中是否有积分

* *“模型不可用”**
- 验证您的API 密钥可以访问 Perplexity 模型
- 检查 OpenRouter 状态页面是否有服务问题

* *“超出速率限制”**
- 使用 `--delay` 选项在请求之间添加延迟
- 检查您的 OpenRouter 帐户限制

* *“没有相关结果”**
- 尝试更多具体或更广泛的查询
- 包括时间范围（例如，“2023-2024”）
- 使用学术关键字和技术术语
