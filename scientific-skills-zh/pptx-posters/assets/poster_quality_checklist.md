# 研究海报质量检查表

在打印或展示研究海报之前使用此综合检查表。

## 预编译检查

### 内容完整性
- [ ]标题简洁且具有描述性（10-15 个单词）
- [ ]所有作者姓名拼写正确
- [ ]附属机构完整且准确
- [ ]包括联系电子邮件地址
- [ ]所有章节：介绍、方法、结果、结论
- [ ]引用的参考文献（5-10 个关键引用）
- [ ]包括致谢（资助、合作者）
- [ ]没有剩余占位符文本（TODO、Lorem ipsum 等）

### 视觉内容
- [ ]所有图形均已准备好并具有高分辨率（300+ DPI）
- [ ]书面文字说明和描述性图形标题
- [ ]可用徽标（大学、资助机构）
- [ ]生成的二维码和已测试
- [ ]图标/图形来源（如果使用）

### LaTeX 配置
- [ ]指定正确的纸张尺寸（A0、A1、36×48" 等）
- [ ]正确的方向（纵向/横向）
- [ ]配置最小边距(5-15mm)
- [ ]字体大小合适（标题 72pt+，正文 24pt+）
- [ ]定义配色方案
- [ ]所有软件包已安装并正在运行

## 编译检查

### 成功编译
- [ ] PDF 编译没有错误
- [ ] .log 文件中没有严重警告
- [ ]所有引用已解析（无 [?]标记）
- [ ]所有交叉引用工作
- [ ]正确生成参考书目（如果使用 BibTeX）

### 警告查看
在终端中运行：`grep -i "warning\|overfull\|underfull" poster.log`

- [ ]没有溢出的水平盒警告（文本太宽）
- [ ]没有未满的水平盒警告（间距过大）
- [ ]没有丢失图形警告
- [ ]没有丢失字体warnings
- [ ]无未定义参考 warnings

## PDF 质量检查

### 自动检查

运行：`./scripts/review_poster.sh poster.pdf` 或手动验证：

#### 页面规格
```bash
pdfinfo poster.pdf | grep "Page size"
```
- [ ]页面大小完全符合要求
- [ ]单页文档（不是多页）
- [ ]正确方向

#### 字体嵌入
```bash
pdffonts poster.pdf
```
- [ ]所有字体在“emb”中显示“yes”列
- [ ]无位图字体（应为Type 1 或TrueType）

#### 图像质量
```bash
pdfimages -list poster.pdf
```
- [ ]所有图像至少为300 DPI
- [ ]图中无JPEG 伪影
- [ ]使用矢量图形可能

#### 文件大小
```bash
ls -lh poster.pdf
```
- [ ]大小合理（典型值2-50 MB）
- [ ]如果以数字方式共享，对于电子邮件来说不会太大（<50 MB）
- [ ]不算小（<1 MB - 可能表明质量低）

## 缩小比例打印测试（关键）

### 测试打印准备
以25%比例打印海报：
- A0海报→ 在 A4 纸上打印
- 36×48" 海报 → 在 Letter 纸上打印
- A1 海报 → 在 A5 纸上打印

### 远距离可读性

* *从 6 英尺（2 米）起：**
- [ ]标题清晰可读
- [ ]作者可识别
- [ ]主要数字可见

* *从4英尺（1.2米）起：**
- [ ]章节标题可读
- [ ]图标题可读
- [ ]主要结果可见

* *从2英尺（0.6米）起米）：**
- [ ]正文可读
- [ ]参考文献可读
- [ ]所有详细信息清晰

### 打印质量
- [ ]颜色准确（符合屏幕预期）
- [ ]无条带或色偏
- [ ]边缘清晰（不模糊）
- [ ]打印密度一致
- [ ]无打印机伪影

## 快速参考：常见问题

|问题 |快速修复 |
|-------|-----------|
|大白边|减少文档类中的边距：`margin=5mm` |
|文字太小 |增加比例：beamerposter |
| 中的 `scale=1.5`模糊的数字|使用矢量图形 (PDF)或更高分辨率 (600+ DPI) |
|颜色错误 |检查 RGB 与 CMYK，最终打印前进行测试 |
|未嵌入字体 |编译为：`pdflatex -dEmbedAllFonts=true` |
|内容被截断 |检查总宽度：列+间距+边距=页宽|
|二维码无法扫描 |加大尺寸（最小2×2cm），保证高对比度|
|文件太大 |压缩：`gs -sDEVICE=pdfwrite -dPDFSETTINGS=/printer ...` |
