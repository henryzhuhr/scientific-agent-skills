# ScholarEval 评估框架

## 概述

本文档提供了ScholarEval 框架各个维度的详细评估标准、评分细则和质量指标。在对学术工作进行系统评估时使用这些标准。

- --

## 维度 1：问题表述和研究问题

### 质量指标

* *优秀 (5)：**
- 研究问题具体、可测量且清晰阐述
- 问题解决了具有高影响力的文献中的重大差距潜力
- 范围在限制内是适当和可行的
- 新颖的贡献与现有工作明显区分开来
- 理论或实践意义具有令人信服的合理性

* *好（4）：**
- 研究问题清晰，有轻微模糊性
- 问题相关，影响中等潜力
- 范围总体上是适当的，但存在较小的可行性问题
- 贡献是可识别的，但不是开创性的
- 意义是充分合理的

* *充分（3）：**
- 存在研究问题，但缺乏特异性
- 问题相关性不清楚或增量
- 范围可能太宽或太窄
- 贡献不清楚或与现有工作严重重叠
- 重要性论证很弱

* *需要改进（2）：**
- 研究问题模糊或定义不明确
- 问题缺乏明确的相关性或重要性
- 范围不适当或不可行
- 贡献未明确表达
- 没有明确的重要性理由

* *差（1）：**
- 没有明确的研究问题
- 问题微不足道或无关
- 范围是根本上有缺陷
- 没有可识别的贡献
- 没有显着性理由

### 评估清单

- [ ]研究问题是否明确表述？
- [ ]问题能否用所提出的方法来回答？
- [ ]问题对该领域是否重要？
- [ ]范围在资源限制内是否可行？
- [ ]新颖性/贡献是否明确阐述？
- [ ]关键假设是否明确
- [ ]是否定义了成功标准或预期结果？

## 维度 2：文献综述

### 质量指标

* *优秀 (5)：**
- 全面覆盖关键领域的相关文献
- 识别模式、矛盾和冲突的关键综合差距
- 文献是最新的（大多数来自过去3-5年快速发展的领域）
- 来源是权威的和同行评审的
- 当前工作在学术对话中的明确定位
- 确定工作所解决的真正的研究差距

* *好(4):**
- 良好的覆盖范围，但关键领域存在微小差距
- 大部分是综合性的，并有一些描述
- 文献大多是最新的一些较旧的基础著作
- 来源通常是权威的
- 工作定位存在，但可能更强
- 研究差距已确定，但可能不是关键

* *足够（3）：**
- 部分覆盖，有明显差距
- 比综合更具描述性的总结
- 当前和过时来源的文献组合
- 权威和不太严格的来源的混合
- 现有的定位薄弱文献
- 研究差距模糊或有问题

* *需要改进（2）：**
- 覆盖范围极小，存在重大差距
- 纯粹描述性而没有综合
- 文献很大程度上已经过时
- 来源缺乏权威或严谨
- 很少对当前工作没有定位
- 没有确定明确的研究差距

* *差（1）：**
- 文献综述不充分或缺失
- 没有综合
- 过时或不适当的来源
- 没有参与学术对话
- 没有差距识别

### 评估清单

- [ ]评论是否涵盖所有主要相关
- [ ]文献是否是综合而非概括？
- [ ]来源是否最新且权威？
- [ ]是否提出了相反的观点？
- [ ]是否清楚地确定了研究差距？
- [ ]当前的工作是否定位在现有文献中？
- [ ]是引文平衡适当（不要过度依赖少数作者）？
- [ ]是否包含开创性/基础性作品？

### 常见问题

- **覆盖范围不足**：缺少关键论文或研究流
- **描述性列表**：按顺序总结论文而不进行综合
- **过时来源**：依赖5-10年以上的文献
- **择优挑选**：仅引用支持假设的著作
- **组织不佳**：缺乏主题或概念结构
- **弱差距识别**：差距是微不足道的或实际上不是差距

## 维度3：方法和研究设计

### 质量指标

* *优秀（5）：**
- 研究设计与研究问题完美契合
- 方法严谨、有效且可靠
- 程序足够详细，可复制
- 对照、随机化或三角测量适当的
- 承认并减轻潜在偏见
- 全面解决道德考虑
- 明确讨论限制

* *好（4）：**
- 设计是适当的，有轻微的对齐问题
- 方法是合理的，但有效性问题很小
- 程序主要是可复制
- 存在一些控制或验证
- 解决了主要偏见
- 提到了道德考虑
- 讨论了一些限制

* *充分（3）：**
- 设计部分适合问题
- 方法具有显着的有效性问题
- 程序缺乏完整复制的细节
- 有限的控制或验证
- 偏差缓解最小
- 表面上解决道德问题
- 限制最小讨论了

* *需要改进（2）：**
- 设计与研究问题不太一致
- 方法有严重的有效性问题
- 程序太模糊，无法复制
- 没有控制或验证
- 没有解决偏见
- 没有道德问题已解决
- 无限制讨论

* *差（1）：**
- 不适当或缺乏方法
- 方法根本上有缺陷
- 不可复制
- 没有有效性考虑
- 没有道德考虑
- 没有确认局限性

### 评估清单

- [ ]方法是否适合研究问题？
- [ ]程序描述是否足够详细？
- [ ]是否可以从描述中复制该研究？
- [ ]是否解决了有效性和可靠性问题？
- [ ]是否已识别和确定潜在偏差？ 
- [ ]是否讨论了道德考虑因素？
- [ ]是否承认局限性？
- [ ]样本量是否合理（用于定量工作）？
- [ ]定性方法是否严格（如果适用）？

### 设计特定考虑因素

* *定量研究：**
- 具有功效分析的样本量
- 对照组和随机化
- 测量有效性和可靠性
- 统计假设检查

* * 定性研究：**
- 抽样策略和饱和度
- 数据收集程序
- 编码和分析框架
- 可信标准（可信性、可转移性等）

* *混合方法：**
- 集成原理
- 排序合理性
- 数据收敛策略

## 维度 4：数据收集和来源

### 质量指标

* *优秀（5）：**
- 数据来源高度可信且恰当
- 样本量充足且合理
- 数据收集程序严谨且系统
- 数据质量控制到位
- 抽样策略确保代表性
- 缺失数据最少并得到处理适当

* *良好（4）：**
- 数据来源可信，略有问题
- 样本量充足
- 收集程序系统化
- 存在一些质量控制
- 抽样合理
- 缺失数据已得到解决

* * 足够(3):**
- 数据源是可以接受的，但不是最佳的
- 样本量很小
- 收集程序缺乏一些严格性
- 有限的质量控制
- 抽样可能存在偏差问题
- 缺失数据处理是基本的

* * 需要改进(2):**
- 数据来源存在可信度问题
- 样本量不足
- 收集程序是临时的
- 无质量控制
- 抽样明显有偏差
- 未解决缺失数据

* *差(1):**
- 数据来源不当或不可靠
- 样本量不足
- 收集不系统
- 没有质量考虑
- 抽样存在根本缺陷
- 缺失数据过多

### 评估检查表

- [ ]数据来源是否可信且适当？
- [ ]样本量是否足以得出结论？
- [ ]是否明确描述了抽样策略？
- [ ]样本是否代表目标人群？
- [ ]数据收集程序是否系统化？
- [ ]是否有数据描述了质量控制？
- [ ]是否解决了缺失数据？
- [ ]是否讨论了任何潜在的数据偏差？

## 维度 5：分析和解释

### 质量指标

* *优秀（5）：**
- 分析方法完全适合数据和问题
- 分析采用适当的技术进行严格
- 结果解释符合逻辑且得到充分支持
- 考虑替代解释
- 主张与证据成比例
- 假设得到验证
- 分析是透明的并且可重现

* *好（4）：**
- 方法适用于小问题
- 分析是合理的
- 解释大部分是合乎逻辑的
- 考虑了一些替代方案
- 声明通常与证据相匹配
- 检查了关键假设
- 分析是大部分是透明的

* *足够（3）：**
- 方法是可以接受的，但不是最佳的
- 分析有一些技术问题
- 解释有逻辑差距
- 替代方案没有彻底探索
- 一些主张超出了证据
- 假设不完全已验证
- 分析透明度有限

* *需要改进（2）：**
- 方法对数据/问题有疑问
- 分析具有重大技术缺陷
- 解释缺乏支持
- 没有替代解释
- 声明明显超过证据
- 假设未经检查
- 分析不透明

* *差(1)：**
- 方法不恰当
- 分析存在根本缺陷
- 解释不合逻辑
- 没有考虑替代方案
- 没有证据支持的主张
- 没有假设验证
- 分析不透明

### 评估清单

- [ ]分析方法是否合适？
- [ ]统计测试/定性方法是否正确应用？
- [ ]是假设经过检验吗？
- [ ]解释是否合乎逻辑且得到充分支持？
- [ ]是否考虑了替代解释？
- [ ]主张是否与证据强度相符？
- [ ]分析是否可从描述中重现？
- [ ]是否承认不确定性？

### 定量分析

- 适当的统计测试
- 检查假设（正态性、同质性等）
- 报告的效应大小
- 提供的置信区间
- 多次测试修正（如果适用）
- 执行模型诊断

### 定性分析

- 编码框架是清除
- 评估者间的可靠性（如果适用）
- 讨论的饱和度
- 检查的阴性案例
- 成员检查或验证
- 清晰的审计跟踪

## 维度6：结果和发现

### 质量指标

* *优秀（5）：**
- 结果清晰、全面地呈现
- 可视化有效且适当
- 统计或定性严谨性明显
- 有效突出关键发现
- 结果直接解决研究问题
- 模式和关系清楚地显示
- 报告阴性和无效结果

* *好（4）：**
- 结果很清楚，有轻微的演示问题
- 可视化通常有效
- 存在严格性
- 主要发现是可识别的
- 结果主要解决问题
- 显示模式
- 包括一些负面结果

* *足够（3）：**
- 结果呈现足够但可能更清晰
- 可视化是基本的或有问题
- 某些地方的严谨性值得怀疑
- 调查结果存在但不存在强调
- 与问题部分一致
- 模式不清楚
- 可能会省略阴性结果

* *需要改进（2）：**
- 结果呈现不清楚或令人困惑
- 可视化效果不佳或具有误导性
- 缺乏严谨
- 结果很难识别
- 与问题的一致性较弱
- 没有明确的模式
- 仅显示积极结果

* *差 (1)：**
- 结果呈现不佳或缺失 
- 可视化不适当或缺失 
- 没有严谨性的证据 
- 结果不清楚 
- 结果没有解决问题
- 没有可识别的模式
- 结果出现选择性

### 评估清单

- [ ]结果是否清楚地呈现？
- [ ]结果是否直接解决研究问题？
- [ ]可视化是否适当且有效？
- [ ]是否突出显示关键发现？
- [ ]是否报告阴性/无效结果？
- [ ]是否报告了适当的精度（p 值、置信区间、效应量）？
- [ ]定性研究结果是否有数据摘录支持？
- [ ]是否有选择性报告的证据？

### 演示质量

* *表格：**
- 清晰的标签和标题
- 适当的精度
- 组织逻辑合理
- 不太复杂

* *数字：**
- 清晰的轴和图例
- 适当的图表类型
- 专业的外观
- 无障碍（色盲）友好）

* *文本：**
- 突出显示主要发现
- 避免表格/数字的冗余
- 使用适当的统计语言

## 维度7：学术写作和演示

### 质量指标

* *优秀（5）：**
- 写作清晰、简洁、精确
- 组织逻辑清晰，流程优秀
- 学术语气恰当、一致
- 语法和机制完美无瑕
- 技术术语使用正确
- 可达目标观众
- 摘要/摘要全面准确

* *好（4）：**
- 写作清晰，略有尴尬
- 组织逻辑清晰，流程良好
- 语气最合适
- 很少有语法/机械错误
- 主要是技术术语正确
- 一般可访问
- 摘要足够

* *充分（3）：**
- 写作可以理解，但存在清晰度问题
- 组织存在一些逻辑差距
- 语气不一致
- 明显的语法/机械错误
- 某些技术术语误用
- 目标受众的可访问性问题
- 摘要不完整或模糊

* *需要改进（2）：**
- 写作经常不清楚或冗长
- 组织和流程不佳
- 语气不合适
- 频繁的语法/机械错误
- 技术术语问题
- 无法访问目标受众
- 摘要较差或缺失

* *较差（1）：**
- 写作不清楚且难以理解
- 没有清晰的组织
- 语气不合适
- 普遍存在语法/机械错误
- 不正确的技术术语
- 无法访问
- 没有足够的摘要

### 评估清单

- [ ]写作是否清晰简洁？
- [ ]组织是否符合逻辑？
- [ ]语气是否适合学术写作？
- [ ]是语法和力学正确吗？
- [ ]技术术语使用得当吗？
- [ ]必要时是否解释行话？
- [ ]摘要是否准确概括了作品？
- [ ]章节之间的过渡是否流畅？
- [ ]目标受众是否明确？

### 常见写作问题

- **冗长**：不必要的复杂或冗长的散文
- **被动语态过度使用**：降低清晰度和直接性
- **段落结构**：缺乏主题句或连贯性
- **冗余**：不必要地重复信息
- **逻辑流程**：差想法之间的转换
- **精确**：含糊或不明确的语言
- **可访问性**：技术性太强或技术性不够

## 维度8：引文和参考文献

### 质量指标

* *优秀（5）：**
- 所有权利要求均得到适当引用
- 来源是权威且最新的
- 引文准确且完整
- 代表不同的观点
- 引文格式一致且正确
- 自引与其他之间的平衡
- 使用的主要来源适当地

* *好（4）：**
- 大多数权利要求被引用
- 来源通常具有权威性
- 引用错误很少
- 来源的多样性合理
- 格式基本一致
- 引用平衡良好
- 主要和次要的混合来源

* *足够（3）：**
- 一些主张缺乏引用
- 来源质量参差不齐
- 几个引用错误
- 来源多样性有限
- 格式不一致
- 引文平衡问题
- 过度依赖二手来源

* *需要改进（2）：**
- 许多主张未引用
- 来源有问题
- 大量引用错误
- 来源基础狭窄
- 格式不一致
- 过度自引或狭窄的引用
- 不适当的来源（例如，仅次要）

* *差（1）：**
- 引用不足
- 来源不可靠
- 普遍的引用错误
- 来源多样性极小
- 不一致格式
- 严重引用不平衡
- 不适当的来源类型

### 评估清单

- [ ]是否引用了所有事实主张？
- [ ]是否在适当的情况下引用了主要来源？
- [ ]来源是否具有权威性和权威性同行评审？
- [ ]引用的观点是否平衡？
- [ ]引文是否准确（作者、日期、页数）？
- [ ]引文格式是否一致？
- [ ]自引是否合适（通常<20%）？
- [ ]来源是否最新（针对时间敏感的主题）？
- [ ]是否包含相关的经典/开创性作品？

### 引文质量评估

* *来源类型（按照大多数学术作品的优先顺序）：**
1. 同行评审的期刊文章
2. 来自知名出版社的学术书籍
3. 会议论文集（取决于现场）
4. 知名机构的技术报告
5. 论文/论文
6. 预印本（谨慎，取决于领域）
7. 灰色文献（有限使用）
8. 网站（很少合适，事实数据除外）

* *危险信号：**
- 维基百科作为主要来源
- 过多的自引（>30%）
- 仅引用支持假设的论文
- 当前存在的来源已过时
- 缺少关键论文在该领域
- 仅在全文可用时引用摘要
- 不一致或不正确的引用格式

## 横切注意事项

### 再现性

跨维度评估：
- 方法是否足够详细复制？
- 数据和代码是否可用（或可用性解释）？
- 分析步骤是否透明？
- 是否指定材料/仪器？

### 道德

考虑：
- IRB 批准（针对人类受试者）
- 知情同意
- 隐私和机密性
- 利益冲突
- 研究诚信
