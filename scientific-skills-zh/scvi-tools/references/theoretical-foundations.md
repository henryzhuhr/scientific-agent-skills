# scvi-tools的理论基础

本文档解释了scvi-tools.

的数学和统计原理##核心概念

### 变分推理

* *它是什么？**
变分推理是一种近似复杂概率分布的技术。在单细胞分析中，我们想要了解后验分布 p(z|x) - 给定观测数据 x 的潜在变量 z 的概率。

* *为什么使用它？**
- 对于复杂模型来说，精确推理在计算上很难处理
- 扩展到大型数据集（数百万个细胞）
- 提供不确定性量化
- 启用关于细胞状态的贝叶斯推理

* *它是如何工作的？**
1. 使用可学习参数 
2 定义更简单的近似分布 q(z|x)。最小化 q(z|x)和真实后验 p(z|x)
3 之间的 KL 散度。相当于最大化证据下界 (ELBO)

* *ELBO 目标**：
```
ELBO = E_q[log p(x|z)] - KL(q(z|x) || p(z))
       ↑                    ↑
  Reconstruction          Regularization
```

- **重建项**：模型应生成类似于观察到的
- **正则化项**：潜在表示应匹配先验

### 变分自动编码器 (VAE)

* *架构**：
```
x (observed data)
    ↓
[Encoder Neural Network]
    ↓
z (latent representation)
    ↓
[Decoder Neural Network]
    ↓
x̂ (reconstructed data)
```

* *编码器**：将单元格 (x)映射到潜在空间 (z)
- 学习 q(z|x)，近似后验
- 通过可学习的神经网络进行参数化权重
- 输出潜在分布的均值和方差

* *解码器**：将潜在空间（z）映射回基因空间
- 学习p（x | z），可能性
- 从潜在表示生成基因表达
- 模型计数分布（负二项式，零膨胀） NB)

* *重新参数化技巧**：
- 允许通过随机采样进行反向传播
- 样本 z = μ + σ ⊙ ε，其中 ε ~ N(0,1)
- 启用梯度下降的端到端训练

### 摊销推理

* *概念**：在所有单元格之间共享编码器参数。

* *传统推理**：为每个单元格学习单独的潜在变量
- n_cells × n_latent 参数
- 无法扩展到大型数据集

* *摊销推理**：为所有单元格学习单个编码器cells
- 固定数量的参数，无论细胞计数如何
- 启用对新细胞的快速推理
- 跨数据集传输学习模式

* *优点**：
- 可扩展到数百万个细胞
- 对查询数据进行快速推理
- 利用共享跨细胞的结构
- 启用小样本学习

## 统计建模

#### 计数数据分布

单细胞数据是计数（整数值），需要适当的分布。

#### 负二项式(NB)
```
x ~ NB(μ, θ)
```
- **μ（平均值）**：预期表达水平
- **θ（离散度）**：控制方差
- **方差**：Var(x) = μ + μ²/θ

* *何时使用**：无零膨胀的基因表达
- 比泊松（允许过度分散）
- 模拟技术和生物变异

#### 零膨胀负二项式 (ZINB)
```
x ~ π·δ₀ + (1-π)·NB(μ, θ)
```
- **π（丢失率）**：技术零的概率
- **δ₀**：零处的点质量
- **NB(μ, θ)**：未丢失时的表达

* *何时使用**：稀疏 scRNA-seq 数据
- 与生物零点分开建模技术丢失
- 更好地适合高度稀疏的数据（例如，10x 数据）

#### Poisson
```
x ~ Poisson(μ)
```
- 最简单的计数分布
- 均值等于方差： Var(x) = μ

* *何时使用**：不太常见； ATAC-seq 片段计数
- 比 NB
 限制更多- 计算速度更快

### 批量校正框架

* *问题**：技术变异混淆了生物信号
- 不同的测序运行、方案、实验室
- 必须在保留的同时消除技术影响生物学

* *scvi-tools方法**：
1. 将批次编码为分类变量 s
2. 将 s 包含在生成模型 
3 中。潜在空间 z 是批次不变的 
4. 针对批次特定效果的 s 上的解码器条件

* *数学公式**：
```
Encoder: q(z|x, s)  - batch-aware encoding
Latent: z           - batch-corrected representation
Decoder: p(x|z, s)  - batch-specific decoding
```

* *关键见解**：批次信息流过解码器，而不是潜在空间
- z 捕获生物变异
- s 解释技术变异
- 可分离的生物学和批次效果

### 深度生成建模

* *生成模型**：学习p(x)，数据分布

* *过程**：
1. 样本潜变量：z ~ p(z) = N(0, I)
2. 生成表达式：x ~ p(x|z)
3. 联合分布：p(x, z) = p(x|z)p(z)

* *优点**：
- 生成合成细胞
- 估算缺失值
- 量化不确定性
- 执行反事实预测

* *推理网络**：反转生成process
- 给定 x，推断 z
- q(z|x)近似真实后验 p(z|x)

## 模型架构详细信息

### scVI 架构

* *输入**：基因表达计数 x ∈ ℕ^G (G基因）

* *编码器**：
```
h = ReLU(W₁·x + b₁)
μ_z = W₂·h + b₂
log σ²_z = W₃·h + b₃
z ~ N(μ_z, σ²_z)
```

* *潜在空间**：z ∈ ℝ^d（通常d=10-30)

* *解码器**:
```
h = ReLU(W₄·z + b₄)
μ = softmax(W₅·h + b₅) · library_size
θ = exp(W₆·h + b₆)
π = sigmoid(W₇·h + b₇)  # for ZINB
x ~ ZINB(μ, θ, π)
```

* *损失函数 (ELBO)**:
```
L = E_q[log p(x|z)] - KL(q(z|x) || N(0,I))
```

### 处理协变量

* *分类协变量** （批次、捐赠者等）：
- One-hot 编码：s ∈ {0,1}^K
- 与潜在层连接：[z, s]
- 或使用条件层

* *连续协变量**（库大小，percent_mito）：
- 标准化为零均值，单位方差
- 包含在编码器和/或解码器中

* *协变量注入策略**：
- **串联**：[z，s]馈送到解码器
- **深度注入**：在多个层添加s
- **条件批量规范**：特定于批次归一化

## 高级理论概念

### 迁移学习（scArches）

* *概念**：使用预训练模型作为新数据的初始化

* *过程**：
1. 在大型数据集
2 上训练参考模型。冻结编码器参数
3. 对查询数据
4 进行微调解码器。或者以较低的学习率对所有内容进行微调

* *为什么有效**：
- 编码器学习一般细胞表示
- 解码器适应特定于查询的特征
- 防止灾难性遗忘

* *应用**：
- 查询到引用映射
- 稀有细胞类型的少量学习
- 新数据集的快速分析

### 多分辨率建模（MrVI）

* *想法**：分离共享和样本特定的变异

* *潜在空间分解**：
```
z = z_shared + z_sample
```
- **z_shared**：跨样本通用
- **z_sample**：样本特定效果

* *分层结构**：
```
Sample level: ρ_s ~ N(0, I)
Cell level: z_i ~ N(ρ_{s(i)}, σ²)
```

* *优点**：
- 解开变异的生物来源
- 比较不同分辨率的样本
- 识别样本特异性细胞状态

### 反事实预测

* *目标**：预测不同条件下的结果

* *示例**：“如果来自不同批次，该细胞会是什么样子？”

* *方法**：
1. 将单元格编码为潜在的：z = Encoder(x, s_original)
2. 使用新条件进行解码：x_new = Decoder(z, s_new)
3. x_new 是反事实预测

* *应用**：
- 批量效果评估
- 预测治疗反应
- 计算机扰动研究

### 后验预测分布

* *定义**：观察到的新数据的分布data

```
p(x_new | x_observed) = ∫ p(x_new|z) q(z|x_observed) dz
```

* *估计**：从q(z|x)采样z，从p(x_new|z)生成x_new

* *用途**：
- 不确定性量化
- 稳健预测
- 异常值检测

## 差异表达框架

### 贝叶斯方法

* *传统方法**：比较点估计
- Wilcoxon、t检验等
- 忽略不确定性
- 需要伪计数

* *scvi-tools方法**：比较分布
- 后验样本：μ_A ~ p(μ|x_A)，μ_B ~ p(μ|x_B)
- 计算对数倍数变化：LFC = log(μ_B) - log(μ_A)
- 后验LFC 的分布量化了不确定性

### 贝叶斯因子

* *定义**：后验赔率与先验赔率的比率

```
BF = P(H₁|data) / P(H₀|data)
     ─────────────────────────
     P(H₁) / P(H₀)
```

* *解释**：
- BF > 3：H₁
- 的中等证据BF > 10：强有力的证据
- BF > 100：决定性证据

* *在scvi-tools**中：用于通过DE

### 错误发现比例（FDP）

* *目标**：控制预期错误发现对基因进行排名比率

* *程序**：
1. 对于每个基因，计算 DE
2 的后验概率。通过证据（贝叶斯因子）
3 对基因进行排序。选择前 k 个基因，使得 E[FDP] ≤ α

* *相对于 p 值的优势**：
- 完全贝叶斯 
- 后验推理自然 
- 无任意阈值

## 实现细节

### 优化

* *优化器**：Adam（自适应学习率）
- 默认lr = 0.001
- 动量参数：β₁=0.9，β2=0.999

* *训练循环**：
1. 小批量细胞样品
2. 计算 ELBO 损失
3. 反向传播梯度
4. 使用 Adam
5 更新参数。重复直到收敛

* *收敛标准**：
- 验证集上的ELBO平台
- 提前停止防止过度拟合
- 通常200-500个时期

### 正则化

* *KL退火**：逐渐增加KL权重
- 防止后塌陷
- 从0开始，在历元内增加到1

* *Dropout**：训练期间随机神经元丢弃
- 默认：0.1辍学率
- 防止过度拟合
- 改进泛化

* *权重衰减**：权重的L2正则化
- 防止大权重
- 提高稳定性

### 可扩展性

* *小批量训练**：
- 每次迭代处理单元子集
- 批量大小：64-256 个单元
- 能够扩展到数百万个单元

* *随机优化**：
- 在小批量上估计 ELBO
- 无偏梯度估计
- 收敛到最佳解决方案

* *GPU加速**：
- 神经网络自然并行
- 数量级加速
- 对于大型数据集至关重要

## 与其他方法的连接

### 与PCA
- **PCA**：线性，确定性
- **scVI**：非线性、概率
- **优点**：scVI 捕获复杂结构，处理计数

### 与 t-SNE/UMAP
- **t-SNE/UMAP**：注重可视化
- **scVI**：完全生成model
- **优点**：scVI 支持下游任务（DE、插补）

### 与 Seurat 集成
- **Seurat**：基于锚点的对齐
- **scVI**：概率建模
- **优点**：scVI 提供不确定性，适用于多个批次

### vs. Harmony
- **Harmony**：PCA + 批量校正
- **scVI**：基于VAE的
- **优点**：scVI原生处理计数，更灵活

## 数学符号

* *通用符号**：
- x：观察到的基因表达（计数）
- z：潜在表示
- θ：模型参数
- q(z|x)：近似后验（编码器）
- p(x|z)：可能性（解码器）
- p(z)：潜在变量的先验
- μ，σ²：均值和方差
- π：丢失概率（ZINB）
- θ（NB）：分散参数
- s：批次/协变量指标
