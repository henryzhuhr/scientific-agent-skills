# 治疗计划质量保证检查表

## 概述

使用此检查表可确保治疗计划符合完整性、质量、安全性和法规遵从性的专业标准。在最终确定计划之前，请查看每个部分。

## 第2 节：智能目标质量

对于每个治疗目标，验证其符合 SMART 标准：

### ☐ 具体 
- [ ]目标明确定义将完成什么
- [ ]无模糊语言（例如“改善”、“更好”）
- [ ]陈述具体结果

  * *示例**：“将 HbA1c 降低8.5% 至 <7%" ✓ 
* *不是**：“改善糖尿病控制” ✗

### ☐ 可测量
- [ ]包括可量化指标或可观察标准
- [ ]记录的基线值
- [ ]目标值指定

* *示例**：“独立步行300英尺” ✓ 
* *不是**：“走得更远” ✗

### ☐可实现的
- [ ]实际给定的患者状况和能力
- [ ]可用于支持的资源目标
- [ ]时间范围合理
- [ ]治疗效果支持目标

* *示例**：“6周内将疼痛从7/10减少到4/10” ✓ 
* *不是**：“1周内消除所有疼痛” ✗

### ☐相关
- [ ]与患者价值观和优先事项保持一致
- [ ]具有临床意义
- [ ]解决患者的功能限制
- [ ]与总体治疗目标相结合

  * *示例**：“在3个月内修改后返回工作岗位” ✓ 
* *不是**：“实验室值改善”（如果患者不关心） ✗

### ☐ 有时间限制的
- [ ]规定的具体截止日期或时间范围
- [ ]定义的重新评估间隔
- [ ]指定的行动频率（如果适用）

* *示例**： “8 周内”或“第 3 个月内” ✓ 
* *不是**：“最终”或“很快” ✗

## 评分和解释

* *项目总数**：~150（因计划类型而异）

### 评分：
- 计算检查项目的数量
- 计算百分比：（已检查/总计）× 100

### 解释：
- **95-100%**：优秀 - 计划符合最高质量标准
- **85-94%**：良好 - 计划质量高，有微小差距
- **70-84%**：可接受 - 计划足够，但有需要的区域改进
- **<70%**：需要改进 - 质量或合规性方面存在重大差距

### 关键项目（必须具备）：
以下项目至关重要且必须存在：
- ✓ 患者识别码和去识别通知
- ✓ 使用 ICD-10 进行初步诊断代码
- ✓ 至少 3 个 SMART 目标
- ✓ 有理由的干预措施
- ✓ 监测计划
- ✓ 随访计划
- ✓ 患者教育
- ✓ 安全/风险缓解
- ✓ 紧急情况程序
- ✓ 提供者签名

如果缺少任何关键项目，则在更正之前不应最终确定计划。
