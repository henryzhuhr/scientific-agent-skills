# Pymoo测试问题参考

pymoo中的基准优化问题综合参考。

## 单目标测试问题

### Ackley函数
* *特性：**
- 高度多模态
- 许多本地optima
- 测试算法逃离局部最小值的能力
- 连续变量

### Griewank 函数
* * 特性：**
- 具有规则分布局部最小值的多模态
- 乘积项引入变量之间的相互依赖性
- 全局最小值起源

### Rastrigin函数
* *特性：**
- 具有规则间隔的局部最小值的高度多模态
- 对基于梯度的方法的挑战
- 测试全局搜索能力

### Rosenbrock函数
* *特性：**
- 单峰但窄谷到全局最优
- 测试算法在困难环境中的收敛性
- 连续优化的经典基准

### Zakharov函数
* *特性：**
- Unimodal
- 单全局最小值
- 测试基本收敛能力

## 多目标测试问题（2-3 个目标）

### ZDT 测试套件
* *用途：** 双目标优化的标准基准
* *构造：** f2(x) = g(x) · h(f₁(x), g(x))其中 g(x) = 1 处于帕累托最优解

#### ZDT1
- **变量：** 30 连续
- **界限：** [0, 1]
- **帕累托前沿：** 凸面
- **目的：**基本收敛性和多样性测试

#### ZDT2
- **变量：** 30 连续
- **界限：** [0, 1]
- **帕累托前沿：** 非凸（凹）
- **目的：** 测试非凸的处理前沿

#### ZDT3
- **变量：** 30 连续
- **边界：** [0, 1]
- **帕累托前沿：** 断开连接（5 个独立区域）
- **目的：** 测试不连续前沿

 的多样性维护#### ZDT4
- **变量：** 10 连续 (x₁ ∈ [0,1], x2₋₁₀ ∈ [-10,10])
- **帕累托前沿：** 凸
- **难度：** 21⁹ 局部帕累托前沿
- **目的：**使用许多局部最优值测试全局搜索

#### ZDT5
- **变量：** 11 个离散（位串）
- **编码：** x₁ 使用 30 位，x2₋₁₁ 每个使用 5 位
- **Pareto 前面：**凸
- **目的：** 测试离散优化和欺骗性景观

#### ZDT6
- **变量：** 10 连续
- **界限：** [0, 1]
- **帕累托前沿：** 非凸非均匀密度
- **用途：**测试偏解分布的处理

* *用法：**
```python
from pymoo.problems.multi import ZDT1, ZDT2, ZDT3, ZDT4, ZDT5, ZDT6
problem = ZDT1()  # or ZDT2(), ZDT3(), etc.
```

## 多目标测试问题（4+目标）

### DTLZ测试Suite
* *用途：**可扩展的多目标基准测试
* *目标：**可配置（通常为3-15）
* *变量：**可扩展

#### DTLZ1
- **帕累托前沿：** 线性（超平面）
- **难度：** 11^k 局部帕累托前沿
- **目的：** 测试与许多局部最优值的收敛性

#### DTLZ2
- **帕累托前沿：** 球面（凹）
- **难度：** 直接收敛
- **目的：** 基本多目标多样性测试

#### DTLZ3
- **帕累托前沿：** 球形
- **难度：** 3^k 局部帕累托前沿
- **目的：** 将 DTLZ1 的多模态与 DTLZ2 的几何结构相结合

#### DTLZ4
- **帕累托前沿：** 具有偏置密度的球形
- **难度：** 非均匀解分布
- **目的：** 测试多样性维护bias

#### DTLZ5
- **帕累托前沿：** 退化（M 维空间中的曲线）
- **目的：** 测试退化前沿的处理

#### DTLZ6
- **帕累托前沿：** 退化曲线
- **难度：**比DTLZ5
- 更难收敛 **目的：**挑战退化前沿

#### DTLZ7
- **Pareto前沿：**断开区域
- **难度：** 2^(M-1)断开区域
- **目的：**测试断开连接的前端的多样性

* *用法：**
```python
from pymoo.problems.many import DTLZ1, DTLZ2
problem = DTLZ1(n_var=7, n_obj=3)  # 7 variables, 3 objectives
```

## 自定义问题定义

通过扩展基类定义自定义问题：

```python
from pymoo.core.problem import ElementwiseProblem
import numpy as np

class MyProblem(ElementwiseProblem):
    def __init__(self):
        super().__init__(
            n_var=2,           # number of variables
            n_obj=2,           # number of objectives
            n_ieq_constr=0,    # inequality constraints
            n_eq_constr=0,     # equality constraints
            xl=np.array([0, 0]),   # lower bounds
            xu=np.array([1, 1])    # upper bounds
        )

    def _evaluate(self, x, out, *args, **kwargs):
        # Define objectives
        f1 = x[0]**2 + x[1]**2
        f2 = (x[0]-1)**2 + x[1]**2

        out["F"] = [f1, f2]

        # Optional: constraints
        # out["G"] = constraint_values  # <= 0
        # out["H"] = equality_constraints  # == 0
```

## 问题选择指南

* *用于算法开发：**
- 简单收敛： DTLZ2、ZDT1
- 多模态：ZDT4、DTLZ1、DTLZ3
- 非凸：ZDT2
- 断开：ZDT3、DTLZ7

* *用于全面测试：**
- 用于双目标的 ZDT 套件
- 用于多目标的 DTLZ 套件
- 用于复杂景观的 WFG
- 用于约束的 MW/DAS-CMOP

* *用于现实世界验证：**
- 工程问题（Truss2D、焊接梁）
- 将问题特征与应用领域相匹配

* *变量类型：**
- 连续：大多数问题
- 离散：ZDT5
- 混合：定义自定义问题
