# 支持我们依赖的开源项目

克劳德的科学技能是建立在巨人的肩膀上的。该存储库中的 139 项技能利用了由世界各地的专门开发人员和研究社区创建和维护的数十个令人难以置信的开源项目。

**如果您发现这些技能有价值，请考虑支持使这些技能成为可能的底层开源项目。**

---

## 如何支持开源

1. GitHub 上的 **明星存储库** - 它是免费的，可帮助项目获得可见性
2. **直接通过 GitHub Sponsors、Open Collective 或特定于项目的捐赠页面来资助维护人员**
3. **贡献**代码、文档或错误报告
4. **在您的出版物中引用**项目
5.与同事**分享**项目

## K-Dense 的注释

在 K-Dense，我们坚信回馈使我们的工作成为可能的社区。我们鼓励克劳德科学技能的所有用户：

1. **确认**当您在研究中使用这些项目时
2.尽可能地**贡献**背部改进
3. 如果您获得商业价值，则在经济上支持**维护者

开源科学Python生态系统是共享资源。让我们一起让它蓬勃发展。
