## 科学数据库和数据访问

- **数据库查找** - 通过 REST API 搜索 78 个公共科学、生物医学、材料科学和经济数据库，并返回结构化 JSON 结果。涵盖物理/天文学（NASA、NIST、SDSS、SIMBAD、Exoplanet Archive）、地球/环境（USGS、NOAA、EPA、OpenWeatherMap）、化学/药物（PubChem、ChEMBL、DrugBank、FDA、KEGG、DailyMed、ZINC、BindingDB）、材料科学（Materials Project、COD）、生物学/基因组学（Reactome、BRENDA、UniProt、 STRING、Ensembl、NCBI 基因、GEO、GTEx、PDB、AlphaFold、InterPro、ChEBI、BioGRID、基因本体、QuickGO、NCBI 蛋白质/分类、dbSNP、SRA、ENA、gnomAD、UCSC 基因组、ENCODE、JASPAR、MouseMine、PRIDE、LINCS L1000、人类蛋白质图谱、人类细胞图谱、RummaGEO、代谢组学Workbench、EMDB、Addgene）、疾病/临床（COSMIC、Open Targets、ClinPGx、ClinicalTrials.gov、OMIM、ClinVar、GDC/TCGA、cBioPortal、DisGeNET、GWAS Catalog、Monarch、HPO）、监管（FDA、USPTO、SEC EDGAR）、经济/金融（FRED、BEA、BLS、美联储、世界银行、欧洲央行、美国财政部、Alpha Vantage、Data Commons）和人口统计（美国人口普查、欧盟统计局、世界卫生组织）。每当用户想要查找化合物、药物、蛋白质、基因、通路、酶、基因表达、变体、临床试验、专利、SEC 文件、经济指标、晶体结构、天文物体、地震、天气或公共数据库 API 中的任何数据时，都可以使用此技能
- **DepMap** - 查询癌症依赖性图谱 (DepMap)，了解癌细胞系基因依赖性评分 (CRISPR Chronos)、药物敏感性数据和基因效应概况。用于识别癌症特定的脆弱性、合成致死相互作用以及验证肿瘤药物靶点
- **成像数据共享** - 使用 idc-index 从 NCI 成像数据共享查询和下载公共癌症成像数据。用于访问大规模放射学（CT、MR、PET）和病理学数据集以进行 AI 培训或研究。无需身份验证。按元数据查询、在浏览器中可视化、检查许可证
- **PrimeKG** - 查询精准医学知识图（PrimeKG）以获取多尺度生物数据，包括基因、药物、疾病、表型等。将20多种生物医学资源整合到单一知识图谱中，用于药物再利用、疾病机制探索和靶点识别
- **美国财政部财政数据** - 来自美国财政部的免费、开放的 REST API，提供涵盖联邦财政数据的 54 个数据集和 182 个数据表。无需 API 密钥。访问全国债务（回溯到 1993 年的便士债务、回溯到 1790 年的历史债务）、每日国债报表（TGA 余额、存款/提款）、月度国债报表（联邦预算收入和支出）、国债拍卖数据（自 1979 年以来的票据、票据、债券、TIPS、FRN）、国债平均利率、国债报告汇率（170 多种货币的季度报告）、I 债券和储蓄债券利率、TIPS/CPI 数据等。支持过滤、排序、分页和CSV/XML/JSON输出格式## 科学整合

### 实验室信息管理系统 (LIMS) 和研发平台

- **Benchling Integration** - 用于与 Benchling 研发平台集成的工具包，提供对实验室数据管理的编程访问，包括注册实体（DNA 序列、蛋白质）、库存系统（样本、容器、位置）、电子实验室笔记本（条目、协议）、工作流程（任务、自动化）以及使用 Python SDK 和 REST API 的数据导出

### 基因组学和生物医学数据云平台

- **DNAnexus 集成** - 用于与 DNAnexus 云平台配合进行基因组学和生物医学数据分析的综合工具包。涵盖构建和部署应用程序/小程序 (Python/Bash)、管理数据对象（文件、记录、数据库）、运行分析和工作流程、使用 dxpy Python SDK 以及配置应用程序元数据和依赖项（dxapp.json 设置、系统包、Docker、资产）。支持处理 FASTQ/BAM/VCF 文件、生物信息学管道、作业执行、工作流程编排和平台操作（包括项目管理和权限）

### 实验室自动化

- **Opentrons 集成** - 用于创建、编辑和调试 Opentrons Python 协议 API v2 协议的工具包，用于使用 Flex 和 OT-2 机器人的实验室自动化。实现自动化液体处理、移液工作流程、硬件模块控制（热循环仪、温度、磁力、加热器摇床、吸光板读取器）、实验室器具管理以及生物和化学实验的复杂方案开发
- **Ginkgo 云实验室** - 在 Ginkgo Bioworks 云实验室 (cloud.ginkgo.bio) 上提交和管理协议，这是一个基于 Web 的界面，用于在可重新配置自动化推车 (RAC) 上自主执行实验室。支持三种方案：无细胞蛋白表达验证（39 美元/样品，5-10 天周转）、无细胞蛋白表达优化（199 美元/样品，DoE 跨越 24 种条件，6-11 天）和荧光像素艺术生成（25 美元/板，包含 11 种荧光大肠杆菌菌株的细菌图稿，5-7 天）。包括用于定制协议可行性和定价的 EstiMate AI 代理### 电子实验室笔记本 (ELN)
- **LabArchives 集成** - 用于与 LabArchives 电子实验室笔记本 (ELN) REST API 交互的工具包。提供对笔记本（备份、检索、管理）、条目（创建、评论、附件）、用户身份验证、站点报告和分析以及第三方集成（Protocols.io、GraphPad Prism、SnapGene、Geneious、Jupyter、REDCap）的编程访问。包括用于配置设置、笔记本操作和条目管理的 Python 脚本。支持多区域 API 端点（美国、英国、澳大利亚）和 OAuth 身份验证
- **Open Notebook** - Google NotebookLM 的自托管开源替代方案，用于 AI 支持的研究和文档分析。将研究材料整理到笔记本中，提取不同的内容源（PDF、视频、音频、网页、Office 文档），生成人工智能驱动的笔记和摘要，根据研究创建多发言者播客，支持使用上下文感知人工智能进行文档聊天，并使用全文和矢量搜索来搜索材料。支持超过 16 个人工智能提供商，包括 OpenAI、Anthropic、Google、Ollama、Groq 和 Mistral，通过自托管提供完整的数据隐私

### 工作流程平台和云执行

- **LatchBio 集成** - 与 Latch 平台集成，用于构建、部署和执行生物信息学工作流程。为使用 Python 装饰器创建无服务器生物信息学管道、部署 Nextflow/Snakemake 管道、管理云数据（LatchFile、LatchDir）和结构化注册表（项目、表、记录）、配置计算资源（CPU、GPU、内存、存储）以及使用预构建的 Latch Verified 工作流程（RNA-seq、AlphaFold、DESeq2、单细胞分析、CRISPR 编辑）提供全面支持。通过全面的数据管理，在可扩展的云基础设施上实现自动容器化、UI 生成、工作流版本控制和执行### 显微镜和生物图像数据
- **OMERO 集成** - 使用 Python 与 OMERO 显微镜数据管理系统交互的工具包。提供对 OMERO 服务器中存储的显微镜图像的全面访问，包括数据集和筛选数据检索、像素数据分析、注释和元数据管理、感兴趣区域 (ROI) 创建和分析、批处理、OMERO.scripts 开发以及用于结构化数据存储的 OMERO.tables。对于处理高内容筛选数据、多维显微镜数据集或协作图像存储库的研究人员至关重要

## 科学包### 生物信息学与基因组学

- **AnnData** - 用于处理带注释的数据矩阵的 Python 包，专门为单细胞基因组数据设计。提供高维数据的高效存储和操作以及相关注释（观察/细胞和变量/基因）。主要功能包括：基于 HDF5 的 h5ad 文件格式，用于高效 I/O 和压缩，与 pandas DataFrames 集成以实现元数据，支持稀疏矩阵 (scipy.sparse) 以提高内存效率，分层数据组织（X 表示主数据矩阵，obs 表示观察注释，var 表示变量注释，obsm/varm 表示多维注释，obsp/varp 表示成对矩阵），以及与 Scanpy、scvi-tools 和其他工具的无缝集成单细胞分析包。支持延迟加载、分块操作以及与其他格式（CSV、HDF5、Zarr）之间的转换。使用案例：单细胞 RNA-seq 数据管理、多模式单细胞数据（RNA+ATAC、CITE-seq）、空间转录组学以及任何需要高效存储和操作的高维注释数据
- **Arboreto** - 使用基于集成树的方法从单细胞 RNA-seq 数据进行高效基因调控网络 (GRN) 推断的 Python 包。实现针对大规模单细胞数据集优化的 GRNBoost2（基于梯度提升的网络推理）和 GENIE3（基于随机森林的推理）算法。主要功能包括：可扩展性的并行处理、对稀疏矩阵和大型数据集（数百万个单元）的支持、与 Scanpy/AnnData 工作流程的集成、可定制的超参数以及与网络分析工具兼容的输出格式。提供潜在调控相互作用（转录因子-目标基因对）的排名列表以及置信度分数。使用案例：识别转录因子-靶标关系、从单细胞数据重建基因调控网络、了解细胞类型特异性调控程序以及推断基因表达的因果关系
- **BioPython** - 用于计算生物学和生物信息学的综合 Python 库，提供序列操作、数据库访问和生物数据分析工具。主要功能包括：用于 DNA/RNA/蛋白质序列的序列对象（Seq、SeqRecord、SeqIO），具有生物字母表验证、文件格式解析器（FASTA、FASTQ、GenBank、EMBL、Swiss-Prot、PDB、SAM/BAM、VCF、GFF）、NCBI 数据库访问（Entrez 编程实用程序用于 PubMed、GenBank、BLAST、t轴测）、BLAST 集成（运行搜索、解析结果）、序列比对（使用 Bio.Align 进行成对和多序列比对）、系统发生学（使用 Bio.Phylo 进行树构建和操作）、群体遗传学（Hardy-Weinberg、F 统计）、蛋白质结构分析（PDB 解析、结构计算）和统计分析工具。支持与 NumPy、pandas 和其他科学 Python 库集成。使用案例：序列分析、数据库查询、系统发育分析、序列比对、文件格式转换和一般生物信息学工作流程
- **BioServices** - Python 库提供对 40 多个生物 Web 服务和数据库的统一编程访问。支持主要生物信息学资源，包括 KEGG（通路和化合物数据）、UniProt（蛋白质序列和注释）、ChEBI（化学实体）、ChEMBL（生物活性分子）、Reactome（通路）、IntAct（蛋白质相互作用）、BioModels（生物模型）等。具有跨不同服务的一致 API、自动结果缓存、错误处理和重试逻辑、支持 REST 和 SOAP Web 服务以及将结果转换为 Python 对象（字典、列表、BioPython 对象）。处理身份验证、速率限制和 API 版本控制。使用案例：从多个生物数据库自动检索数据、构建生物信息学管道、数据库集成工作流程以及无需手动网页浏览即可以编程方式访问生物网络资源
- **Cellxgene Census** - 用于查询和分析来自 CZ CELLxGENE Discover 普查的大规模单细胞 RNA-seq 数据的 Python 包。通过标准化注释和元数据，可以访问 1,000 多个数据集中的 5000 万多个单元格。主要功能包括：使用 TileDB-SOMA 格式进行高效数据访问以进行可扩展查询、与 AnnData 和 Scanpy 集成以进行下游分析、细胞元数据过滤和查询、基因表达检索以及对人类和小鼠数据的支持。在下载之前可以根据细胞类型、组织、疾病或其他元数据对数据集进行子集化，从而减少数据传输和内存需求。支持本地缓存和批量操作。使用案例：大规模单细胞分析、细胞类型发现、跨数据集比较、参考数据集构建以及公共单细胞数据的探索性分析
- **deepTools** - 用于探索和可视化下一代测序 (NGS) 的全面 Python 工具套件ata，特别是 ChIP-seq、RNA-seq 和 ATAC-seq 实验。提供用于处理 BAM 和 bigWig 文件的命令行工具和 Python API。主要功能包括：质量控制指标（plotFingerprint、plotCorrelation）、覆盖轨迹生成（用于创建 bigWig 文件的 bamCoverage）、热图矩阵生成（computeMatrix、plotHeatmap、plotProfile）、比较分析（multiBigwigSummary、plotPCA）以及大文件的高效处理。支持标准化方法、分箱选项和各种可视化输出。专为高通量分析工作流程和出版质量的图形生成而设计。使用案例：ChIP-seq 峰值可视化、RNA-seq 覆盖分析、ATAC-seq 信号轨迹、比较基因组学和 NGS 数据探索
- **FlowIO** - 用于读取和操作流式细胞术标准 (FCS) 文件（流式细胞术数据的标准格式）的 Python 库。提供 FCS 文件（版本 2.0、3.0、3.1）的高效解析、事件数据访问（荧光强度、散射参数）、元数据提取（关键字、参数、采集设置）以及转换为 pandas DataFrames 或 NumPy 数组。功能包括：支持大型 FCS 文件、处理多个数据段、访问文本段和分析段以及与流式细胞术分析工作流程集成。允许以编程方式访问流式细胞术数据，以进行下游分析、可视化和机器学习应用。使用案例：流式细胞术数据分析、高通量筛选、免疫细胞分析和 FCS 文件的自动处理
- **gget** - 命令行工具和 Python 包，用于通过简单、统一的界面高效查询基因组数据库。提供对 Ensembl（基因信息、序列、直系同源物、变体）、UniProt（蛋白质序列和注释）、NCBI（BLAST 搜索、基因信息）、PDB（蛋白质结构）、COSMIC（癌症突变）和其他数据库的快速访问。功能包括：无需复杂 API 设置的单命令查询、自动结果格式化、批量查询支持、与 pandas DataFrames 集成以及支持命令行和 Python API 使用。针对速度和易用性进行了优化，无需丰富的生物信息学经验的用户即可进行数据库查询。使用案例：生物信息学工作流程中的快速基因查找、序列检索、变异注释、蛋白质结构访问和快速数据库查询
- **geniml** - 基因组间隔 ma中国学习工具包提供了在 BED 文件上构建 ML 模型的无监督方法。主要功能包括 Region2Vec（使用标记化和神经语言建模对基因组区域和区域集进行 word2vec 式嵌入）、BEDspace（使用 StarSpace 进行跨模态查询的区域和元数据标签的联合嵌入）、scEmbed（Region2Vec 应用于单细胞 ATAC-seq 数据生成细胞级嵌入，用于通过 scanpy 集成进行聚类和注释）、共识峰构建（四种统计方法 CC/CCF/ML/HMM从 BED 集合创建参考宇宙）以及综合实用程序（用于 BED 缓存的 BBClient、用于保留上下文的基因组随机化的 BEDshift、用于嵌入质量的评估指标、用于神经搜索后端的 Text2BedNN）。 BEDbase 生态系统的一部分。支持 Python API 和 CLI 工作流程、Hugging Face 上的预训练模型以及与 gtar 集成以进行标记化。使用案例：区域相似性搜索、染色质可访问性数据的降维、scATAC-seq 聚类和细胞类型注释、元数据感知基因组查询、标准化参考的宇宙构建以及任何需要基因组区域特征向量的 ML 任务
- **gtars** - 用于基因组区间分析的高性能 Rust 工具包，提供使用 IGD（集成基因组数据库）索引进行重叠检测的专用工具、覆盖轨迹生成（用于 WIG/BigWig 格式的 uniwig 模块）、用于机器学习应用程序的基因组标记化（用于深度学习模型的 TreeTokenizer）、参考序列管理（refget 协议合规性）、用于单细胞基因组学的片段处理（基于条形码的分割和聚类分析）以及针对参考数据集的片段评分。提供与 NumPy 集成、命令行工具 (gtars-cli) 和 Rust 库的 Python 绑定。关键模块包括：tokenizers（将基因组区域转换为 ML token）、overlaprs（高效重叠计算）、uniwig（ATAC-seq/ChIP-seq/RNA-seq 覆盖图谱）、refget（符合 GA4GH 的序列摘要）、bbcache（BEDbase.org 集成）、评分（片段富集指标）和 fragsplit（单细胞片段操作）。支持并行处理、内存映射文件、大型数据集流式传输，并作为 geniml 基因组 ML 包的基础。非常适合基因组 ML 预处理、调控元件分析、变异注释、染色质可及性分析和计算基因组学工作流程
- **极地-Bio** - Polars DataFrames 上的高性能基因组间隔操作和生物信息学文件 I/O。提供 BED/VCF/BAM/GFF 间隔的重叠、最近、合并、覆盖、补和减操作。用于大规模基因组分析的流式传输和云原生架构，作为 Bioframe 的更快替代方案
- **pysam** - 通过堆积分析、覆盖率计算和生物信息学工作流程读取、写入和操作基因组数据文件（SAM/BAM/CRAM 比对、VCF/BCF 变体、FASTA/FASTQ 序列）
- **PyDESeq2** - 用于批量 RNA-seq 数据的 DESeq2 差异基因表达分析方法的 Python 实现。提供使用负二项式广义线性模型确定实验条件之间差异表达的统计方法。主要功能包括：文库大小标准化的大小因子估计、离散度估计和收缩、使用 Wald 检验或似然比检验的假设检验、多重检验校正 (Benjamini-Hochberg FDR)、结果过滤和排序以及与 pandas DataFrames 的集成。处理复杂的实验设计、批次效应和重复。生成每个基因的倍数变化估计值、p 值和调整后的 p 值。使用案例：识别条件之间的差异表达基因、RNA-seq 实验分析、生物标志物发现以及需要严格统计分析的基因表达研究
